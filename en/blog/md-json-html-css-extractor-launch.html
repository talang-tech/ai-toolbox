New: Markdown Table to JSON & HTML to CSS Extractor

We've added two new developer tools this week:

🔄 Markdown Table to JSON

Many developers use Markdown tables in GitHub Issues, READMEs, and documentation. When you need to import that table data into code or a database, manual conversion is tedious.

This tool supports:

  • Parse Markdown tables into JSON object arrays (first row as keys)
  • Plain array format for all rows as data
  • Special characters in column names auto-converted to valid JSON keys (Chinese preserved)
  • Real-time conversion — paste and see results instantly
  • One-click copy of JSON output

Use cases:

  • Import GitHub Issue / README table data into databases
  • Build API test data fixtures
  • Prepare data for analysis scripts
  • Generate automated test fixtures

🎨 HTML to CSS Extractor

When working with legacy projects, refactoring CSS, or analyzing HTML structure, you often need to quickly identify which CSS classes and IDs are used in the HTML. This tool automatically extracts all selectors and generates a CSS skeleton.

Key features:

  • Extract all CSS class names (.classname format)
  • Extract all ID selectors (#id format)
  • Extract all HTML tags
  • Three modes: classes, IDs, tags, or all-in-one
  • Auto-generate CSS skeleton for quick styling setup
  • Real-time extraction as you type

Use cases:

  • Frontend debugging — understand HTML structure and associated styles
  • CSS refactoring — extract all referenced selectors from HTML
  • Learning from existing code — analyze HTML style structure
  • Creating CSS skeletons for new pages — never miss a selector

Other Updates

  • CSS Box Shadow Generator tool launched with visual box-shadow creation
  • CSS Unit Converter now supports px, em, rem, %, vw, vh conversions
  • CSS Media Query Generator with visual breakpoint configuration
  • Improved privacy notices across all tools — always shows "processed locally, no data upload"
