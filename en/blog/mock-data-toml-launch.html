New: Mock Data Generator & TOML JSON Converter

July 31, 2026

AI Toolbox has added two new tools to help developers with testing and configuration management: Mock Data Generator and TOML JSON Converter.

🧪 Mock Data Generator

Test data is essential for development, but manually creating it is tedious and error-prone. The Mock Data Generator helps you quickly generate realistic test data with 15 field types:

  • Basic info: Name, Email, Phone, Address
  • Professional: Company, Job Title, Salary
  • Identifiers: ID, SSN, Credit Card (test only)
  • Network: URL, IP Address
  • Other: DOB, Color, Description

Supports three output formats: JSON (API development), CSV (spreadsheets), Markdown Table (documentation). Freely combine fields and generate 1-1000 records.

All data is generated locally in your browser — nothing is uploaded.

🔄 TOML JSON Converter

TOML is gaining popularity as a configuration file format in the Rust (Cargo.toml) and Python (pyproject.toml) ecosystems. The TOML JSON Converter supports bidirectional conversion:

  • TOML → JSON: Convert config files for API or script use
  • JSON → TOML: Convert JSON data to TOML format
  • Supports standard TOML: tables, arrays of tables, inline tables, strings, numbers, booleans
  • One-click direction swap for easy back-and-forth testing
