New Tools: XPath Evaluator & CSS to Tailwind Converter

This week we added two high-demand developer tools to the toolbox:

🔍 XPath Evaluator

Test and debug XPath 1.0 expressions online with real-time node highlighting. Supports XML and HTML document input with full XPath syntax including path expressions, predicates, axes, wildcards, and built-in functions.

Use cases:

  • Frontend developers debugging DOM selection logic
  • Data engineers testing XML transformations
  • Web scrapers verifying extraction rules
  • QA engineers writing automation test selectors

100% client-side processing — your data never leaves your browser.

🎨 CSS to Tailwind CSS Converter

Convert traditional CSS properties to equivalent Tailwind CSS utility classes. Supports color, spacing, Flexbox, Grid, Typography, Border, Shadow, and more. Colors auto-map to the closest Tailwind palette values.

Use cases:

  • Migrating from traditional CSS to Tailwind
  • Tailwind beginners finding equivalent class names
  • Batch converting CSS rules during refactoring
