Text Deduplicator

Remove duplicate lines, count lines removed and percentage

—

About this tool

Essential for data cleaning, list deduplication, removing duplicate emails/phone numbers/URLs. Supports: case-insensitive, ignore empty lines, trim whitespace.

Real-time stats: original lines, lines after dedup, count and percentage removed.

Key Features

  • One-click remove duplicate lines
  • Count removed number and percentage
  • Preserve original order
  • Case sensitive option
  • Large text support
  • Browser local processing

Frequently Asked Questions

Does it change original order?

No, preserves first-occurrence order.

Is different case considered duplicate?

Default treats as different. Case sensitivity option available.

How large text is supported?

Hundreds of thousands of lines as browser memory permits.
