JSON to TOML

Convert JSON data to TOML format quickly, supports nested objects and arrays

About this tool

Free online JSON to TOML converter — transform JSON objects into TOML format quickly. TOML is widely used for configuration files (Cargo.toml, pyproject.toml) and known for its readability.

Supports nested objects, arrays, strings, numbers, booleans, null, and all JSON data types. Smart detection of value arrays (inline TOML arrays) vs object arrays (TOML table arrays). All processing is done locally in your browser.

Key Features

  • Quickly convert JSON objects to TOML format
  • Nested objects become TOML sections
  • Smart array type detection (value list vs table array)
  • Supports strings, numbers, booleans, null
  • Automatic special character escaping
  • One-click copy or download
  • Zero data upload, browser local processing
  • TOML v1.0 compliant output

Frequently Asked Questions

What JSON types are supported?

All JSON data types: strings, numbers, booleans, null, nested objects, arrays, and mixed arrays.

How are nested objects handled?

Nested objects are converted to TOML sections. E.g., a.b.c becomes [a.b] with key c.

How are arrays handled?

Value arrays like [1, 2, 3] become inline TOML arrays. Object arrays like [{a:1}, {a:2}] become TOML table arrays [[array]].

Is my data uploaded?

No. All processing is done locally in your browser.

What's the difference between TOML and YAML?

TOML prioritizes readability for config files; YAML is more flexible but has complex syntax. Both have their use cases.

Is TOML v1.0 supported?

Yes. Output follows TOML v1.0 spec, including inline tables, table arrays, and multi-line strings.
