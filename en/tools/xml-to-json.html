Frequently Asked Questions

How are XML attributes represented in JSON?

By default, attributes are marked with @ prefix (e.g., @id). You can disable this by unchecking the option.

What's the fundamental difference between XML and JSON?

XML has attributes, namespaces, and mixed content. JSON only has key-value pairs, arrays, and objects. Attributes and text nodes are mapped appropriately.

Does it support namespaced XML?

Yes. Namespace prefixes are preserved as part of keys or attributes. For complex namespace conversions, verify the output.

Is my data safe?

Everything runs locally in your browser. No data is sent to any server.
