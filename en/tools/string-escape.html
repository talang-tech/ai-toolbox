String Escape / Unescape

Escape and unescape JSON, JavaScript, URL and HTML strings

About this tool

Free online string escape/unescape tool for JSON strings, JavaScript strings, URL encoding, HTML entities and Unicode \uXXXX sequences. Useful for API parameters, logs, code snippets and config files with special characters.

All conversion runs locally in your browser. Your input is never uploaded.

Key Features

  • JSON string escape and unescape
  • JavaScript backslash escape handling
  • Unicode \uXXXX encode/decode
  • URL encode/decode
  • HTML entity encode/decode
  • Error messages and one-click copy
  • Browser-local processing, no upload

Frequently Asked Questions

What is the difference between JSON and JavaScript escaping?

JSON mode follows JSON.stringify rules strictly; JavaScript mode handles common backslash escapes for code snippets and logs.

Can it handle Chinese and emoji?

Yes. Unicode mode converts non-ASCII characters to \uXXXX while keeping surrogate pairs reversible.

Is my input uploaded?

No. All escaping and unescaping happens locally in your browser.
