Frequently Asked Questions

What's the difference between pseudo-classes and pseudo-elements?

Pseudo-classes (:) describe element states (e.g. :hover), pseudo-elements (::) describe specific parts (e.g. ::before). CSS3 recommends double colon for pseudo-elements.

Which pseudo-classes have widest browser support?

:hover, :focus, :active, :first-child, :nth-child are supported by virtually all browsers.

Do ::before and ::always require content?

Yes, both pseudo-elements need the content property (even empty string) to render.

Is data uploaded to a server?

No. All data loads locally in the browser. No network requests.
