CSV Viewer & Table Converter

Parse CSV/TSV into a table, copy as HTML table or JSON

Privacy note

This tool runs in your browser. Your input, files, JSON, JWT, images, PDFs, passwords, hashes, or text are not uploaded to an AI Toolbox server.

Basic analytics may record page views and conversion clicks, but user input and file content are not tracked.

About this tool

Free online CSV viewer and table converter. Parse CSV, TSV, or custom-delimited data into a scrollable table, then copy it as an HTML table or JSON array. Supports quoted fields, commas inside fields, escaped double quotes, and header detection.

All parsing and conversion happen locally in your browser, making it useful for exported reports, admin lists, and lightweight data cleanup without uploading the raw table.

Key Features

  • Preview CSV/TSV as an online table
  • Supports comma, semicolon, Tab, pipe, and custom delimiters
  • Detect first row as header
  • Copy as HTML table
  • Copy or download JSON array
  • Supports quoted fields and commas inside fields
  • Browser local processing, no table data upload

Frequently Asked Questions

Can it parse commas inside fields?

Yes. Fields wrapped in double quotes may contain commas, for example "Product, Growth".

Can it handle TSV files?

Yes. Select Tab in the delimiter dropdown to parse TSV content.

Is data uploaded to a server?

No. CSV parsing, table preview, and JSON conversion all run locally in your browser.
