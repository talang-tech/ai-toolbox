About this tool

Free online XML formatter, validator, and minifier for SOAP payloads, sitemaps, SVG, config files, and API responses. It uses the browser's DOMParser locally to detect parse errors and produce either indented XML or a compact one-line version.

All XML text is processed in your browser and is not uploaded, making it suitable for internal responses, configs, and XML snippets with sensitive fields.

Key Features

  • Format XML with 2/4 spaces or tab indentation
  • Minify XML into a compact one-line string
  • Validate XML using the browser DOMParser
  • Show parser errors with context when available
  • Works for SOAP, sitemaps, SVG, and config files
  • Browser-local processing, XML content is not uploaded

Frequently Asked Questions

Can it format SVG?

Yes. SVG is XML, so you can paste SVG source and format or minify it.

Can it handle SOAP payloads?

Yes, for common SOAP XML payloads. Because it runs locally, internal API responses are not uploaded.

Does minifying XML change content?

Minifying removes whitespace between tags. It usually preserves elements and attributes, but be careful if text nodes intentionally depend on whitespace.
