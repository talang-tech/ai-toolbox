About this tool

JWT (JSON Web Token) is the most common auth method for modern APIs. This tool decodes JWT header and payload entirely client-side, auto-detects expiry.

⚠️ Security: JWT is encoded, not encrypted. Never transmit secrets in plaintext over public networks.

Key Features

  • JWT Header parsing
  • JWT Payload parsing
  • Auto JSON formatting
  • Expiration time display
  • Issued-at time display
  • Pure frontend processing

Frequently Asked Questions

What are the 3 parts of JWT?

Header, Payload, Signature, separated by dots.

Can the JWT signature be decoded?

The signature is binary hash and cannot be decoded, but it can be verified for integrity.

Is JWT encrypted?

No. JWT is just Base64 encoded, anyone can decode and read its content.
