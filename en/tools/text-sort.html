About this tool

Free online text sorter running entirely in your browser. Supports alphabetical ascending/descending, numerical sort, sort by line length, and random shuffle. Options include case-insensitive, remove empty lines, and remove duplicates. Great for organizing lists, sorting filenames, and cleaning up data.

All processing happens locally — your text is never uploaded.

Key Features

  • Alphabetical ascending/descending sort
  • Numerical sort
  • Sort by line length
  • Random shuffle
  • Case-insensitive option
  • Remove empty/duplicate lines
  • Browser-local processing, no data upload

Frequently Asked Questions

Does it support Chinese character sorting?

Yes. Chinese characters are sorted by Unicode code point. Pinyin sorting is not yet supported.

What's the difference between numerical and alphabetical sort?

Numerical sort orders by value (2 < 10), alphabetical by string ('10' < '2').

Is my text uploaded to a server?

No. All sorting happens locally in your browser. Your data never leaves your device.
