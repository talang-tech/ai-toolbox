Password Generator

Generate strong random passwords with customizable length and character types

Privacy note

This tool runs in your browser. Your input, files, JSON, JWT, images, PDFs, passwords, hashes, or text are not uploaded to an AI Toolbox server.

Basic analytics may record page views and conversion clicks, but user input and file content are not tracked.

About this tool

Generate truly random passwords using the browser's cryptographically secure random number generator (crypto.getRandomValues).

Customize length (4-128), and whether to include uppercase, lowercase, numbers, and special characters. Generated passwords are never uploaded or stored.

Key Features

  • Custom password length (4-128 chars)
  • Uppercase/lowercase options
  • Numbers option
  • Special symbols option
  • Exclude ambiguous characters option
  • One-click copy to clipboard

Frequently Asked Questions

What makes a password secure?

At least 12 characters with mix of uppercase, lowercase, numbers, and special symbols.

Why exclude ambiguous characters?

Characters like 0/O, 1/l/I can be hard to distinguish in some fonts. Excluding them makes typing easier.

Are generated passwords logged?

No. All passwords are generated locally in your browser and never uploaded.
