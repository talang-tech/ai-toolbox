ROT13 / Caesar Cipher

ROT13, ROT47, ROT5 text transformation, Caesar shift cipher

About this tool

ROT13 is a simple letter substitution cipher that shifts each letter by 13 places (A↔N, B↔O...). Commonly used online to hide spoilers, puzzle answers, and non-sensitive content.

This tool supports multiple variants:

  • ROT13: Letters A-Z/a-z only, applying twice returns original
  • ROT47: All printable ASCII (codes 33-126)
  • ROT5: Digits 0-9 only
  • ROT13+5: ROT13 for letters + ROT5 for digits
  • Caesar Shift: Custom shift amount (1-25)

All computation happens locally in your browser — no data is uploaded.

Frequently Asked Questions

Is ROT13 encryption?

No. ROT13 is a very simple substitution cipher (a special case of Caesar cipher). It is not secure encryption — anyone who knows ROT13 can easily reverse it.

Why does applying ROT13 twice restore the original?

Because there are 26 letters in the alphabet, shifting by 13 is exactly half the alphabet. Applying ROT13 twice returns the original text.

What is the difference between ROT47 and ROT13?

ROT13 only processes letters A-Z/a-z; ROT47 processes all printable ASCII characters (codes 33-126), covering a much wider range.

What does ROT5 do?

ROT5 only processes digits 0-9, shifting each digit by 5 (0↔5, 1↔6...). It is often used to obfuscate numbers like phone digits in spoilers.
