About this tool

Free online PEM certificate decoder — no OpenSSL installation needed. Decode SSL/TLS certificates, CSRs (Certificate Signing Requests), and private keys. Display full certificate details: Subject, Issuer, validity period, SAN (Subject Alternative Names), public key algorithm, signature algorithm, fingerprint, and more.

All parsing is done locally in your browser. Your private keys and certificate data never leave your machine.

Key Features

  • Decode SSL/TLS certificates, CSRs, and private keys
  • Display Subject, Issuer, validity, and SAN
  • Auto-detect PEM type (CERTIFICATE/CSR/PRIVATE KEY etc.)
  • Show public key algorithm, signature algorithm, fingerprints
  • Browser-local parsing, private keys never uploaded

Frequently Asked Questions

What is PEM format?

PEM is a Base64-encoded certificate format. It starts with -----BEGIN CERTIFICATE-----.

Is my certificate data uploaded?

No. All parsing is done locally via JavaScript in your browser.

What types can be decoded?

CERTIFICATE, CERTIFICATE REQUEST (CSR), PRIVATE KEY, PUBLIC KEY, X509 CRL, and more.

Is it safe to paste my private key?

Yes. Only metadata (algorithm, length, fingerprints) is extracted.

How to get PEM cert from a server?

Run: openssl s_client -connect example.com:443 -showcerts
