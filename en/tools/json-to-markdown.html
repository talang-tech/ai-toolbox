JSON to Markdown Table

Convert JSON arrays/objects into Markdown table format with nested object expansion

About this tool

Free online JSON to Markdown Table converter — quickly convert JSON arrays or objects into clean Markdown tables. Supports automatic nested object expansion with dot-path flattening. Ideal for API documentation, README files, data visualization, and code comments.

Accepts JSON arrays of objects and single objects. Auto-detects nested field structures and flattens deep paths. The generated Markdown table works in GitHub README, Git Issues, blog posts, and any Markdown-supported platform. 100% client-side — your data never leaves your browser.

Key Features

  • Paste JSON array/object, auto-generate Markdown table
  • Nested objects auto-expanded with dot-path flattening
  • Supports all JSON value types
  • Auto-detects column structure, uniform display across rows
  • One-click copy generated result
  • Auto-convert on input (Ctrl+Enter shortcut supported)
  • 100% client-side, no data upload

Frequently Asked Questions

What JSON formats are supported?

JSON arrays of objects and single objects. Each object becomes a Markdown table row.

How are nested objects handled?

Nested objects are flattened with dot notation, e.g. address.city becomes the address.city column header.

How are arrays displayed?

Array fields are displayed as JSON strings in the cell, preserving data integrity.

Is there a data size limit?

No hard limit, but recommend under 5,000 rows for best browser performance.

Is my data safe?

Absolutely. All data is processed locally in your browser. Nothing is uploaded to any server.
