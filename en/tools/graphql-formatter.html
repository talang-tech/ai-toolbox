GraphQL Formatter

Format GraphQL queries/mutations/subscriptions, basic syntax validation, operation naming check, empty selection set detection

About this tool

Free online GraphQL Formatter to quickly format GraphQL queries, mutations, and subscriptions with basic syntax validation.

Supports query/mutation/subscription operation formatting, handles strings, block strings, and comments, outputs clean indented formatting with basic syntax checks.

100% client-side processing, your code never leaves your browser.

Key Features

  • Format query/mutation/subscription operations
  • Handle strings and comments correctly
  • Clean indented output formatting
  • Basic syntax validation (brace matching)
  • Operation naming suggestions
  • Empty selection set {} detection
  • Directive @ prefix detection
  • Copy formatted results
  • One-click clear and re-enter
  • Browser-local processing, no code upload

Frequently Asked Questions

What operation types does the GraphQL formatter support?

It supports formatting of query, mutation, and subscription operations.

Is my data uploaded to a server?

No. All formatting is done locally in your browser.

Does it support keyboard shortcuts?

Yes. Press Ctrl+Enter (Mac: Cmd+Enter) to quickly format.
