About this tool

Free online JSON to CSV converter. Convert JSON arrays or objects to CSV format. Supports nested object flattening. Perfect for exporting API responses to Excel, converting database results to tables, data analysis prep.

Custom delimiter (comma, tab, semicolon, pipe), optional headers, nested flattening with dot-path column names.

100% browser local, no data upload.

Key Features

  • Supports JSON arrays and single objects
  • Auto-detect all fields as columns
  • Nested object flattening (dot-path columns)
  • Array of simple values support
  • Custom delimiter: comma, tab, semicolon, pipe
  • Optional headers row
  • Ctrl+Enter shortcut
  • 100% browser-local, no data upload

Frequently Asked Questions

Does it support nested objects?

Yes. Use 'Nested flatten' mode to flatten nested objects like user.address.city.

Will Chinese text be garbled?

No. Output is UTF-8 encoded. When opening in Excel, select UTF-8 encoding.

What if my JSON has only one object?

Single objects are converted to one CSV row. Perfect for inspecting structure.

How to choose delimiter?

Comma works for Excel. Use tab if your data contains commas.

Is my data uploaded?

No. All processing happens locally in your browser.
