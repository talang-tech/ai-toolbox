About this tool

Break down a full URL into its components: protocol, host, port, path, query parameters, hash.

Key Features

  • Scheme recognition (http/https)
  • Domain/host extraction
  • Port number recognition
  • Path breakdown
  • Query params table display
  • Hash fragment extraction

Frequently Asked Questions

What is URL encoding?

Special characters in URLs are represented as % plus two hex digits to ensure proper transmission.

Does query param order matter?

No, params are unordered key-value pairs.

Are IPv6 addresses supported?

Yes, standard IPv6 format URLs are supported.
