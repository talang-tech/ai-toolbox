CSV to SQL INSERT

Convert CSV data to SQL INSERT statements with custom table name, column mapping, and batch inserts

🔒 Privacy: All data is processed locally in your browser. No upload.

About this tool

Free online CSV to SQL INSERT converter — convert CSV data to SQL INSERT statements with one click. Supports custom table names, column mapping, batch inserts, auto type detection, NULL handling, and string escaping. Ideal for database migration, data import, and test data generation.

Compatible with MySQL, PostgreSQL, SQLite, and other major databases. 100% client-side — your data never leaves your browser.

Key Features

  • One-click CSV to SQL INSERT conversion
  • Custom table name and column names
  • Batch insert mode (INSERT INTO ... VALUES (...))
  • Single-row mode (one INSERT per row)
  • Auto type detection (numbers, booleans, NULL, strings)
  • Automatic string escaping (single quotes, backslashes)
  • Supports CSV with or without headers
  • Configurable delimiter (comma, tab, semicolon)
  • Row count statistics
  • 100% client-side processing

Frequently Asked Questions

Which databases are supported?

Generated SQL works with MySQL, PostgreSQL, SQLite, MariaDB, and other major databases. Syntax differences are handled automatically.

What's the difference between batch and single-row modes?

Batch mode uses one INSERT statement with multiple value tuples for efficient bulk import. Single-row mode generates one INSERT per row.

How are empty fields handled?

Empty fields become SQL NULL. You can optionally keep them as empty strings by checking the option.

Does it support CSV with and without headers?

Yes. CSV with headers auto-detects column names. For CSV without headers, you can manually specify column names.

Is my data safe?

Absolutely. All data is processed locally in your browser. Nothing is uploaded to any server.
