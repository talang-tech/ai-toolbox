About this tool

Free online CSS Flexbox layout generator. Adjust flex container and flex item properties through a visual interface, see live preview, and copy the generated CSS code with one click.

Supports flex-direction, justify-content, align-items, flex-wrap, gap, align-content, flex-grow, flex-shrink, flex-basis, align-self and more. All processing happens locally in your browser.
