Searchable CSS property reference covering common CSS properties, values, and browser support

About this tool

Free online CSS Property Reference — quickly look up CSS properties, values, syntax, and browser support. Covers layout, box model, typography, colors, animation, transforms, Grid, Flexbox, and more. Ideal for front-end development, UI design, CSS debugging, and learning CSS.

Supports search by property name and filtering by CSS category (layout, typography, animation, etc.). Each property includes syntax, allowed values, initial value, browser support flags, and code examples. All data is embedded in the page works offline. 100% client-side.

Key Features

  • Search CSS properties: real-time filter by name
  • Filter by category: layout, typography, animation, colors, box model, flexbox, grid, etc.
  • Each property includes: syntax, values, initial value, browser support
  • Browser support flags: full support / modern / limited / experimental
  • Code examples: every property comes with a CSS example
  • Works offline: all data embedded in the page
  • Completely free, no registration required

Frequently Asked Questions

What CSS properties are included?

All commonly used CSS properties including CSS2.1 and CSS3+. Layout, box model, typography, colors, backgrounds, animation, transforms, transitions, Flexbox, Grid, multi-column, lists, tables, and more.

How to view property details?

Type in the search box or click category filters. Results show syntax, values, initial value, compatibility, and code examples.

Does it support browser compatibility?

Yes. Each property has a compatibility level: all (full support), modern (modern browsers), limited, or experimental.

Can I use it offline?

Yes. All data is embedded in the page. Once loaded, it works offline.
