About this tool

Free online Unicode converter. Decode \uXXXX escape sequences to readable text, or encode Chinese/special characters into various formats.

100% client-side processing.

Key Features

  • Decode/encode \uXXXX escape sequences
  • Convert between hex and text
  • Convert between decimal codepoints and text
  • HTML entity encode/decode
  • Auto-detect input format
  • Display character count and Unicode info
  • 100% local processing, no data upload

Frequently Asked Questions

What is the \uXXXX format?

JavaScript Unicode escape sequences. e.g. \u4e2d\u6587 = Chinese characters.

Does it support 4+ digit Unicode?

Yes. Supports \u{1F389}, surrogate pairs, and direct input.

Is data uploaded?

No. All conversions happen in your browser.
