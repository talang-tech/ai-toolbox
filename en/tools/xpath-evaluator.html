About this tool

Free online XPath Evaluator — quickly test, debug, and validate XPath expressions. Paste your XML/HTML document and XPath expression, see matched nodes highlighted in real-time with their text content. Supports all XPath 1.0 core syntax: path expressions, predicates, axes, wildcards, operators, and built-in functions.

Ideal for frontend developers, data engineers, QA testers, and web scrapers who work with XML/HTML documents. All processing happens in your browser — your data never leaves your device.

  • Supports all XPath 1.0 syntax: paths, predicates, axes, functions
  • Real-time node highlighting with text and attribute display

Frequently Asked Questions

What's the difference between XPath and CSS selectors?

XPath traverses the DOM tree in any direction (up, down, sideways), making it much more powerful. CSS selectors only select descendant elements. XPath supports text matching, position calculation, and more.

Does it support XPath 2.0 or 3.0?

This tool uses the browser's built-in document.evaluate() which supports full XPath 1.0. XPath 2.0/3.0 requires external libraries and is not included yet.

Is my data safe?

Completely safe. All XPath evaluation happens locally in your browser. Your document never leaves your device.

How large can the document be?

We recommend keeping XML/HTML documents under 500KB for optimal browser performance. Larger documents will be truncated.

Can I export match results?

Match results are displayed as text. You can copy them to clipboard with one click for further use.
