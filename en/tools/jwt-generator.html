JWT Generator

Generate JWT tokens online with HS256/HS384/HS512, custom header and payload

About this tool

Free online JWT (JSON Web Token) generator. Supports HS256 / HS384 / HS512 signing algorithms. Customize header and payload, auto-generate iat and exp timestamps.

All signing is done client-side via Web Crypto API. Your secret never leaves your browser.

Generated tokens are ready for API auth testing, development, and debugging.

Key Features

  • Supports HS256 / HS384 / HS512 signing algorithms
  • Editable header and payload JSON
  • Auto-generate iat (issued at) and exp (expiration) timestamps
  • Client-side signing via Web Crypto API, secret never uploaded
  • Real-time token preview with one-click copy

Frequently Asked Questions

What's the difference between JWT and regular tokens?

JWT is a self-contained token format that carries JSON claims like user identity and permissions.

Is my secret key safe?

All signing is done client-side via Web Crypto API. Your secret is never uploaded to any server.

HS256 vs RS256?

HS256 uses the same key for signing and verification (symmetric). RS256 uses public/private keys.

Can I use these tokens in production?

We recommend using server-side JWT libraries for production use.

Does it support RS/ES algorithms?

Current version supports HS256/HS384/HS512. Use server-side libraries for asymmetric signing.
