About this tool

Free online HTTP status code reference. Covers all standard HTTP status codes from 1xx (Informational), 2xx (Success), 3xx (Redirection), 4xx (Client Error), to 5xx (Server Error). Each code includes the name, meaning, common causes, and troubleshooting tips.

Supports search by code number, filter by category. Perfect for backend developers, API debugging, DevOps troubleshooting, and frontend error handling. All data is bundled and queried locally in the browser.

Frequently Asked Questions

What's the difference between 404 and 410?

404 means the resource is temporarily gone (may return). 410 means it's permanently deleted.

What's the difference between 301 and 302?

301 is permanent redirect (search engines update their index). 302 is temporary.

Is a 500 error always a backend problem?

Yes. 500 Internal Server Error indicates a server-side issue — code exception, database problem, or misconfiguration.

What causes a 502 Bad Gateway?

502 means the proxy/gateway received an invalid response from the upstream server. Common with Nginx when backend crashes or times out.

Does this tool need network requests?

No. All status code data is embedded in the page — it works offline.
