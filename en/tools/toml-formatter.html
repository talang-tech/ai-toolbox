TOML Formatter

TOML config file formatter and validator — indent, sort sections, and detect common errors

About this tool

Free online TOML formatter and validator. TOML is widely used for configuration files (Rust Cargo, Python pyproject.toml, etc.).

  • Format: Auto-indent sections, align equals, organize table structure, clean extra whitespace
  • Validate: Check for empty table headers, invalid key-value pairs, tab characters in values, and other common issues

Perfect for: cleaning up Cargo.toml, pyproject.toml, or any TOML configuration before or after editing.

All processing happens locally in your browser — no data uploaded.

Key Features

  • One-click TOML formatting with auto-indentation
  • Clean [section] and [[array]] table structure
  • Aligned equals signs for key-value pairs
  • Basic validation: empty headers, invalid values
  • Remove extra blank lines and trailing whitespace
  • Supports standard TOML (multiline strings, inline tables)
  • Browser-local processing, config stays private
  • Ctrl+Enter keyboard shortcut for quick execution

Frequently Asked Questions

How is TOML different from other config formats?

TOML aims to be intuitive and readable — like INI but more powerful. Supports nested tables, arrays, dates, etc. Popular in Rust (Cargo.toml) and Python (pyproject.toml).

Does formatting break comments?

No. The tool preserves all inline and line-level comments while adjusting indentation and whitespace.

Does it support all TOML v1.0 features?

The tool handles common TOML structures: tables, inline tables, arrays, strings, numbers, booleans, dates. Advanced features like dotted keys have basic support.

Is data uploaded?

No. All formatting and validation happens entirely in your browser. Your config never leaves your device.
