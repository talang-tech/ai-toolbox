About this tool

Free online JSON deep merge tool. Merge two JSON objects into one with recursive nested object merging and array deduplication. Perfect for config file merging, API response merging, i18n file merging, and more.

Merges left JSON fields into right JSON with array dedup, recursive nested merge, and key overwrite. All processing is done locally in your browser.

Key Features

  • Deep merge two JSON objects
  • Recursive nested object merging
  • Array deduplication on merge
  • Auto-detects JSON syntax errors
  • Swap left/right input for comparison
  • One-click copy merge result
  • Clear status and statistics
  • Browser local processing, no upload

Frequently Asked Questions

What is the merge strategy?

Left JSON fields are merged into right JSON. If both have the same key and both values are objects, they merge recursively. If both are arrays, they merge with dedup. Otherwise, the right value overwrites the left.

Does it support nested merging?

Yes. Nested objects are merged recursively with no depth limit.

How are arrays merged?

Arrays are merged with deduplication. Duplicate entries are not added twice. Both primitive and object arrays are supported.

What is the difference from JSON Diff?

JSON Diff compares two JSONs to show differences, JSON Merge combines two JSONs into one.

Is my data safe?

All processing is done locally in your browser. Your data is never uploaded.
