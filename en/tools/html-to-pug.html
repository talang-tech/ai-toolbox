HTML to Pug Converter

Convert HTML tags to Pug/Jade template syntax with class and ID shorthand

🔒 Privacy: All processing is local. No data upload.

About this tool

Free online HTML to Pug converter to help Node.js developers quickly convert HTML tags to Pug (formerly Jade) template syntax. Supports full conversion of elements, attributes, classes, IDs, text content, and nested structures. All processing is done locally.

Key Features

  • Auto-convert to Pug indentation syntax
  • Class and ID shorthand
  • All HTML attributes supported
  • Self-closing tags
  • Nested structure support
  • One-click copy, Ctrl+Enter
  • Browser-local processing

Frequently Asked Questions

Pug vs Jade?

Pug was formerly Jade. Node.js template engine.

Can I use the output directly?

Yes. Follows Pug 2.x syntax.

Is data uploaded?

No. All processing is local.

HTML5 support?

All standard HTML elements supported.
