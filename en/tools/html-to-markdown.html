About this tool

Free online HTML to Markdown converter. Quickly convert HTML pages, rich text snippets, or code fragments into clean Markdown format. Perfect for:

  • Converting web content to Markdown notes
  • Converting HTML emails to Markdown
  • Extracting Markdown from rich text editors
  • Cleaning HTML while preserving text markup

Conversion runs entirely in your browser. Your content is never uploaded.

Key Features

  • Convert HTML to Markdown in one click
  • Supports headings h1-h6, paragraphs, lists
  • Table conversion support
  • Links, images, and code blocks
  • Bold, italic, strikethrough conversion
  • Live Markdown preview
  • Copy or download .md file
  • Browser local processing, no upload

Frequently Asked Questions

Which HTML tags are supported?

Major block tags: h1-h6, p, ul/ol, blockquote, pre/code, table, hr, div; inline tags: a, img, strong/b, em/i, del/s, code.

Is my HTML content uploaded?

No. All conversion and preview happen locally in your browser. Your data never leaves your device.

Where can I use the converted Markdown?

GitHub README, Markdown notes, blog drafts, Notion, Obsidian, or any Markdown editor.

Does it support HTML tables?

Yes. HTML tables are converted to Markdown table format.

Are scripts and styles preserved?

No. script and style tags are automatically removed for clean output.
