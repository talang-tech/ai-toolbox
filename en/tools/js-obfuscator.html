Obfuscate JavaScript code with variable renaming, string splitting, numeric encoding

About this tool

Free online JavaScript obfuscator to help developers protect frontend JS code. Supports three obfuscation levels: Light (variable renaming + comment removal), Medium (adds string splitting), Heavy (adds hex numeric encoding). Built-in beautifier to restore formatting.

Perfect for: obfuscating frontend logic, protecting API keys, code security review, learning obfuscation techniques. All processing is local in your browser.

Key Features

  • Three obfuscation levels: Light/Medium/Heavy
  • Auto-rename variables to short names
  • String splitting & concatenation
  • Hex numeric encoding
  • Comment and whitespace removal
  • Built-in beautifier for format restoration
  • Input/output size and compression ratio display
  • Ctrl+Enter keyboard shortcut
  • 100% browser-local processing

Frequently Asked Questions

Will obfuscated code still run?

Yes. Obfuscation only changes variable names and formatting, not logic.

Does obfuscation fully protect code?

No. JS code is always viewable in browser. Obfuscation increases reverse-engineering difficulty.

What are the three levels?

Light: rename+comment removal; Medium: +string splitting; Heavy: +hex encoding.

Is data uploaded?

No. All processing is local.

Can I reverse obfuscation?

Beautifier restores formatting, but variable names cannot be recovered.

What code is suitable?

Frontend logic, API keys, config objects, utility functions.
