About this tool

Internationalized Domain Names (IDN) allow non-ASCII characters (Chinese, Japanese, Korean, etc.) in domain names. Punycode is the encoding method that converts these characters to ASCII, making them compatible with the existing DNS protocol.

Example: 中文.com → xn--4gqw0a.com

This tool converts between Punycode and Unicode in both directions, auto-detecting the input type. All processing is done locally in your browser.

Key Features

  • Encode Unicode domain to Punycode
  • Decode Punycode to Unicode
  • Support Chinese, Japanese, Korean and other scripts
  • Auto-detect input type
  • Support full domain names and individual labels
  • 100% local processing, no domain data uploaded
  • One-click copy results

Frequently Asked Questions

What is Punycode?

Punycode is a method to encode Unicode characters as ASCII for Internationalized Domain Names (IDN). Punycode domains start with xn--.

Is Punycode secure?

Punycode is encoding, not encryption. All characters are publicly visible. However, homoglyph characters may be used for phishing attacks (Homograph Attack).

Which browsers support Chinese domains?

All modern browsers support IDN. You can type Chinese characters directly in the address bar, and the browser converts to Punycode automatically for DNS resolution.

What is the xn-- prefix?

Punycode encoding starts with the xn-- prefix. The DNS system uses this prefix to recognize an encoded IDN label.
