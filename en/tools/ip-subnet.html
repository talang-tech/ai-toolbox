Frequently Asked Questions

What is CIDR?

Classless Inter-Domain Routing, using IP/prefix-length notation like 192.168.1.0/24.

How many usable IPs in /24?

256 total addresses, minus network and broadcast = 254 usable.

Is IPv6 supported?

IPv4 currently supported, IPv6 can be added later.
