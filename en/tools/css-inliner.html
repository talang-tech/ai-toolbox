CSS Inliner

Inline CSS styles from style tags into HTML element style attributes, ideal for email HTML

🔒 Privacy: All processing is local. No data upload.

About this tool

Free online CSS inliner tool. Automatically inline CSS rules from <style> tags into each element's style attribute, solving email client compatibility issues where external and embedded styles are not supported.

Supports class and ID selectors, basic media queries, and pseudo-classes (hover/active etc.) as separate attributes. Perfect for email marketing, HTML email template development, and email compatibility.

All processing is done locally in your browser.

Key Features

  • Automatically inline CSS from <style> blocks into HTML elements
  • Supports class and ID selector matching
  • Preserves media queries as separate style blocks
  • Preserves pseudo-classes (:hover, :active, etc.)
  • One-click copy or download inlined HTML
  • 100% local processing, no data upload

Frequently Asked Questions

Why do I need to inline CSS?

Most email clients (Outlook, Gmail, Yahoo Mail) don't support CSS in <style> tags. They only recognize inline style attributes. Inlining ensures consistent rendering across email clients.

Which CSS selectors are supported?

Class (.class), ID (#id), and tag selectors (div, p) are supported. Complex selectors like :nth-child or :not() are not supported.

What about pseudo-classes?

Pseudo-classes (:hover, :active, :focus, etc.) are preserved in their own <style> block since inline styles can't represent them. Base inline styles are generated as fallback.

Are media queries removed?

No. Media queries are preserved in a separate <style> block to ensure responsive emails work in clients that support them.

Is my data safe?

Completely safe. All processing is local in your browser. No data is uploaded to any server.

Does it support CSS frameworks?

Basic CSS framework classes (like Bootstrap) are supported. However, very complex selector combinations or CSS functions may not be fully parsed.
