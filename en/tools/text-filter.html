Text Filter (Grep)

Filter text lines by keyword or regex — quickly extract or exclude matching lines, with case-insensitive and inverse matching

About this tool

Free online Text Filter (Grep) — like grep, but runs entirely in your browser. Paste your text, use keywords or regex patterns to filter, extract, or exclude matching lines with real-time preview.

Supports case-sensitive/insensitive toggle, inverse matching (exclude matches), and regex patterns. Perfect for log analysis line extraction, code search, data cleaning line filtering, and config file key line lookup. All processing is done locally in your browser.

Key Features

  • Keyword or regex pattern filtering
  • Case-sensitive/insensitive toggle
  • Inverse match (exclude matching lines)
  • Real-time filter preview
  • Match count and statistics display
  • One-click copy result
  • Zero data upload, browser local processing
  • Large text support

Frequently Asked Questions

What can Text Filter do?

Filter text lines by keyword or regex pattern — quickly extract matching lines or exclude unwanted ones. Like an online grep.

Does it support regex?

Yes. Enable the Regex option to use JavaScript regex syntax like \d+, [a-z], ^error, etc.

What is inverse match?

Inverse match excludes all lines that match the pattern, keeping only non-matching lines.

Is my data uploaded?

No. All processing is done locally in your browser.

How is this different from Remove Lines?

Remove Lines operates by line number/position. Text Filter matches by content — ideal for extracting specific patterns from large datasets.

Can I use it with other tools?

Yes. Filter first, then sort, deduplicate, or analyze — perfect for data analysis workflows.
