Free online Cron Expression Generator. Generate cron expressions quickly from common presets (every minute, hourly, daily, etc.) or from human-friendly descriptions. Ready to use in Linux crontab, CI/CD, and scheduling tools.

Frequently Asked Questions

What is the basic cron expression format?

Standard 5-field format: minute hour day-of-month month day-of-week.

How to represent every N time?

Use / operator, e.g. */5 means every 5 minutes, 0 */2 means every 2 hours.

What if both day-of-month and day-of-week are set?

It is OR logic. Either condition triggers execution.

Where can I use the generated expression?

Linux crontab, cloud function triggers, CI/CD schedules, Kubernetes CronJob.

Does it support second-level expressions?

This tool generates standard 5-field crontab format without seconds.
