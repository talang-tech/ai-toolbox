Encode/decode Base64 strings and files, UTF-8 safe

About this tool

Base64 is an encoding scheme that represents binary data using ASCII characters, commonly used to transmit binary data through text-based protocols (email, JSON, URLs).

This tool supports UTF-8 (including Chinese characters) and works in both directions.
