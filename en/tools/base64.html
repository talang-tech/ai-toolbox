Base64 Encoder/Decoder

Encode/decode Base64 strings and files, UTF-8 safe

About this tool

Base64 is an encoding scheme that represents binary data using ASCII characters, commonly used to transmit binary data through text-based protocols (email, JSON, URLs).

This tool supports UTF-8 (including Chinese characters) and works in both directions.

Key Features

  • Text Base64 encoding
  • Text Base64 decoding
  • Image file Base64 encoding
  • Any file Base64 encoding
  • UTF-8 Chinese support
  • Data URL format support

Frequently Asked Questions

How much does Base64 increase size?

Base64 encoding increases size by about 33% as 3 bytes become 4 ASCII characters.

Why use Base64?

Mainly for transmitting binary data in text protocols, e.g., embedding images in JSON, HTML, URLs.

Is Base64 encryption?

No. Base64 is just encoding. Anyone can decode to get original data.
