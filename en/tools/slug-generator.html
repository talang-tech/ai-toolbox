About this tool

Free online URL slug generator. Convert article titles or any text into SEO-friendly URL aliases. Strips special characters, normalizes case, replaces spaces with separators.

Supports custom separators, max length control, lowercase toggle. Ideal for WordPress slugs, GitHub repos, route paths. All processing locally in your browser.

Key Features

  • Custom separator
  • Lowercase option
  • Max length control
  • Strip special chars
  • Unicode normalization
  • Live URL preview
