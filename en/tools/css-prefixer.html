CSS Prefixer

Auto-add vendor prefixes to CSS properties

🔒 Privacy: All processing is local. No CSS upload.

About this tool

Free online CSS vendor prefixer tool. Automatically add -webkit-, -moz-, -ms-, -o- vendor prefixes to CSS properties, ensuring CSS3 features work in older browsers.

Supports 60+ commonly prefixed CSS properties, @keyframes rule prefixing, and gradient function value prefixing. All processing is done locally in your browser.

Key Features

  • Auto-add -webkit-, -moz-, -ms-, -o- vendor prefixes
  • Supports 60+ CSS properties including transform, animation, transition
  • Supports @keyframes rule prefixing
  • Supports gradient function value prefixing
  • Supports flexbox, grid layout property prefixes
  • 100% local processing, no CSS upload

Frequently Asked Questions

Why add vendor prefixes?

Different browser engines implement CSS3 features at different stages. Vendor prefixes ensure compatibility across older browsers.

Which CSS properties are supported?

60+ properties including transform, animation, transition, flexbox, grid, mask, filter.

Does it support @keyframes?

Yes. @keyframes rules are automatically prefixed with vendor prefixes.

Does it support gradient values?

Yes. Functions like linear-gradient, radial-gradient get -webkit- prefix.

Is my data safe?

Completely safe. All CSS processing is done locally in your browser.

How is this different from Autoprefixer?

Similar functionality but runs entirely in the browser - no installation needed.
