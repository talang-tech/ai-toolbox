JSON Flatten/Unflatten

Flatten nested JSON into dot-notation keys, with one-click unflatten back

About this tool

Free online JSON flatten and unflatten tool. Transform deeply nested JSON objects into flat dot-notation key-value pairs, and restore them back to the original nested structure.

  • Flatten mode: Convert nested JSON to dot-separated keys, e.g. {"user": {"name": {"first": "John"}}} → {"user.name.first": "John"}
  • Unflatten mode: Restore flattened dot-notation keys back to the original nested structure
  • Array support: Properly handles JSON array indices like items.0.name

Perfect for: configuration flattening, log analysis, ETL preprocessing, working with jq flatten libraries, API response parsing.

100% browser-local processing — your data never leaves your device.

Frequently Asked Questions

What does JSON flatten mean?

It transforms nested JSON objects into single-level key-value pairs using dot notation to represent hierarchy. E.g. {"a": {"b": "c"}} becomes {"a.b": "c"}.

How are arrays handled?

E.g. {"items": ["a", "b"]} becomes {"items.0": "a", "items.1": "b"}.

Can I unflatten back to the original?

Yes. Switch to Unflatten mode, paste the flattened JSON, and it will restore the original nested structure.

Is data uploaded?

No. All processing happens entirely in your browser. Your data never leaves your device.

Can it handle large JSON files?

Yes, but we recommend keeping files under 5MB for optimal browser performance.

How is this different from jq flatten?

Same concept, but graphical interface with no installation needed — great for users who prefer a visual tool over CLI.

Does it handle deeply nested objects?

Yes. There is no practical depth limit — any valid JSON structure can be flattened.
