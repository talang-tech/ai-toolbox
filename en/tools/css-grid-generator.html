Frequently Asked Questions

What's the difference between CSS Grid and Flexbox?

Grid is 2D (rows and columns simultaneously), Flexbox is 1D (row or column). Grid is for page layout, Flexbox for component arrangement.

What is the 1fr unit?

1fr is a CSS Grid flexible unit representing one fraction of available space. 1fr 1fr 1fr means 3 equal columns.

What's the difference between gap and grid-gap?

gap is the standard property; grid-gap is deprecated. Use gap to set both row and column gaps.

What's the difference between justify-content and justify-items?

justify-content controls the grid horizontal alignment within the container; justify-items controls item alignment within their cells.
