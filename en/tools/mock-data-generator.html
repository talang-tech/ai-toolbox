About this tool

Free Mock Data Generator for developers. Quickly generate realistic test data with support for names, emails, phones, addresses, companies, job titles, dates of birth, IDs, SSNs, IP addresses, colors, salaries, and more. Freely combine fields, choose generation count, and export as JSON, CSV, or Markdown table.

Ideal for software testing, database seeding, API development, UI prototyping, and data migration validation. All data is generated locally in your browser — no data is ever uploaded.

Key Features

  • 15 field types: name, email, phone, address, company, job title, etc.
  • Three output formats: JSON, CSV, Markdown table
  • Customizable count (1-1000 records)
  • One-click copy generated data
  • All data generated locally in browser, zero upload
  • Perfect for dev testing, DB seeding, UI prototyping

Frequently Asked Questions

What is Mock Data Generator used for?

Quickly generate test data for database seeding, API testing, UI prototyping, and data migration verification. Generated data is not real — for testing purposes only.

What output formats are supported?

JSON, CSV, and Markdown table. JSON for API development, CSV for spreadsheets, Markdown table for documentation.

What is the maximum number of records?

Up to 1000 records per generation. You can generate multiple times for more data.

Is my data uploaded to servers?

No. All data is generated locally in your browser. Nothing is uploaded.

Are the generated phone numbers real?

All data is randomly generated for testing only and does not represent real information.

Can I customize the generation logic?

Currently supports 15 built-in field types. For custom data, export as CSV and edit in Excel.

Can I use the generated credit card numbers?

No. They are randomly generated test numbers that match format patterns. Not valid for payments.
