About this tool

Free online Markdown table formatter. Sort, align, and beautify existing tables. Perfect for GitHub README files and documentation.

  • Column sorting: Sort by any column ascending/descending
  • Alignment control: Left, center, or right
  • Canonical output: Auto-fix formatting issues
  • Strip table: Convert to plain text

All processing is local.

Key Features

  • Sort by any column ascending/descending
  • Unified alignment: left/center/right
  • Auto-fix separator rows and column widths
  • Convert to plain text (comma or pipe delimited)

Frequently Asked Questions

What format is supported?

GFM table format with separator row and pipe delimiters.

Does sorting affect headers?

No, headers stay at the top.
