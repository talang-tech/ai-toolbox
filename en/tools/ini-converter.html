INI Config Converter

Convert between INI and JSON, YAML, or TOML. Supports nested sections and comment handling.

About this tool

Free online INI config converter for bidirectional conversion between INI, JSON, YAML, and TOML. Handles nested sections, comment stripping, type inference, and indentation.

  • INI → JSON: Standard JSON output
  • INI → YAML: For CI/CD pipelines
  • INI → TOML: Modern Python/Go projects
  • Reverse: JSON/YAML/TOML → INI

All processing is local.

Key Features

  • Bidirectional INI ↔ JSON/YAML/TOML
  • Nested section parsing: section.sub.key
  • Smart type inference: numbers/booleans
  • Preserve or strip INI comments

Frequently Asked Questions

How are nested sections handled?

Dot-notation like [database.replica] parsed into nested structures.

Is my data safe?

All processing is local. No upload.
