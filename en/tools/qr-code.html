About this tool

Generate QR codes from any text, URL, WiFi credentials, etc. Adjustable size and error correction level, downloadable as PNG.

Pure frontend implementation (qrcode.js), data is never uploaded.

Key Features

  • Generate QR code from any text/URL
  • Custom QR code size
  • Download as PNG image
  • Error correction level selection
  • Real-time preview
  • Chinese encoding support

Frequently Asked Questions

How much data can a QR code store?

Version 40 QR code can store up to 7089 numeric or 4296 alphanumeric characters, ~1800 Chinese characters.

What is error correction level?

L(7%), M(15%), Q(25%), H(30%) - higher level tolerates more damage/obscuration.

Do generated QR codes expire?

No. QR code content is static and permanent.
