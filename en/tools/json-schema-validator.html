JSON Schema Validator

Validate JSON data against JSON Schema (Draft-07 support)

Tip: Ctrl+Enter / Cmd+Enter to validate

About this tool

JSON Schema Validator helps you check JSON data against JSON Schema Draft-07 standards. Supports type checking, required properties, pattern matching, enum, value ranges, array items validation, allOf/anyOf/oneOf/if-then-else, format validation (email/uri/date-time/uuid/ipv4/hostname), additionalProperties, and more.

Whether for API response validation, config file checking, or data testing, this tool pinpoints which fields fail and why.

All processing happens locally. Your data stays on your device.

Key Features

  • Supports JSON Schema Draft-07 core specification
  • Type checking: string, number, integer, object, array, boolean, null
  • String constraints: minLength, maxLength, pattern, format (email/uri/uuid etc.)
  • Number constraints: minimum, maximum, multipleOf
  • Array constraints: minItems, maxItems, uniqueItems, contains
  • Conditional validation: allOf, anyOf, oneOf, not, if-then-else
  • Object constraints: required, properties, additionalProperties, dependencies
  • Precise error reporting with field path and reason
  • Ctrl+Enter shortcut for quick validation
  • 100% local processing, zero data upload

Frequently Asked Questions

Which JSON Schema version is supported?

JSON Schema Draft-07 is fully supported with most Draft-2019-09 features. Draft-2020-12's prefixItems and some new features are not yet supported.

What validation scenarios does it cover?

Covers everyday API validation, config checking, and data testing: type, required, pattern, format, enum, numeric ranges, array constraints, and conditionals (if-then-else).

Is my data uploaded to a server?

No. All processing happens 100% in your browser. Your data never leaves your device.

What's the maximum JSON size?

Limited by browser memory. Recommend under a few hundred KB. Very large JSON (several MB) may be slow.

How is this different from the JSON Formatter?

JSON Formatter focuses on formatting/compressing; JSON Schema Validator checks data structure against a schema. They complement each other.

How do I validate quickly?

Press Ctrl+Enter (Cmd+Enter on Mac) in the Schema or Data textarea for quick validation.
