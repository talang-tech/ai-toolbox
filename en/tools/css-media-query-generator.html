Frequently Asked Questions

What is a CSS media query?

A CSS media query (@media) is a CSS3 feature that applies styles based on device characteristics like viewport width, orientation, and resolution. It's the core technology for responsive web design.

What's the difference between mobile-first and desktop-first?

Mobile-first uses min-width queries, starting with small-screen styles and enhancing for larger screens. Desktop-first uses max-width, starting with large-screen styles and adapting for smaller screens. Mobile-first is recommended.

What is a breakpoint?

A breakpoint is the width threshold where your design changes. Common breakpoints: phone 480px, tablet 768px, laptop 1024px, desktop 1280px, large screen 1440px.

What device presets are available?

6 presets: Phone (480px), Small Tablet (640px), Tablet (768px), Laptop (1024px), Desktop (1280px), Large Screen (1440px).

Can I use the generated code directly?

Yes. The generated code is standard CSS @media rules that can be copied directly into your stylesheets.

Is my data safe?

Completely safe. All media query generation is done locally in your browser.

What is orientation?

Orientation detects screen direction: portrait (height > width) and landscape (width > height).

Can I combine multiple conditions?

Yes. Use and, or, and not operators to combine multiple media features like width and orientation.
