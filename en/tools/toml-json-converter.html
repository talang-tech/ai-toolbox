TOML JSON Converter

Bidirectional TOML and JSON format converter

About this tool

Free bidirectional TOML and JSON converter. Quickly convert between two popular configuration file formats. TOML is widely used in the Rust ecosystem (Cargo.toml), Python community (pyproject.toml), and more, while JSON is the standard for web development and APIs.

Supports standard TOML syntax: key-value pairs, strings, numbers, booleans, arrays, tables ([table]), and arrays of tables ([[array]]). All processing happens locally in your browser — no data uploaded.

Frequently Asked Questions

What is the difference between TOML and JSON?

TOML has a simpler, more readable syntax designed for configuration files. JSON is more universal and widely used in web APIs and data exchange. TOML doesn't support null values; JSON doesn't support multi-line strings (without escaping).

What TOML syntax is supported?

Key-value pairs, strings (single and double quotes), numbers, booleans, arrays, tables ([table]), arrays of tables ([[array]]), and inline tables. Multi-line strings, datetime, and special float formats are not yet supported.

Where is TOML used?

Rust's Cargo.toml, Python's pyproject.toml, Ruby's Bundler config, and more. TOML is growing in popularity with the Rust and Python ecosystems.

Will the conversion preserve everything?

There are some differences between TOML and JSON: TOML doesn't support null, JSON doesn't support multi-line strings. Conversion tries to preserve data integrity, but some format details may be lost.
