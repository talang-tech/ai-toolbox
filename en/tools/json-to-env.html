JSON to .env Variables

Convert JSON object to .env format environment variables with flat or nested modes

🔒 Privacy: All data is processed locally in your browser. No upload.

About this tool

Free online JSON to .env converter — quickly convert JSON config objects to standard .env format. Supports flat mode, nested object concatenation, array serialization, and value type detection. Ideal for Docker deployments, CI/CD pipelines, Node.js/React project configs, and more.

Supports case conversion (keep original, UPPERCASE, or camelCase to SCREAMING_SNAKE_CASE), and optional value quoting. 100% client-side — your data never leaves your browser.

Key Features

  • One-click JSON to .env conversion
  • Flat mode: expand nested keys (e.g. app.port=3000)
  • Nested mode: preserve path structure in key names
  • Case conversion: keep original / UPPERCASE / camelCase to SCREAMING_SNAKE_CASE
  • Arrays auto-serialized to JSON strings
  • Auto type detection for booleans, numbers, nulls
  • Optional quoting for string values
  • One-click copy .env content
  • 100% client-side processing

Frequently Asked Questions

What JSON formats are supported?

Any valid JSON object. Nested objects are flattened into dot-notation keys. Arrays are serialized as JSON strings.

What's the difference between flat and nested modes?

Flat mode merges nested keys with dot notation (e.g. app.port=3000). Nested mode serializes the whole object per key. Flat mode is recommended.

Can env var names be converted to uppercase?

Yes. Select 'UPPERCASE' to convert all keys to uppercase. Select 'camelCase to SCREAMING_SNAKE_CASE' for NODE_ENV style.

Is the output compatible with Docker?

Yes. The output follows standard .env file format, compatible with docker-compose, dotenv, and similar tools.

Is my data safe?

Absolutely. All data is processed locally in your browser. Nothing is uploaded to any server.
