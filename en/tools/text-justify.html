Text Justify

Justify text to a specified width with padding character, first-line indent, paragraph spacing and alignment options

About this tool

Free online Text Justify tool. Supports custom padding characters, first-line indent, paragraph spacing, left/right/center alignment, and more. All processing is done locally.

Key Features

  • Full justification
  • Left, right, center alignment
  • Custom padding character
  • First-line indent support
  • Paragraph spacing adjustment
  • Preserve or auto-merge paragraphs
  • Real-time statistics
  • All processing in browser

Frequently Asked Questions

What is text justification?

Stretching each line to a specified width by adding even spacing between words.

Does it support Chinese?

Yes. Chinese characters count as 2 English character widths.
