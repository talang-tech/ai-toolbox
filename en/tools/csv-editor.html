CSV Editor

Edit CSV data online — visual table editor, add/remove rows/columns, live preview

About this tool

Free online CSV editor. Paste CSV text and it auto-parses into an editable table. Click cells to edit, add/remove rows/columns, and see the CSV output update in real-time.

No signup, no data upload, fully local. Perfect for quick CSV edits, small data cleaning, and rearranging columns.

Key Features

  • Paste CSV and auto-parse into editable table
  • Click cells to edit data directly
  • Add/remove rows and columns
  • Live CSV output preview
  • One-click copy or download CSV
  • Fully local, no data upload

Frequently Asked Questions

Will the CSV format change after editing?

The output uses standard CSV: comma-separated, fields with commas/newlines auto-quoted.

What delimiters are supported?

Comma (,) is standard. Tab-delimited TSV is auto-detected.

Is my data uploaded?

No. All editing happens locally in your browser. Data stays on your device.

How many rows can I edit?

No hard limit, but ~500 rows recommended for smooth editing. Large data needs a dedicated tool.
