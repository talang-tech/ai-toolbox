About this tool

CSS Unit Converter is a free online tool that helps frontend developers quickly convert between different CSS units. Supports px, em, rem, percentage(%), vw, vh, vmin, vmax, pt, ch, ex and other common CSS units. All conversions are done locally in your browser — no data uploaded, your privacy is protected.

Key Features

  • Convert between px, em, rem, %, vw, vh, vmin, vmax, pt, ch, ex units
  • Customizable base font size (default 16px)
  • Customizable viewport width and height
  • Shows full conversion chain (source → px → target)
  • One-click copy results
  • 100% browser-local, zero data upload

Frequently Asked Questions

Why do I need to set the base font size?

em and rem units are relative to the base font size. Browsers default to 16px, but you can adjust it based on your design requirements.

What are viewport dimensions for?

vw, vh, vmin, vmax and percentage units depend on viewport size. Set your viewport width and height based on your design mockup for accurate conversions.

What are ch and ex units?

ch (character width) and ex (character height) are font-relative units. ch is approximately the width of character 0, ex is approximately the height of lowercase x. We use half the base font size as an approximation.

Is my data uploaded to a server?

No. All conversions happen entirely in your browser. Your data never leaves your device.
