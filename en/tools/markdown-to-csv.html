Markdown Table to CSV

Convert Markdown tables to CSV format, with optional header export

About this tool

Free online Markdown Table to CSV converter — quickly convert Markdown tables to CSV format. Supports automatic separator row parsing, optional header retention. Ideal for data extraction, table migration, document data export, and GitHub README table to Excel.

Supports standard GFM table format, auto-aligns columns, handles pipe escaping. Generated CSV works directly in Excel, Google Sheets, or any database. 100% client-side — your data never leaves your browser.

Key Features

  • Paste Markdown table, one-click convert to CSV
  • Toggle header row inclusion
  • Auto-parses separator rows and column alignment
  • Handles pipe escaping and column padding automatically
  • One-click copy result
  • Auto-convert on input (Ctrl+Enter shortcut supported)
  • 100% client-side, no data upload

Frequently Asked Questions

What Markdown table formats are supported?

Standard GFM table format with separator rows (|---|).

Are headers preserved?

Yes, headers are preserved as the first CSV row by default.

How are commas in cells handled?

Fields containing commas are automatically wrapped in double quotes per CSV standards.

What if columns are misaligned?

Rows with fewer columns are auto-padded with empty values.

Is my data safe?

Absolutely. All data is processed locally in your browser. Nothing is uploaded to any server.
