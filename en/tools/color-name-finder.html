About this tool

Free online Color Name Finder tool. Enter any Hex or RGB color value to auto-match the closest CSS named color (148 standard named colors). Search color names by keyword or browse the complete CSS named color palette with live previews.

All processing is done locally in your browser.

Key Features

  • Input Hex or RGB to auto-match closest CSS color name
  • Browse 148 standard CSS named colors palette
  • Live color preview with one-click color name copy
  • Fast keyword filter for color names
  • Browser local processing, no data upload

Frequently Asked Questions

What color formats are supported?

Hex (#ff6347, #f63 shorthand) and RGB formats are supported.

How many CSS named colors exist?

CSS defines 148 named colors in total.

How does color matching work?

It uses Euclidean distance in RGB space to find the closest named color.

Are named colors supported in all browsers?

All 148 CSS named colors work in modern browsers.
