HTML Table Extractor

Extract table data from HTML pages, export as CSV/JSON/Markdown

Ctrl+Enter for quick extract

About this tool

HTML Table Extractor helps you extract table data from HTML <table> tags and convert to CSV, JSON, or Markdown format.

Use cases: Copy tables from web pages to Excel/databases, scrape statistical tables, compare multiple HTML tables, extract table data from emails/documents.

Supports colspan (merged cells). All processing happens locally in your browser.

Key Features

  • Extract data from HTML tags
  • Export to CSV, JSON, or Markdown table
  • Preview original table structure
  • Supports colspan (merged cells)
  • Auto-detect and extract multiple tables
  • Ctrl+Enter keyboard shortcut
  • 100% browser-local, no data upload

    • Frequently Asked Questions

    How do I get the HTML to extract?

    Open the web page, right-click on the table, select Inspect, copy the

    HTML code and paste it into the input.

    Does it support rowspan?

    Currently supports colspan only. Tables with rowspan may need manual adjustment.

    How are multiple tables ordered?

    In order of appearance in the HTML, separated by comments.

    Is data uploaded to a server?

    No. All parsing happens locally in your browser.

    What's the JSON output format?

    First row is used as headers, creating an array of objects with header names as keys.
