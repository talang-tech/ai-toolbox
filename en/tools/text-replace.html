Text Find & Replace

Batch find and replace text with regex and case options

Privacy note

This tool runs in your browser. Your input, files, JSON, JWT, images, PDFs, passwords, hashes, or text are not uploaded to an AI Toolbox server.

Basic analytics may record page views and conversion clicks, but user input and file content are not tracked.

About this tool

Free online find-and-replace tool running entirely in your browser. Supports plain text and regex replacement, with case-sensitive, global, and per-line options. Real-time preview of results and replacement count. Ideal for batch-editing configs, cleaning data, and format conversion.

All processing happens locally — your text is never uploaded, making it safe for sensitive content.

Key Features

  • Plain text and regex replacement
  • Case-sensitive option
  • Global or first-match toggle
  • Real-time preview of results
  • Replacement count statistics
  • Browser-local processing, safe and secure

Frequently Asked Questions

What regex syntax is supported?

JavaScript regex syntax is supported, including groups, quantifiers, and character classes. Use $1, $2 for capture group references in replacement.

Does it modify the original text?

No. The original text remains unchanged. Results appear in the output area on the right.

Is my text uploaded to a server?

No. All replacement happens locally in your browser, safe for sensitive content.
