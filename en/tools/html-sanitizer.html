HTML Sanitizer

Safely sanitize HTML, remove XSS vectors and malicious scripts

🔒 Privacy: All processing is local. No HTML upload.

About this tool

Free online HTML sanitizer tool. Safely clean HTML code by removing XSS vectors, malicious scripts, dangerous tags, and event handlers. Supports Safe mode (empties script content) and Strict mode (removes all unknown and script tags).

Whitelist-based approach ensures only safe HTML tags and attributes are allowed. All event handlers and javascript: protocol links are automatically removed.

Key Features

  • Remove XSS vectors (javascript:, data: and other dangerous protocols)
  • Remove all on* event handlers
  • Safe mode: preserve tag structure, empty script content
  • Strict mode: remove all unknown tags and script tags
  • Whitelist-based tag and attribute filtering
  • 100% local processing, no HTML upload

Frequently Asked Questions

What is XSS?

XSS (Cross-Site Scripting) is a security vulnerability where attackers inject malicious scripts into web pages. HTML sanitizer removes these.

What is the difference between Safe and Strict mode?

Safe mode empties script/style content but preserves tag structure. Strict mode completely removes unknown tags.

Which HTML tags are supported?

All standard safe HTML tags including headings, paragraphs, lists, tables, forms, media elements.

Are style attributes removed?

No. Legitimate style attributes are preserved, but all event handlers are removed.

Is my data safe?

Completely safe. All processing is done locally in your browser.

What are common use cases?

User input sanitization, rich text editor output filtering, HTML email security.
