JSON Sorter

Sort JSON keys and array elements alphabetically, with nested and custom order support

About this tool

Free online JSON sorter with multiple modes: alphabetically sort JSON object keys, sort array elements by letter or number, custom sort order. Automatically recurses into nested structures.

All processing happens locally in your browser. No data is uploaded.

Key Features

  • Sort JSON object keys alphabetically
  • Sort JSON array elements (text/numeric)
  • Recursive sort for nested structures
  • Case-sensitive and insensitive modes
  • One-click copy sorted result
  • Browser local processing, data stays safe

Frequently Asked Questions

Does sorting modify the original JSON?

No. Sorting only affects the output. Your original input stays unchanged.

What JSON size is supported?

As long as browser memory allows, files of several MB can be processed.

How are array elements sorted?

By default text alphabetically. Check 'Numeric sort' for numeric sorting.

Is data uploaded to server?

No. All processing happens locally in your browser.

Are nested objects sorted too?

Yes. Recursive sort mode handles nested objects and arrays at all levels.
