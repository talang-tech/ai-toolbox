About this tool

Free online CSS animation generator. Visually generate common @keyframes animations with 16 animation types including fade, slide, bounce, shake, rotate, pulse, heartbeat, zoom, flip and more.

Customize duration, easing, delay, iteration count, direction, and fill mode. Live preview with one-click copy of generated CSS.

All processing happens locally in your browser — no dependencies needed.

Key Features

  • 16 common animation effects: fade, slide, bounce, shake, rotate, etc.
  • Customizable animation parameters: duration, easing, delay, iteration, direction, fill mode
  • Live preview of animation
  • One-click copy generated CSS code
  • Pure CSS implementation, no JS dependencies needed
  • 100% local processing, no data upload

Frequently Asked Questions

How to use generated animations?

Copy the generated CSS and add the corresponding class name to your HTML element. For example, add class="anim-fadeIn" to apply the fade-in animation.

How to loop animation infinitely?

Select 'infinite' in the iteration count option, and the animation will play continuously.

Can I use multiple animations together?

Yes, but it's recommended to use one keyframe animation at a time. Multiple animations may conflict. You can supplement with CSS transitions.

Which browsers are supported?

All modern browsers support CSS @keyframes: Chrome, Firefox, Safari, Edge. IE 11+ also supports it, though some advanced easing functions may not work.

Is my data uploaded?

No. All animation code is generated locally in your browser. Your data never leaves your computer.
