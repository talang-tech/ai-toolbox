Frequently Asked Questions

What is ASCII?

ASCII (American Standard Code for Information Interchange) is a character encoding standard that uses 7 or 8 bits to represent 128 or 256 characters including letters, digits, punctuation, and control characters.

What's the difference between ASCII and Unicode?

ASCII defines only 128 (or 256) characters for English. Unicode supports over 140,000 characters from virtually all languages. ASCII is a subset of Unicode.

What is extended ASCII?

Extended ASCII uses 8-bit encoding (0-255), adding 128 extra characters beyond standard ASCII (0-127), including special symbols, box-drawing characters, and accented letters.

Does it support Chinese?

This tool focuses on ASCII. For Chinese and other Unicode characters, please use the Unicode Converter tool.

What are HTML entities?

HTML entities use &-prefixed sequences to represent special characters in HTML, like < for < and & for &.

Is my data safe?

Completely safe. All character encoding conversion is done locally in your browser.

What is \\uXXXX escaping?

\\uXXXX is a Unicode escape sequence used in JavaScript and JSON. \\u0041 represents 'A', \\u00A9 represents the copyright symbol ©, etc.
