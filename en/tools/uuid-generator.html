About this tool

This tool supports multiple unique identifier formats, all generated locally in the browser with zero network transfer.

UUID — 128-bit standard identifier: v4 (random), v7 (time-ordered), v1, v5.

ULID — 26-char Base32 Crockford encoded, time-sortable, shorter than UUID.

NanoID — 21-char URL-safe identifier (A-Za-z0-9_-).

CUID — Horizontally scalable short unique ID (~25 chars).

Snowflake — Twitter/X Snowflake-style 64-bit integer ID.

Key Features

Frequently Asked Questions

What's the difference between UUID and ULID?

UUID is 128-bit standard, ULID is also 128-bit but only 26 chars and time-sortable — shorter and more readable.

Why use NanoID over UUID?

NanoID is shorter (21 vs 36 chars), URL-safe, great for short URLs and ID fields.

What is a Snowflake ID?

Twitter's 64-bit integer ID containing timestamp + worker node + sequence, good for distributed DB primary keys.

Do these need internet to generate?

Not at all. All generation happens locally in your browser, zero data uploaded.
