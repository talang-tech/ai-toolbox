About this tool

Free URL Query Builder to visually add, edit and remove query parameters, then generate a full URL or query string. Supports parsing existing links, parameter encoding, repeated keys and UTM templates.

Great for API debugging, filter links and campaign tracking URLs. Everything runs locally in your browser.

Key Features

  • Parse query parameters from a full URL
  • Visually add/edit/remove params
  • Automatic URL encoding
  • Repeated parameter names supported
  • One-click UTM template
  • Copy full URL or query string
  • Browser-local processing, no upload

Frequently Asked Questions

Should I copy the leading question mark?

The tool provides both full URL and query string. The query string output does not include the question mark for easier use in code.

Are repeated parameter names supported?

Yes. Multiple params with the same key are preserved, for example tag=a&tag=b.

Can it generate UTM links?

Yes. Use the UTM template button and fill source, medium and campaign fields.
