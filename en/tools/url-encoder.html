About this tool

URL encoding (Percent Encoding) converts special characters in a URL to %XX format, ensuring the URL is correctly transmitted and parsed.

Useful for: URLs with non-ASCII characters, API calls, form submissions.

Key Features

  • URL encoding (percent encoding)
  • URL decoding
  • UTF-8 Chinese support
  • RFC 3986 standard
  • One-click copy result

Frequently Asked Questions

Why encode URLs?

URLs can only contain ASCII characters. Non-ASCII and special symbols need encoding for proper transmission.

Space encoded as + or %20?

%20 is standard. + is used in application/x-www-form-urlencoded format.

What's the difference between encodeURI and encodeURIComponent?

encodeURI doesn't encode URI reserved characters like :/?#[]@!$&'()*+,;=.
