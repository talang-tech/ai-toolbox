CSS Validator

Check CSS syntax errors, unclosed braces, unknown properties, duplicate selectors, missing units

About this tool

Free online CSS validator to help developers quickly check CSS code for syntax errors, best practice issues, and potential problems. Detects unclosed braces/parentheses, unknown CSS properties, duplicate selectors, missing length units, duplicate property declarations, invalid hex color values, empty rule definitions, and more.

100% client-side processing, your code never leaves your browser.

Key Features

  • Unclosed braces/parentheses/brackets detection
  • Unknown CSS property name check
  • Duplicate selector detection
  • Missing length unit warnings
  • Duplicate property declaration detection
  • Invalid hex color value check
  • Empty rule definition detection
  • Missing semicolon warnings
  • @import position check
  • 100% local processing, no data upload

Frequently Asked Questions

What errors can the CSS validator check?

It checks unclosed braces, unknown properties, duplicate selectors, missing units, invalid colors, empty rules, and other common CSS issues.

What's the difference between CSS validator and CSS minifier?

The validator checks code correctness and best practices, while minifiers format or compress CSS code.

Is my data uploaded to servers?

No. All CSS validation is done locally in your browser.

Does it support CSS custom properties?

Yes. Custom properties (--variable) are not flagged as unknown.

Does it support Sass/Less preprocessors?

No. Please compile preprocessor syntax to standard CSS first.

Does the result show line numbers?

Yes. Every error and warning includes the line number.

How do I copy the validation report?

Click the 'Copy Report' button to copy results to clipboard.

What should I do when errors are found?

Fix the CSS code based on the line numbers and suggestions, then re-validate.
