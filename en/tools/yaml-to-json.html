YAML to JSON Converter

Convert YAML config files to JSON format, supporting Docker Compose, K8s, and CI/CD configs

About this tool

Free online YAML to JSON converter for Docker Compose, Kubernetes, GitHub Actions, CI/CD, OpenAPI and other YAML config files. Supports basic data types, nested objects, arrays (lists), multi-line strings (block scalars), and comment filtering.

All conversion runs locally in your browser — your config content is never uploaded to a server. Note: this is a lightweight YAML parser for common config scenarios. It does not support YAML anchors/aliases, tags, or advanced merge keys. Use a dedicated YAML library for full spec support.

Key Features

  • Convert YAML to its equivalent JSON representation
  • Support nested objects and arrays (lists)
  • Support multi-line strings (block scalar - | >)
  • Automatically filters comments and empty lines
  • Browser-local processing, config data stays on your machine
  • Auto-converts as you type

Frequently Asked Questions

Is my config data safe?

This tool runs entirely in your browser. Your config is never sent to any server. It's safe to paste files containing secrets or API keys.

Does it support all YAML syntax?

It supports common config scenarios: key-value pairs, nested objects, arrays, multi-line strings, and comment filtering. It does NOT support anchors/aliases, tags, merge keys (<<), or complex multi-document YAML. Use js-yaml for full spec parsing.

What's the difference from the JSON to YAML tool?

JSON to YAML generates YAML from JSON. This tool does the reverse — converting YAML configs to JSON format for those who prefer or need JSON output.
