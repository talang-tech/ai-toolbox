Base Converter

Real-time conversion between binary, octal, decimal, hexadecimal

About this tool

Base conversion is fundamental in programming and computer science. This tool supports bidirectional real-time conversion between 2/8/10/16 bases.

Type in any value, the other three update automatically. BigInt support for large numbers.

Key Features

  • Binary ↔ Decimal ↔ Hexadecimal
  • Octal conversion support
  • Large number support
  • Real-time synchronized conversion
  • One-click copy any format

Frequently Asked Questions

Why hex uses A-F?

Using one character to represent 10-15 is more compact and standard among programmers.

How large numbers are supported?

JavaScript safe integer range (~16 decimal digits).

How to convert negative numbers?

Currently supports unsigned integers. Use two's complement for negatives.
