HTML Tag Reference

HTML5 tag reference with search, category filter, and attribute details

About this tool

Free online HTML5 tag reference for developers to quickly look up all standard HTML elements, their attributes, and usage guidelines. Supports search by tag name, filter by content category (text/forms/tables/media/interactive), with example code for each.

Covers: document structure (html/head/body), text semantics (p/h1/article), forms (input/select/form), tables (table/tr/td), media (img/video/audio), interactive elements (dialog/details), and more. All content is built into the page — no network requests.

Key Features

  • Complete standard HTML5 element collection
  • Real-time search by tag name
  • Category filter (text/forms/tables/media/interactive etc.)
  • Attribute list and descriptions for each tag
  • Example code and usage tips
  • One-click tag name copy
  • Fully static, no network requests
