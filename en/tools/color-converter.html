About this tool

Essential tool for web designers and frontend devs. Enter Hex color (#fff or #ffffff format) to auto-convert to RGB, or enter R/G/B values to auto-convert to Hex.

Live color preview, one-click copy.

Key Features

  • HEX hexadecimal to RGB
  • RGB to HEX hexadecimal
  • RGB to HSL
  • Real-time color preview
  • Opacity support
  • Color picker

Frequently Asked Questions

Are #000000 and #000 the same?

Yes, #RGB format is shorthand for #RRGGBB where each character repeats twice.

What is HSL?

Hue (0-360°), Saturation (0-100%), Lightness (0-100%).

How to represent opacity?

HEX uses #RRGGBBAA, RGB uses rgba(r, g, b, a).
