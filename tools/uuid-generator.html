UUID / ULID / NanoID 生成器

生成 UUID v4/v7、ULID、NanoID、CUID、Snowflake

关于这个工具

本工具支持多种唯一标识符格式，全部在浏览器本地生成，无需网络传输。

UUID — 128位标准标识符，v4（随机）、v7（时间排序）、v1、v5。

ULID — 26字符 Base32 Crockford 编码，时间可排序，比 UUID 更短。

NanoID — 21字符 URL 安全标识符（A-Za-z0-9_-）。

CUID — 水平缩放的短唯一 ID（约25字符）。

Snowflake — Twitter/X Snowflake 风格的 64 位整数 ID。

常见问题

UUID 和 ULID 有什么区别？

UUID 是 128 位标准，ULID 也是 128 位但只有 26 字符且时间可排序，更短更易读。

NanoID 比 UUID 好在哪？

NanoID 更短（21字符 vs 36字符），URL 安全，适合短链接、ID 字段。

Snowflake ID 是什么？

Twitter 设计的 64 位整数 ID，包含时间戳+工作节点+序列号，适合分布式数据库主键。

这些 ID 生成需要联网吗？

完全不需要。所有生成逻辑在浏览器中本地执行，不上传任何数据。
