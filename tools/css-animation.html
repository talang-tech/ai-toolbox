关于这个工具

免费的在线 CSS 动画生成器。可视化生成常用的 @keyframes 动画效果，包含淡入淡出、滑入滑出、弹跳、抖动、旋转、脉冲、心跳、缩放等 16 种动画类型。

可自定义持续时间、缓动函数、延迟、播放次数、方向和填充模式。实时预览动画效果，一键复制生成的 CSS 代码。

所有处理在浏览器本地完成，无需任何依赖。

  • 16 种常用动画效果：淡入淡出、滑动、弹跳、抖动、旋转等
  • 自定义动画参数：时长、缓动、延迟、次数、方向、填充模式
  • 实时预览动画效果
  • 一键复制生成的 CSS 代码

  • 完全本地处理，数据不上传

常见问题

如何使用生成的动画？

复制生成的 CSS 代码，在你的 HTML 元素上添加对应的 class 名即可。例如生成 'anim-fadeIn' 类，在元素上添加 class="anim-fadeIn"。

如何让动画循环播放？

在播放次数选项中选择 '无限循环（infinite）'，动画将持续播放。

可以同时使用多个动画效果吗？

可以。CSS 动画可以叠加，但建议一次只使用一个关键帧动画，多个动画可能产生冲突。你可以使用 CSS transition 来补充。

动画兼容哪些浏览器？

现代浏览器都支持 CSS @keyframes 动画，包括 Chrome、Firefox、Safari、Edge。IE 11 及以上版本也支持，但部分高级缓动函数可能不支持。

数据会上传到服务器吗？

不会。所有动画代码完全在浏览器本地生成，数据不会离开你的电脑。
