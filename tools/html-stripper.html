HTML 标签去除

从 HTML 中提取纯文本，去除 HTML 标签和样式

Ctrl+Enter

关于这个工具

免费的在线 HTML 标签去除工具。一键去除 HTML 代码中的所有标签、样式和脚本，提取纯净的文字内容。常用于：从网页复制内容时去掉格式污染、从邮件模板中提取文案、从富文本编辑器中获取纯文本。

支持三种模式：仅去除标签保留内容、去除标签及内容（如 script/style）、仅解码 HTML 实体。支持保留换行结构、合并多余空格。

所有处理在浏览器本地完成，HTML 代码不会上传到任何服务器。

主要功能

  • 一键去除所有 HTML 标签，保留纯净文字
  • 三种模式：仅去标签、去标签+内容、仅解码实体
  • 支持保留/去除换行结构
  • 支持合并多余空格
  • 自动解码 HTML 实体
  • 实时预览统计：字符数对比、压缩比例
  • Ctrl+Enter 快捷键执行
  • 浏览器本地处理，HTML 代码不上传

常见问题

HTML 标签去除和 HTML 编码转换有什么不同？

标签去除是删除 <div> 这样的标记保留文字；HTML 编码转换是将 &lt; 这样的实体转为正常字符。本工具同时支持这两种操作。

什么情况下需要用'去除标签+内容'模式？

当你想完全移除 script、style、noscript、svg 等标签及其内部内容时使用。

保留换行结构是什么意思？

开启后，<p>、<br> 等块级标签会替换为换行符，保留段落结构。

数据会上传到服务器吗？

不会。所有处理在浏览器本地完成。

支持多大量？

浏览器内存允许范围内均可处理。建议超过 10MB 的大文件分多次处理。
