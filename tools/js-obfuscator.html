JavaScript 混淆器

混淆 JavaScript 代码，支持变量重命名、字符串拆分、数字编码

🔒 隐私提示：所有处理在浏览器本地完成，代码不会上传到服务器。

关于这个工具

免费的在线 JavaScript 混淆器，帮助开发者保护前端 JS 代码。支持三种混淆等级：轻度（变量重命名+注释删除）、中度（追加字符串拆分）、重度（追加数字十六进制编码）。内置代码美化器，可一键还原格式。

适合：混淆前端业务逻辑、保护 API 密钥、代码安全审计、学习混淆原理。所有处理在浏览器本地完成，代码不上传服务器。

主要功能

  • 三种混淆等级：轻度/中度/重度
  • 变量名自动重命名为短名称
  • 字符串自动拆分拼接
  • 数字转十六进制编码
  • 注释和多余空白自动删除
  • 内置代码美化器，一键还原格式
  • 显示输入/输出大小和压缩比
  • Ctrl+Enter 快捷键快速混淆
  • 浏览器本地处理，代码不上传

常见问题

混淆后代码还能运行吗？

可以。混淆只改变变量名和格式，不改变逻辑。但重度混淆可能影响调试。

混淆能完全保护代码吗？

不能。JS 代码始终可以在浏览器中被查看。混淆增加逆向难度，但并非绝对安全。

三种等级有什么区别？

轻度：变量重命名+去注释；中度：追加字符串拆分；重度：追加数字十六进制编码。

数据会被上传到服务器吗？

不会。所有处理在浏览器本地完成。

能反向还原混淆的代码吗？

内置美化器可恢复格式，但变量名无法还原。

适合混淆什么类型的代码？

前端业务逻辑、API 密钥、配置对象、工具函数等。
