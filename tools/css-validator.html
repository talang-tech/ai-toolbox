CSS 验证器

检查 CSS 语法错误、未闭合括号、未知属性、重复选择器、缺失单位等

关于这个工具

免费的在线 CSS 验证器，帮助开发者快速检查 CSS 代码中的语法错误、最佳实践问题和潜在问题。支持检测未闭合的大括号/括号、未知 CSS 属性、重复选择器、缺少长度单位、重复属性声明、无效十六进制颜色值、空规则定义等常见问题。

所有处理在浏览器本地完成，代码不会上传到服务器。

主要功能

  • 未闭合大括号/括号/方括号检测
  • 未知 CSS 属性名检查
  • 重复选择器检测
  • 数值缺少长度单位警告
  • 重复属性声明检测
  • 无效十六进制颜色值检查
  • 空规则定义检测
  • 声明末尾缺少分号提醒
  • @import 位置检查
  • 完全本地处理，代码不上传

常见问题

CSS 验证器能检查哪些错误？

可以检查未闭合的括号、未知属性名、重复选择器、缺失单位、无效颜色值、空规则等常见 CSS 问题。

CSS 验证器和 CSS 压缩/美化有什么区别？

CSS 验证器用于检查代码正确性和最佳实践，而压缩/美化工具用于格式化或压缩 CSS 代码。

数据会上传到服务器吗？

不会。所有 CSS 验证完全在浏览器本地完成，代码不会离开你的设备。

支持 CSS 自定义属性吗？

支持。自定义属性（--variable）不会被标记为未知属性。

支持 CSS 预处理器如 Sass/Less 吗？

不支持预处理器语法。请先编译为标准 CSS 后再验证。

验证结果会显示行号吗？

会的。每个错误和警告都会标注对应的行号，方便定位问题。

如何复制验证报告？

点击「复制报告」按钮即可将验证结果复制到剪贴板。

检测到错误后如何使用？

根据行号和建议在输入区修改 CSS 代码后重新验证，直到没有错误为止。
