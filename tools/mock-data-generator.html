Mock 数据生成器

生成逼真的测试数据，支持姓名、邮箱、地址、公司等字段

关于这个工具

免费的 Mock 数据生成器，帮助开发者快速生成逼真的测试数据。支持姓名、邮箱、电话、地址、公司、职位、出生日期、ID、社保号、IP 地址、颜色、薪资等多种字段类型。可自由组合字段，选择生成数量，支持 JSON、CSV 和 Markdown 表格三种输出格式。

适用于软件开发测试、数据库填充、API 开发、UI 原型展示、数据迁移验证等场景。所有数据在浏览器本地生成，不会上传到任何服务器，保证数据安全。

主要功能

  • 支持 15 种字段类型：姓名、邮箱、电话、地址、公司、职位等
  • 三种输出格式：JSON、CSV、Markdown 表格
  • 自定义生成数量（1-1000 条）
  • 一键复制生成的测试数据
  • 所有数据在浏览器本地生成，零数据上传
  • 适用于开发测试、数据库填充、原型展示

常见问题

Mock 数据生成器的用途是什么？

用于快速生成测试数据，填充数据库、API 测试、UI 原型展示、数据迁移验证等开发场景。生成的不是真实数据，仅供测试使用。

支持哪些输出格式？

支持 JSON、CSV 和 Markdown 表格三种格式。JSON 适合 API 开发，CSV 适合导入电子表格，Markdown 表格适合文档展示。

最多可以生成多少条数据？

单次最多生成 1000 条记录。如果需要更多数据，可以多次生成。

数据会上传到服务器吗？

不会。所有数据完全在浏览器本地生成，不会上传到任何服务器，保证数据安全。

生成的电话号码是真实的吗？

所有电话号码和其他数据都是随机生成的，仅用于测试，不代表真实信息。

可以自定义生成逻辑吗？

目前支持内置的 15 种字段类型。如需自定义数据，可以选择 CSV 格式在 Excel 中编辑。

生成的信用卡号可以用吗？

信用卡号是随机生成的格式符合的测试号码，不能用于实际支付。仅供测试和演示使用。
