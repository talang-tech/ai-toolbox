HTML 表格提取器

从 HTML 页面提取表格数据，导出为 CSV/JSON/Markdown

Ctrl+Enter 快速提取

关于这个工具

HTML 表格提取器帮助你将包含 <table> 标签的 HTML 代码中的表格数据一键提取并转换为 CSV、JSON 或 Markdown 表格格式。

使用场景：从网页文档复制表格数据到 Excel/数据库、抓取网页上的统计表格、快速比较多个 HTML 表格、从邮件/文档中提取表格数据。

支持 colspan（跨列合并）处理。所有解析在浏览器本地完成，不上传任何数据。

主要功能

  • 从 HTML 标签提取表格数据
  • 支持导出为 CSV、JSON、Markdown 表格
  • 预览原始表格结构
  • 支持跨列合并 (colspan)
  • 自动检测多个表格分别提取
  • Ctrl+Enter 快捷键执行
  • 浏览器本地处理，数据不上传

    • 常见问题

    如何获取要提取的 HTML？

    在浏览器中打开网页，右键点击表格区域，选择「检查」(Inspect)，复制包含

    的 HTML 代码粘贴到输入框。

    支持 rowspan（跨行合并）吗？

    目前支持 colspan（跨列合并），不支持 rowspan。rowspan 的表格建议手动调整后再提取。

    提取多个表格时结果怎么排序？

    按在 HTML 中出现的顺序排列，每个表格之间用注释分隔。

    数据会上传到服务器吗？

    不会。所有解析在浏览器本地完成，不会上传任何 HTML 或表格数据。

    提取的 JSON 格式是怎样的？

    以第一行为表头构建对象数组，每行对应一个对象，表头作为键名。
