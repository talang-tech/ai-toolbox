CSS 压缩/美化

压缩和美化 CSS 代码，支持去除注释、缩短颜色值、精简属性，及代码格式化排版

关于这个工具

免费的在线 CSS 压缩与美化工具，支持将 CSS 样式表一键压缩（去除注释、空格、颜色值缩写、属性精简）或美化（格式化缩进、添加空格和换行，提升可读性）。

压缩功能可减小 CSS 文件体积 20-50%，适合生产环境部署。美化功能可将压缩后的 CSS 还原为可读格式。所有处理在浏览器本地完成，代码不会上传到服务器。

主要功能

  • 一键压缩 CSS 样式表
  • 一键美化/格式化 CSS
  • 去除所有 CSS 注释
  • 颜色值自动缩短（#RRGGBB → #RGB）
  • 去除多余空格和换行
  • 去除 0 值的单位
  • 去除小数末尾的 0
  • 实时统计：原大小/结果大小/减少比例
  • 复制结果一键粘贴
  • 零数据上传，浏览器本地处理

常见问题

CSS 压缩能减少多少体积？

通常可减少 20-50%，取决于原始代码的注释量和格式风格。

压缩后的 CSS 能直接用于生产吗？

可以。本工具只去除注释和空格，不改变 CSS 语义，适合生产环境。

支持 CSS 预处理器语法吗？

不支持预处理语法（Sass/Less/Stylus）。压缩前请先编译为纯 CSS。

颜色值缩写安全吗？

安全。#AABBCC 到 #ABC 是 CSS 标准缩写，所有浏览器兼容。

代码会被上传吗？

不会。所有处理在浏览器本地完成，代码不会上传到任何服务器。
