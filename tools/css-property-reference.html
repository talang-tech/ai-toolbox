常见问题

包含哪些 CSS 属性？

涵盖所有常用 CSS 属性，包括 CSS2.1 和 CSS3+ 属性。布局、盒模型、文字排版、颜色、背景、动画、变换、过渡、Flexbox、Grid、多列、列表、表格等。

如何查看属性详情？

在搜索框输入属性名，或点击分类标签过滤。结果列表会显示每个属性的语法、可选值、初始值、兼容性和示例代码。

支持浏览器兼容性查询吗？

支持。每个属性标注了兼容性级别：完全支持（all）、现代浏览器（modern）、有限支持（limited）、实验性（experimental）。

可以离线使用吗？

可以。所有数据直接嵌入在页面中，首次加载后即可离线使用。
