CSS 转 Tailwind CSS

将传统 CSS 属性转换为 Tailwind CSS 等效类名，加速 Tailwind 迁移

已转换 0 条属性

关于这个工具

免费的在线 CSS 转 Tailwind CSS 工具，帮助您快速将传统 CSS 属性转换为 Tailwind CSS 等效类名。支持颜色、间距、尺寸、Flexbox、Grid、Typography、Border、Shadow、Transition 等常用 CSS 属性到 Tailwind 类名的映射。

适合 从传统 CSS 迁移到 Tailwind 的前端开发者、Tailwind 初学者、代码重构场景。所有转换在浏览器本地完成，CSS 代码不会上传到服务器。

主要功能

  • 支持颜色、背景、文字颜色映射到 Tailwind 色值类
  • 间距（margin/padding/gap）映射到 Tailwind 间距类
  • 尺寸（width/height）映射到 Tailwind 尺寸类
  • Flexbox 布局属性映射到 Tailwind Flex 类
  • Grid 布局属性映射到 Tailwind Grid 类
  • Typography 属性映射到 Tailwind 文字类
  • Border、Shadow、Opacity、Transition 等属性映射
  • 一次输入多条 CSS 规则，批量转换
  • 一键复制转换结果
  • 完全本地处理，数据不上传

常见问题

哪些 CSS 属性可以转换？

支持颜色（color/background-color/border-color）、间距（margin/padding/gap）、尺寸（width/height）、Flexbox、Grid、Typography、Border、Shadow、Opacity、Transition、Display、Position 等常见属性。

转换准确吗？

颜色值会映射到最接近的 Tailwind 色值（如 #3b82f6 → blue-500）。间距值精确映射到 Tailwind 的 4px 基准（如 margin: 16px → m-4）。部分复杂的 CSS 组合可能需要手动调整。

支持自定义颜色吗？

会尝试映射到最近的 Tailwind 预设色值。如果颜色值与 Tailwind 色板不匹配，会输出生成的 Tailwind 任意值（如 text-[#ff5500]）。

数据安全吗？

完全安全。所有转换在浏览器本地完成，CSS 代码不会上传到任何服务器。

一次可以转换多少条规则？

没有限制。您可以输入多条 CSS 规则，工具会逐条转换并显示结果列表。

生成的类名可以直接使用吗？

生成的类名是标准的 Tailwind CSS 类名，可以直接在 HTML 中使用。但建议根据实际项目中的 Tailwind 配置进行验证。

支持 Tailwind 的变体前缀吗？

基础版本输出标准类名。您可以根据需要自行添加 hover:、md:、dark: 等变体前缀。

可以转换 CSS 文件吗？

可以复制 CSS 文件内容粘贴到输入框进行批量转换。支持常用 CSS 规则的解析。
