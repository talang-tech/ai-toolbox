URL 参数解析

拆解 URL 显示协议主机路径参数表

关于这个工具

将完整的 URL 拆解显示各个组成部分：协议、主机、端口、路径、查询参数、哈希值。

主要功能

  • 协议识别 (http/https)
  • 域名/主机提取
  • 端口号识别
  • 路径拆解
  • 查询参数表格化显示
  • 哈希片段提取

常见问题

什么是 URL 编码？

URL 中特殊字符用 % 加两位十六进制表示，确保正确传输。

查询参数顺序会影响解析吗？

不影响，参数是无序的键值对。

支持 IPv6 地址吗？

支持标准 IPv6 格式的 URL。
