XML 格式化/压缩

在线格式化、校验和压缩 XML，支持本地解析错误提示

隐私说明

这个工具在你的浏览器中运行。你输入的内容、文件、JSON、JWT、图片、PDF、密码、哈希或文本不会上传到 AI 工具盒子的服务器。

站点可能记录基础访问量和转化点击事件，但不会追踪用户输入内容或文件内容。

关于这个工具

免费的在线 XML 格式化、校验与压缩工具，适用于 SOAP 报文、Sitemap、SVG、配置文件、接口响应等场景。工具使用浏览器内置 DOMParser 在本地解析 XML，能提示解析错误，并输出缩进良好的 XML 或压缩后的单行版本。

所有 XML 文本只在你的浏览器中处理，不会上传到服务器，适合处理内部接口响应、配置和包含敏感字段的 XML 片段。

主要功能

  • 格式化 XML 并按 2/4 空格或 Tab 缩进
  • 压缩 XML 为紧凑单行
  • 使用浏览器 DOMParser 校验 XML
  • 提示解析错误和行列上下文
  • 适合 SOAP、Sitemap、SVG、配置文件
  • 浏览器本地处理，XML 内容不上传

常见问题

能格式化 SVG 吗？

可以。SVG 本质上是 XML，粘贴 SVG 源码后可以格式化或压缩。

能处理 SOAP 报文吗？

可以处理常见 SOAP XML 报文。由于工具在浏览器本地运行，内部接口响应不会上传。

压缩 XML 会改变内容吗？

压缩会移除标签之间的空白和换行，通常不改变元素和属性；如果 XML 文本节点依赖空白，请谨慎使用压缩。
