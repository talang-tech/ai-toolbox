常见问题

404 和 410 有什么区别？

404 表示资源临时不存在（未来可能恢复），410 表示资源已被永久删除。

301 和 302 有什么区别？

301 是永久重定向（搜索引擎会更新索引），302 是临时重定向。

500 错误通常是后端问题吗？

是的。500 Internal Server Error 表示服务器内部错误，通常是后端代码异常、数据库问题或配置错误。

502 Bad Gateway 是什么原因？

502 表示网关/代理服务器从上游服务器收到无效响应，常见于 Nginx 反向代理后端服务崩溃或超时。
