CSS 单位转换器

在 px、em、rem、%、vw、vh、vmin、vmax、pt、ch、ex 之间自由转换

关于这个工具

CSS 单位转换器是一款免费在线工具，帮助前端开发者在不同 CSS 单位之间快速转换。支持 px、em、rem、百分比(％)、vw、vh、vmin、vmax、pt、ch、ex 等常用 CSS 单位。所有转换均在浏览器本地完成，无需上传数据，保护您的隐私。

主要功能

  • 支持 px、em、rem、%、vw、vh、vmin、vmax、pt、ch、ex 单位互转
  • 可自定义基础字体大小（默认 16px）
  • 可自定义视口宽度和高度
  • 显示完整的转换链路（源单位 → px → 目标单位）
  • 一键复制结果
  • 纯浏览器本地处理，零数据上传

常见问题

为什么需要设置基础字体大小？

em 和 rem 单位是相对于基础字体大小计算的。通常浏览器默认是 16px，但您可以根据实际设计需求调整。

视口宽度和高度有什么作用？

vw、vh、vmin、vmax 和百分比单位依赖于视口尺寸。您可以根据您的设计稿设置视口宽度和高度，以获得准确的转换结果。

ch 和 ex 单位是什么？

ch（字符宽度）和 ex（字符高度）是相对于字体度量单位的。ch 约等于字符 0 的宽度，ex 约等于小写字母 x 的高度。这里我们使用基础字体大小的一半作为近似值。

数据会上传到服务器吗？

不会。所有转换完全在浏览器本地完成，您的数据不会离开您的设备。
