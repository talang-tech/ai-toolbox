URL Query Builder

可视化编辑 URL 查询参数，生成、解析和复制完整链接

参数名参数值操作

关于这个工具

免费的 URL Query Builder，可视化添加、编辑、删除查询参数，并自动生成完整 URL 和 query string。支持从现有链接解析参数、参数编码、重复键、UTM 参数模板。

适合调试 API、构造带筛选条件的链接、生成活动追踪 URL。所有处理在浏览器本地完成。

主要功能

  • 从完整 URL 解析查询参数
  • 可视化添加/编辑/删除参数
  • 自动 URL 编码
  • 支持重复参数名
  • 一键添加 UTM 模板
  • 复制完整 URL 或 query string
  • 浏览器本地处理，链接不上传

常见问题

Query string 前面的问号要复制吗？

工具会同时提供完整 URL 和 query string。query string 输出不包含问号，便于粘贴到代码里。

支持重复参数名吗？

支持。多个同名参数会按行保留，例如 tag=a&tag=b。

适合生成 UTM 链接吗？

适合。点击 UTM 模板后填写 source、medium、campaign 等字段即可。
