关于这个工具

JWT（JSON Web Token）是现代 API 最常用的认证方式。本工具支持纯前端解码 JWT 的 Header 和 Payload，自动显示过期时间。

常见问题

JWT 三个部分是什么？

Header（头部）、Payload（载荷）、Signature（签名），用点分隔。

可以解码 JWT 签名吗？

签名部分是二进制哈希，无法解码，但可以验证完整性。

JWT 是加密的吗？

不是。JWT 只是 Base64 编码，任何人都可以解码看到内容。
