JSON 验证器

验证 JSON 语法，高亮定位错误，格式化并显示行号

关于这个工具

免费的在线 JSON 验证器，快速检查 JSON 语法正确性。精确定位错误位置（行号、列号）、可视高亮错误片段。适合调试 API 或配置文件。

所有处理在浏览器本地完成，数据不会上传。

主要功能

  • 精确验证 JSON 语法，显示错误行号与列号
  • 一键格式化（缩进 2/4 空格可切换）
  • 一键压缩 JSON
  • 错误高亮显示，点击可定位
  • 显示 JSON 树深度和节点数统计
  • 完全本地处理，数据不上传

常见问题

JSON 验证和 JSON Schema 验证有什么区别？

JSON 验证检查语法是否正确（如缺括号、逗号）。JSON Schema 验证检查数据结构是否符合预定义的 Schema 规则。

支持大文件验证吗？

支持，但超 10MB 的文件建议用本地工具处理。

验证通过后一定能被后端解析吗？

JSON 语法通过即合法 JSON，可被任何标准解析器正确解析。
