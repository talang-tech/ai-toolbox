关于这个工具

免费的在线 JSON 深度合并工具。将两个 JSON 对象合并为一个，支持嵌套对象递归合并、数组合并去重。适用于配置文件合并、API 响应合并、国际化文件合并等场景。

支持将左侧 JSON 的字段合并到右侧 JSON 中，数组自动去重合并，嵌套对象递归合并，同名键值覆盖。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 深度合并两个 JSON 对象
  • 嵌套对象递归合并
  • 数组合并去重，不重复追加
  • 自动检测并报告 JSON 语法错误
  • 交换左右输入框，方便对比
  • 一键复制合并结果
  • 清晰的状态提示和统计信息
  • 浏览器本地处理，数据不上传

常见问题

合并规则是什么？

左侧 JSON 的字段会合并到右侧 JSON 中。如果同一键都存在，且值都是对象则递归合并；如果是数组则合并去重；其他情况右侧值覆盖左侧值。

支持多级嵌套合并吗？

支持。嵌套对象会递归合并，深度不限。

数组怎么合并？

数组合并后去重，不会重复添加相同元素。基本类型和对象数组都支持。

和 JSON Diff 有什么区别？

JSON Diff 是比较两个 JSON 的差异，JSON Merge 是将两个 JSON 合并为一个。

数据安全吗？

所有处理在浏览器本地完成，数据不会上传到任何服务器。
