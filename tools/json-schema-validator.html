JSON Schema 校验

根据 JSON Schema 标准校验 JSON 数据结构，支持 Draft-07

提示：Ctrl+Enter / Cmd+Enter 快速校验

关于这个工具

JSON Schema 校验工具帮助你根据 JSON Schema 标准（Draft-07）检查 JSON 数据是否符合预期的结构和约束。支持类型检查、required 属性、pattern 正则匹配、enum 枚举、minimum/maximum 范围、array items 与 uniqueItems、allOf/anyOf/oneOf/if-then-else、format（email/uri/date-time/uuid/ipv4/hostname）、additionalProperties 等多种校验规则。

无论是 API 响应校验、配置文件验证还是数据测试，这个工具都能精准定位不符合 Schema 的字段和原因。

所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • 支持 JSON Schema Draft-07 核心规范
  • 类型检查：string、number、integer、object、array、boolean、null
  • 字符串约束：minLength、maxLength、pattern、format（email/uri/uuid 等）
  • 数值约束：minimum、maximum、multipleOf
  • 数组约束：minItems、maxItems、uniqueItems、contains
  • 条件校验：allOf、anyOf、oneOf、not、if-then-else
  • 对象约束：required、properties、additionalProperties、dependencies
  • 精准错误定位，显示具体路径和原因
  • Ctrl+Enter 快捷键快速校验
  • 纯本地处理，数据零上传

常见问题

支持 JSON Schema 哪个版本？

支持 JSON Schema Draft-07（2019-09 的大部分核心功能）。Draft-2020-12 的部分新功能如 prefixItems 暂不支持。

校验规则能覆盖什么场景？

日常常见的 API 校验、配置验证、数据测试都能覆盖。支持 type、required、pattern、format、enum、数值范围、数组约束、条件式（if-then-else）等。

数据会被上传到服务器吗？

不会。所有处理 100% 在浏览器本地执行，数据不会离开你的设备。

最大支持多大 JSON？

受浏览器内存限制，建议在几百 KB 以内。超大 JSON（数 MB）可能出现卡顿。

和 JSON 格式化工具什么区别？

JSON 格式化侧重格式化和压缩；JSON Schema 校验侧重根据 Schema 验证数据结构是否正确，两者互补使用效果更佳。

如何快速使用？

在 Schema 或数据输入框按 Ctrl+Enter（Mac: Cmd+Enter）即可快速校验。
