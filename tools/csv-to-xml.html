CSV 转 XML

CSV 表格数据一键转换为结构化的 XML 文件，支持自定义元素名称

关于这个工具

免费的在线 CSV 转 XML 工具。将 CSV 表格数据一键转换为格式化的 XML 文档。

  • 自定义根元素名称（默认 root）
  • 自定义行元素名称（默认 row）
  • 支持逗号/制表符/分号/竖线分隔符
  • 首行作表头，自动生成字段元素名
  • 无表头模式自动生成 col1, col2...
  • 自动 XML 转义
  • 2 空格/4 空格/紧凑缩进可选

所有处理在浏览器本地完成，数据不会离开你的设备。

主要功能

  • CSV 一键转换为结构化 XML
  • 自定义根元素和行元素名称
  • 支持多种分隔符
  • 首行表头自动生成字段名
  • 无表头模式自动生成列名
  • 自动 XML 转义
  • 可配置缩进
  • 一键复制或下载
  • 浏览器本地处理

常见问题

支持哪些分隔符？

逗号、制表符、分号、竖线。

表头中的特殊字符怎么办？

工具会自动转义为有效的 XML 名称。

数据会上传吗？

不会。全部在浏览器本地处理。
