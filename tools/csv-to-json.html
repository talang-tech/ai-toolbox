CSV ↔ JSON 互转

CSV 数据转 JSON 格式，支持分隔符选择、表头配置、嵌套对象生成

关于这个工具

免费的在线 CSV 转 JSON 工具。将 CSV 表格数据一键转换为格式化的 JSON 数组。支持：

  • 自定义分隔符（逗号、制表符、分号、竖线等）
  • 首行作为表头 / 无表头模式
  • 2 空格/4 空格/紧凑缩进可选
  • 自动类型推断（数字、布尔值、null）
  • 点号分隔表头支持嵌套 JSON 结构

典型场景：API 数据格式转换、数据库导出数据转 JSON、ETL 流水线预处理、配置文件格式迁移。

所有处理在浏览器本地完成，数据不会离开你的设备。

常见问题

CSV 中的引号如何处理？

支持标准 CSV 引号转义：双引号包裹含分隔符或换行的字段，双引号自身用 "" 转义。

支持超大 CSV 文件吗？

完全取决于浏览器性能。建议 5000 行以内的 CSV 可流畅转换，所有处理均在本地进行。

自动类型推断可靠吗？

纯数字字段转为 number，'true'/'false' 转为 boolean，空字段转为 null。如需保持字符串，可在 CSV 中用引号包裹。

点号和 JSON 嵌套结构怎么用？

如表头为 'user.name' 和 'user.email'，会自动生成嵌套对象 {user: {name: ..., email: ...}}。

数据会上传到服务器吗？

不会。所有转换在浏览器本地完成，数据不离开你的设备。

支持反向转换（JSON 转 CSV）吗？

此工具仅支持 CSV→JSON。反向转换请使用 JSON 转 CSV 工具。
