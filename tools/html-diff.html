HTML 对比

比较两段 HTML 的差异，高亮新增/删除/修改的内容，支持结构和属性对比

差异结果

关于这个工具

免费在线 HTML 差异比较工具。将两段 HTML 内容进行逐行/逐结构对比，以绿色高亮新增内容、红色高亮删除内容。特别适合：

  • 前端开发：对比模板文件不同版本间的结构性变化
  • 代码 Review：HTML 修改前后的差异审查
  • CMS 内容管理：查看文章编辑前后的变化
  • 渲染对比：验证 HTML 模板渲染结果

支持纯文本行对比和 HTML 结构化对比两种模式。所有处理在浏览器本地完成，数据不上传。

主要功能

  • 两段 HTML 差异高亮对比
  • 逐行对比模式（LCS 算法）
  • HTML 结构对比模式
  • 绿色高亮新增、红色高亮删除
  • 带行号显示，轻松定位变更
  • 快速复制差异结果
  • 清晰的视觉分隔和状态提示
  • 浏览器本地处理，数据不上传

常见问题

逐行对比和结构对比有什么区别？

逐行对比比较两段 HTML 每行文本的差异（类似 git diff），结构对比比较 DOM 元素结构的差异（忽略缩进和空白调整）。

对比结果可以复制吗？

可以，差异结果区域的内容可以直接选中复制，目前暂不支持一键复制差异。

支持大文档吗？

支持，但由于所有处理在浏览器本地完成，过大的文档可能导致浏览器响应变慢。建议对比 500 行以内的 HTML。

数据会上传吗？

不会，所有对比在浏览器本地完成，数据不会上传到任何服务器。
