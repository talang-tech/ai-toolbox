CSS 前缀添加器

为 CSS 属性自动添加 -webkit-、-moz-、-ms-、-o- 浏览器前缀

🔒 隐私提示：所有处理在浏览器本地完成，CSS 代码不会上传到服务器。

关于这个工具

免费的在线 CSS 浏览器前缀添加器。自动为 CSS 属性添加 -webkit-、-moz-、-ms-、-o- 浏览器供应商前缀，确保 CSS3 新特性（如 transform、animation、transition、flexbox、grid、mask、filter 等）在旧版浏览器中正常工作。

支持 60+ 常见需要前缀的 CSS 属性，支持 @keyframes 规则前缀化，支持 gradient 等函数值前缀化。所有处理在浏览器本地完成，CSS 代码不会上传到服务器。

主要功能

  • 自动添加 -webkit-、-moz-、-ms-、-o- 浏览器前缀
  • 支持 transform、animation、transition 等 60+ CSS 属性
  • 支持 @keyframes 规则前缀化
  • 支持 gradient 函数值前缀处理
  • 支持 flexbox、grid 等布局属性前缀
  • 完全本地处理，CSS 代码不上传服务器

常见问题

为什么要添加 CSS 浏览器前缀？

不同浏览器引擎对 CSS3 新特性的实现阶段不同，需要添加供应商前缀来确保兼容性。

支持哪些 CSS 属性？

支持 transform、animation、transition、flexbox、grid、mask、filter 等 60+ 属性。

支持 @keyframes 吗？

支持。@keyframes 规则会自动生成 -webkit-、-moz-、-o- 前缀版本。

支持 gradient 值前缀吗？

支持。linear-gradient、radial-gradient、conic-gradient 等函数值会自动添加 -webkit- 前缀。

数据安全吗？

完全安全。所有 CSS 处理在浏览器本地完成，代码不会上传到服务器。

和 Autoprefixer 有什么区别？

功能类似，但本工具完全在浏览器本地运行，无需安装任何软件或依赖。
