HTML 转纯文本

从 HTML 中提取纯文本，去除标签和样式

关于这个工具

免费的在线 HTML 转纯文本工具。快速从 HTML 中提取干净文本，自动去除所有 HTML 标签、样式、脚本。支持保留链接和标题标记。

适合从网页内容中提取文字、整理邮件内容、清理复制粘贴的富文本格式。所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • 一键从 HTML 中提取纯文本
  • 自动去除 script/style/svg 标签
  • 可选择保留链接（显示为 文本(URL) 格式）
  • 可选择保留标题标记（# 格式）
  • 显示字符缩减率
  • 完全本地处理，数据不上传

常见问题

HTML 转纯文本和去除标签有什么区别？

基本一致，但 HTML 转纯文本更智能：会处理块级元素自动换行、保留链接和标题结构、解码 HTML 实体。

支持哪些 HTML 版本？

支持所有标准 HTML，包括 HTML5 和 XHTML。

数据会上传到服务器吗？

不会。所有处理完全在浏览器本地完成，你的数据不会离开你的电脑。

为什么转换后有很多空行？

空行来自 HTML 中的块级元素（段落、div、标题等），这是为了保持可读性。你可以手动删除多余空行。
