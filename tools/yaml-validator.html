YAML 语法验证器

深度检查 YAML 语法错误，检测重复键、缩进问题、无效值类型和常见配置陷阱

🔒 隐私提示：所有处理在浏览器本地完成，数据不会上传到服务器。

关于这个工具

免费的在线 YAML 语法验证器。深度检查 YAML 配置文件的语法问题，包括缩进错误、重复键、缺少冒号、无效值类型、未闭合引号、列表缩进不一致等常见问题。

区别于 YAML 格式化工具，本工具专注于问题检测和错误定位，针对每个问题给出具体行号和修复建议。适合 Docker Compose、Kubernetes、Ansible、GitHub Actions、OpenAPI 等配置文件的调试和排查。

所有处理在浏览器本地完成，配置内容不会上传到服务器。

主要功能

  • 检测 Tab 缩进（YAML 应使用空格）
  • 检测奇数缩进和层级不一致
  • 检测重复键（同层级相同键名）
  • 检测缺少冒号和值
  • 检测未闭合的引号
  • 检测无效的布尔值、数字和空值格式
  • 检测列表缩进不一致
  • 每个问题附带行号和修复建议
  • 一键复制错误报告
  • 浏览器本地处理，配置内容不上传

常见问题

YAML 验证器和格式化器有什么区别？

格式化器侧重让 YAML 变整洁；验证器专注发现和定位问题。已经格式良好的 YAML 但运行报错，用验证器检查。如果 YAML 很乱，先用格式化器。

支持 Docker Compose 和 Kubernetes 的 YAML 吗？

支持。Docker Compose、Kubernetes、Ansible、GitHub Actions、OpenAPI 的 YAML 配置都可以用本工具验证常见语法问题。

能检测出所有 YAML 错误吗？

本工具是轻量级语法检查器，覆盖缩进、重复键、引号、格式等最常见问题。复杂结构如锚点、标签、多行块标量可能只做保守检查。

配置中的密钥会被上传吗？

不会。所有验证在浏览器本地执行，输入内容不会上传到服务器。

为什么缩进问题最重要？

YAML 对缩进极其敏感。线上配置错误 90% 以上是缩进问题：Tab 和空格混用、缩进层级不一致、列表缩进错位等。
