字符串转义/反转义

JSON、JavaScript、URL、HTML 字符串转义与反转义

关于这个工具

免费的在线字符串转义/反转义工具，支持 JSON 字符串、JavaScript 字符串、URL 编码、HTML 实体、Unicode \uXXXX 等常见格式。适合处理接口参数、日志文本、代码片段、配置文件中的特殊字符。

常见问题

JSON 转义和 JavaScript 转义有什么区别？

JSON 字符串会严格使用 JSON.stringify 的规则；JavaScript 模式会额外处理常见反斜杠转义，适合代码片段和日志。

能处理中文和 Emoji 吗？

可以。Unicode 模式会把非 ASCII 字符转换为 \uXXXX，遇到 Emoji 等代理对也会保持可逆。

内容会上传吗？

不会。所有转义和反转义都在浏览器本地完成。
