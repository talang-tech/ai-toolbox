关于这个工具

免费的在线 HTML5 标签参考手册，帮助开发者快速查找所有标准 HTML 元素的用途、属性和使用规范。支持按标签名称搜索、按内容分类过滤（文本/表单/表格/媒体/交互等），每项附带示例代码和说明。

涵盖：文档结构（html/head/body）、文本语义（p/h1/article）、表单（input/select/form）、表格（table/tr/td）、媒体（img/video/audio）、交互元素（dialog/details）等。所有内容内置在页面中，无需网络请求。

主要功能

  • 完整收录所有标准 HTML5 元素
  • 按标签名称实时搜索
  • 按内容分类过滤（文本/表单/表格/媒体/交互等）
  • 每个标签附带属性列表和说明
  • 显示示例代码和用法提示
  • 一键复制标签名称
  • 纯静态页面，加载即用，无网络请求
