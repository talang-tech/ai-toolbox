CSV 转 Markdown 表格

将 CSV 数据快速转换为 Markdown 表格格式，支持预览、复制和下载

预览

关于这个工具

免费在线 CSV 转 Markdown 表格工具。将剪贴板中的 CSV 数据、Excel 导出的 CSV 文件、数据库查询结果等一键转换为整洁的 Markdown 表格格式。支持自定义分隔符、表头/无表头模式、列对齐方式。

  • 开发者：将数据库导出结果直接转为 Markdown 放入 README
  • 写作者：将表格数据转为 Markdown 嵌入博客或文档
  • 分析师：将统计数据转为易于分享的格式化表格

所有转换在浏览器本地完成，数据不会上传。

主要功能

  • 一键 CSV 转 Markdown 表格
  • 支持逗号、制表符、分号分隔符
  • 表头/无表头模式
  • 左/中/右列对齐
  • 自动处理引号包裹的数据
  • 实时 HTML 表格预览
  • 复制或下载 .md 文件
  • 浏览器本地处理，数据不上传

常见问题

支持 Excel 文件吗？

不支持直接上传 Excel 文件，建议在 Excel 中另存为 CSV（逗号分隔）格式后再使用此工具。

数据会泄露吗？

不会，所有处理在浏览器本地完成，数据不会上传到任何服务器。

CSV 中有引号怎么办？

工具会自动处理引号包裹的字段，包括字段内包含逗号或换行的情况。
