YAML 转 JSON

将 YAML 配置文件一键转换为 JSON 格式，支持 Docker/K8s 配置

关于这个工具

免费的 YAML 转 JSON 在线工具，适合将 Docker Compose、Kubernetes、GitHub Actions、CI/CD、OpenAPI 等 YAML 配置文件转换为 JSON 格式。支持基本数据类型、嵌套对象、数组（列表）、多行字符串（block scalar），以及注释过滤。

所有转换在浏览器本地完成，你的配置内容不会上传到服务器。注意：本工具为轻量级 YAML 解析器，覆盖常见配置场景，不支持 YAML 锚点/别名、标签、高级 merge key 等复杂语法。如需完整 YAML 支持，请使用专用 YAML 库。

主要功能

  • 将 YAML 转换为其等价的 JSON 格式
  • 支持嵌套对象和数组（列表）结构
  • 支持多行字符串（Block Scalar - | >）
  • 自动过滤注释和空行
  • 浏览器本地处理，配置不上传
  • 输入自动转换，无需点击按钮

常见问题

上传后我的配置安全吗？

本工具完全在浏览器本地运行，你的配置内容不会发送到任何服务器。可以放心粘贴包含密钥或敏感信息的 YAML 文件。

支持所有 YAML 语法吗？

支持常见配置场景：键值对、嵌套对象、数组、多行字符串、注释过滤。不支持锚点/别名、标签（!!str 等）、merge key（<<）、复杂 multi-document。如果需要完整 YAML 解析，建议使用 js-yaml 等专用库。

和 JSON 转 YAML 工具有什么区别？

JSON 转 YAML 是将 JSON 数据生成 YAML 格式。这个工具方向相反，把 YAML 配置转成 JSON，适合偏好 JSON 格式或需要 JSON 输出的场景。
