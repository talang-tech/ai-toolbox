HTML 验证器

检查 HTML 标签嵌套、重复 ID、弃用标签、可访问性问题和最佳实践

关于这个工具

免费的在线 HTML 验证器，帮助开发者快速检查 HTML 代码中的语法错误、结构问题和最佳实践违规。支持检测标签嵌套错误、未闭合标签、重复 ID、弃用标签/属性、内联事件处理器、可访问性问题（缺少 alt/lang）、缺失 DOCTYPE/字符集声明等。

所有处理在浏览器本地完成，代码不会上传到服务器。

主要功能

  • HTML 标签嵌套正确性检查
  • 未闭合标签检测
  • 重复 ID 属性检测
  • 已弃用标签和属性检测
  • 内联事件处理器提醒
  • 可访问性检查（alt/lang/标签）
  • 缺失 DOCTYPE/字符集/标题检测
  • 空 href/src 属性检查
  • 未引用属性值检测
  • label 标签关联性检查
  • 完全本地处理，代码不上传

常见问题

HTML 验证器能检查哪些内容？

可以检查标签嵌套错误、未闭合标签、重复 ID、弃用标签和属性、内联事件处理器、可访问性问题、缺失 DOCTYPE/字符集/标题等。

HTML 验证器和 W3C 验证器有什么区别？

功能类似，但本工具完全在浏览器本地运行，无需将代码发送到服务器，适合调试包含敏感内容的 HTML。

数据会上传到服务器吗？

不会。所有 HTML 验证完全在浏览器本地完成，代码不会离开你的设备。

支持 HTML5 吗？

支持。工具基于 HTML5 规范，识别所有标准 HTML5 标签和自闭合标签。

支持 SVG 和 MathML 吗？

支持。SVG 和 MathML 标签不会被错误标记为未知标签，且允许自闭合语法。

验证结果会显示行号吗？

会的。每个错误和警告都会标注对应的行号，方便定位问题。

如何修复验证错误？

根据行号建议在输入区修改 HTML 代码，然后重新验证直到通过。

支持框架模板（如 Vue/React）吗？

支持基本的 HTML 部分验证。但模板语法（如 v-if、{{ }}）可能被标记为未知标签，建议验证纯 HTML 部分。
