CSV 转 SQL INSERT

将 CSV 数据转换为 SQL INSERT 语句，支持自定义表名、列映射和批量插入

🔒 隐私提示：所有数据在浏览器本地处理，不会上传到服务器。

关于这个工具

免费的在线 CSV 转 SQL INSERT 语句工具，将 CSV 数据快速转换为 SQL INSERT 语句。支持自定义表名、列映射、批量插入、自动类型推断、NULL 值处理、字符串转义。适合 数据库迁移、数据导入、测试数据生成等场景。

支持 MySQL、PostgreSQL、SQLite 等主流数据库语法。所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • CSV 数据一键转换为 SQL INSERT 语句
  • 自定义表名和列名
  • 支持批量插入（INSERT INTO ... VALUES (...)）格式
  • 单行插入格式（每行一个 INSERT）
  • 自动类型推断（数字、布尔值、NULL、字符串）
  • 字符串自动转义（单引号、反斜杠）
  • 支持带表头和不带表头的 CSV
  • 可配置分隔符（逗号、制表符、分号）
  • 输出行数统计
  • 完全本地处理，数据不上传

常见问题

CSV 转 SQL 支持哪些数据库？

生成的 SQL 语句兼容 MySQL、PostgreSQL、SQLite、MariaDB 等主流数据库。不同数据库的语法差异会自动适配。

批量插入和单行插入有什么区别？

批量插入使用一条 INSERT 语句插入多行数据（如 INSERT INTO t VALUES (...), (...), (...)），适合大量数据导入。单行插入每行生成一条 INSERT 语句。

CSV 文件中的空值怎么处理？

空字段会被转换为 SQL 的 NULL。如果希望保留空字符串，可以勾选对应的选项。

支持带表头和不带表头的 CSV 吗？

都支持。带表头的 CSV 会自动读取列名，不带表头的需要手动指定列名。

数据安全吗？

完全安全。所有数据在浏览器本地处理，不会上传到任何服务器。
