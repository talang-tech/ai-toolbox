随机字符串生成

自定义长度和字符集生成密码/随机字符串

关于这个工具

生成安全的随机字符串，用于密码、API Key、Token、文件名等。

主要功能

  • 自定义长度（1-512位）
  • 可选大小写字母
  • 可选数字
  • 可选特殊符号
  • 排除易混淆字符选项
  • 一键复制

常见问题

和密码生成器有什么区别？

这个工具更通用，适合生成 API Key、Token、文件名等各种随机字符串。

生成的是真随机吗？

使用浏览器的 crypto.getRandomValues()，是密码学安全的随机数。

可以生成包含中文的吗？

目前只支持 ASCII 字符集。
