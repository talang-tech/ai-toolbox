URL 编解码

URL 编码与解码，处理特殊字符和中文

关于这个工具

URL 编码（也叫 Percent Encoding）将 URL 中的特殊字符转换为 %XX 形式，确保 URL 在传输过程中不被误解析。

常用于：处理含中文或特殊字符的 URL、API 调用、表单提交。

主要功能

  • URL 编码（百分号编码）
  • URL 解码
  • 支持 UTF-8 中文
  • RFC 3986 标准
  • 一键复制结果

常见问题

为什么 URL 需要编码？

URL 只能包含 ASCII 字符，非 ASCII 字符和特殊符号需要编码才能正确传输。

空格编码成 + 还是 %20？

标准是 %20，application/x-www-form-urlencoded 格式中空格用 +。

encodeURI 和 encodeURIComponent 有什么区别？

encodeURI 不编码 :/?#[]@!$&'()*+,;= 这些 URI 保留字符。
