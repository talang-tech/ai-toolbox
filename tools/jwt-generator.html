关于这个工具

免费在线 JWT（JSON Web Token）生成器。支持 HS256 / HS384 / HS512 签名算法，可自定义 Header 和 Payload，自动添加 iat 和 exp 时间戳。

所有签名计算在浏览器端通过 Web Crypto API 安全完成，密钥不会上传到服务器。

生成的 Token 可直接用于 API 认证测试、开发调试等场景。

主要功能

  • 支持 HS256 / HS384 / HS512 签名算法
  • 可编辑 Header 和 Payload JSON
  • 支持自动添加 iat（签发时间）和 exp（过期时间）
  • 使用 Web Crypto API 纯前端签名，密钥不上传
  • 实时预览生成的 Token 结构，一键复制

常见问题

JWT 和普通 Token 有什么区别？

JWT 是自包含的 Token 格式，包含 JSON 格式的声明信息（claims），可以携带用户身份、权限等数据。

密钥安全吗？

所有签名计算在浏览器内通过 Web Crypto API 完成，密钥不会被传输到任何服务器。

HS256 和 RS256 有什么区别？

HS256 使用同一个密钥签名和验证（对称加密），适合内部使用。RS256 使用公私钥对，适合跨系统认证。

token 可以用于生产环境吗？

本工具生成的 token 建议用于开发调试。生产环境应使用服务端 JWT 库生成和管理 token。

支持不对称加密（RS/ES）吗？

当前版本支持 HS256/HS384/HS512 对称签名算法。不对称加密建议使用服务端 JWT 库生成。
