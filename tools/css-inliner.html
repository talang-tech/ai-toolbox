CSS 内联转换器

将 HTML 中的 CSS 样式规则内联到每个元素的 style 属性中，用于邮件 HTML

🔒 隐私提示：所有处理在浏览器本地完成，数据不会上传到服务器。

关于这个工具

免费的在线 CSS 内联转换工具。将 HTML 中 <style> 标签定义的 CSS 规则自动内联到每个元素的 style 属性中，解决邮件客户端（如 Outlook、Gmail）不支持外部和嵌入式样式的问题。

支持 class 和 id 选择器、基础媒体查询、伪类（hover/active 等）作为单独属性保留。适合邮件营销、HTML 邮件模板开发、电子邮件兼容性处理。

所有处理在浏览器本地完成。

主要功能

  • 自动将 <style> 块中的 CSS 内联到 HTML 元素
  • 支持 class 和 id 选择器匹配
  • 支持媒体查询保留为独立样式块
  • 支持伪类（:hover、:active 等）保留
  • 一键复制或下载内联后的 HTML
  • 完全本地处理，数据不上传

常见问题

为什么要内联 CSS？

多数邮件客户端（Outlook、Gmail、Yahoo Mail）不支持 <style> 标签中的 CSS，只能识别内联 style 属性。内联后邮件在各种客户端中显示一致。

支持哪些 CSS 选择器？

支持 class（.class）、id（#id）、标签选择器（div、p）。复杂选择器如 :nth-child、:not() 不支持。

伪类如何处理？

伪类（:hover、:active、:focus 等）会保留在 <style> 块中，因为内联样式不支持伪类。同时生成基础内联样式作为回退。

媒体查询会被删除吗？

不会。媒体查询会保留在独立的 <style> 块中，不会内联，以确保响应式邮件在支持媒体查询的客户端中正常工作。

数据安全吗？

完全安全。所有处理在浏览器本地完成，没有数据上传到服务器。

支持复杂的 CSS 框架吗？

支持基础的 CSS 框架（如 Bootstrap 的部分类）。但过于复杂的选择器组合或 CSS 函数可能无法完全解析。
