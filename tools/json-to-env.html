JSON 转 .env 环境变量

将 JSON 对象转换为 .env 格式的环境变量文件，支持扁平化与嵌套展开

🔒 隐私提示：所有数据在浏览器本地处理，不会上传到服务器。

关于这个工具

免费的在线 JSON 转 .env 环境变量工具，将 JSON 配置对象快速转换为标准 .env 格式文件。支持扁平化展开、嵌套对象自动连缀、数组序列化、值类型推断。适合 Docker 部署、CI/CD 流水线、Node.js/React 项目配置等场景。

支持大小写转换（保留原样/全大写/驼峰转下划线大写），可选择是否用引号包裹字符串值。所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • JSON 对象一键转换为 .env 格式
  • 扁平化模式：展开嵌套层级（如 app.port=3000）
  • 嵌套对象连缀模式：保留路径结构为键名
  • 大小写转换：保留原样 / 全大写 / 驼峰转下划线大写
  • 数组自动序列化为 JSON 字符串
  • 布尔值/数字/空值自动类型推断
  • 可选引号包裹字符串值
  • 一键复制 .env 内容
  • 完全本地处理，数据不上传

常见问题

JSON 转 .env 支持哪些格式？

支持任何有效的 JSON 对象输入。嵌套对象可以扁平化展开，数组会序列化为 JSON 字符串。

扁平化模式和嵌套模式有什么区别？

扁平化模式将嵌套键用点号连接（如 app.port=3000），嵌套模式将整个 JSON 对象序列化为一行。推荐使用扁平化模式。

环境变量名可以自动转大写吗？

可以。选择"全大写"模式，所有键名会自动转为大写字母（如 appPort → APPPORT）。选择"驼峰转下划线"模式，会转为 APP_PORT 格式。

生成的 .env 文件可以直接用于 Docker 吗？

可以。生成的格式符合 .env 文件规范，可以直接用于 docker-compose 或 Node.js 的 dotenv 包。

数据安全吗？

完全安全。所有数据在浏览器本地处理，不会上传到任何服务器。
