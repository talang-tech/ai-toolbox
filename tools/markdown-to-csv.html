Markdown 表格转 CSV

将 Markdown 格式表格转换为 CSV 文件，支持导出表头

关于这个工具

免费的在线 Markdown 表格转 CSV 工具，将 Markdown 格式表格快速转换为 CSV 文件。支持自动解析分隔行、保留或移除表头。适合 数据提取、表格迁移、文档数据导出、GitHub README 表格转 Excel 等场景。

支持标准 GFM 表格格式，自动对齐列数，处理管道符转义。转换后的 CSV 可直接在 Excel、Google Sheets 或数据库中使用。所有处理在浏览器本地完成，数据不会上传。

主要功能

  • 粘贴 Markdown 表格，一键转换为 CSV 格式
  • 支持是否包含表头输出
  • 自动解析分隔行和列对齐
  • 自动处理管道符转义和列填充
  • 一键复制转换结果
  • 输入即自动转换（支持 Ctrl+Enter 快捷键）
  • 完全本地处理，数据不上传

常见问题

支持哪些 Markdown 表格格式？

支持标准 GFM 表格格式，需要有分隔行（|---|）。

表头会保留吗？

默认保留表头作为 CSV 的首行。也可以取消勾选包含表头选项来移除表头。

单元格中的逗号怎么处理？

自动用双引号包裹包含逗号的字段，符合标准 CSV 规范。

列数不一致怎么办？

自动用空值填充列数不足的行，确保 CSV 每行列数一致。

数据安全吗？

完全安全。所有数据在浏览器本地处理，不会上传到任何服务器。
