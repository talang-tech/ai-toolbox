JSON 转 Excel

将 JSON 数组/对象转换为 Excel (.xlsx) 或 CSV 格式并下载

关于这个工具

免费的在线 JSON 转 Excel 工具，将 JSON 数组或对象快速转换为 Excel (.xlsx) 格式，支持一键下载。完美处理嵌套 JSON 对象和数组，自动展平为表格列。同时支持导出为 CSV 格式，满足不同场景需求。

本工具适合 数据分析师、后端开发者、API 测试人员、产品经理 等需要将 JSON 数据转换为表格格式的人群。所有处理在浏览器本地完成，数据不会上传到任何服务器，隐私安全有保障。

主要功能

  • 支持 JSON 数组和对象输入，自动检测格式
  • 自动展平嵌套 JSON 对象（如 user.name -> user_name）
  • 支持数组嵌套展开为多行
  • 导出为 Excel (.xlsx) 或 CSV 格式
  • 智能列排序和数据类型推断
  • 一键复制到剪贴板
  • 完全本地处理，数据不上传

常见问题

支持多大的 JSON 文件？

建议 JSON 数据不超过 10MB，行列数不超过 10,000 行以保证浏览器性能。超出时工具会提示。

嵌套 JSON 对象怎么处理？

嵌套对象自动展平，如 {user: {name: '张三'}} 会变成 user_name 列。数组嵌套会展开为多行，同一父级数据会自动复制。

支持导出为 XLSX 还是 CSV？

两种格式都支持。XLSX 保留更多格式信息，CSV 兼容性更广，通用性更强。

数据安全吗？

完全安全。所有 JSON 解析和转换在浏览器本地完成，数据不会上传到任何服务器。

支持哪些 JSON 输入格式？

支持 JSON 数组（推荐的输入格式）和 JSON 对象。工具会自动检测输入格式并相应处理。

能处理中文列名吗？

完全支持中文列名，无需额外配置。中文列名在 Excel 和 CSV 中均可正常显示。

空值怎么处理？

JSON 中缺失的字段在导出表格中显示为空单元格。null 值也会显示为空。

可以在手机上使用吗？

可以。工具响应式设计，在手机浏览器上也能正常使用。

JSON 格式错误怎么办？

工具会检测 JSON 格式错误并给出明确的错误提示，帮助您快速定位问题。

最大行列数有限制吗？

推荐不超过 10,000 行 x 100 列。超过建议范围时工具会给出性能警告。
