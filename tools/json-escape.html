JSON 转义/反转义

JSON 字符串转义与反转义，方便嵌入代码字符串

关于这个工具

免费的在线 JSON 转义/反转义工具。转义：将 JSON 文本转换为可用作代码中字符串字面量的格式（自动添加引号、转义换行/引号/反斜杠）。反转义：将转义后的 JSON 字符串还原为可读格式。

常用于调试时把 JSON 打印到日志、嵌入 JavaScript/Python 代码、或从代码字符串中提取 JSON。所有处理在浏览器本地完成。

主要功能

  • 一键转义 JSON 为字符串字面量
  • 一键反转义回到可读 JSON
  • 可选择是否包裹引号
  • 实时显示字符数和转义序列统计
  • 验证反转义结果的 JSON 有效性
  • 完全本地处理，数据不上传

常见问题

什么是 JSON 转义？

JSON 转义是将 JSON 对象转换成字符串字面量格式。例如 {"a":1} 会变成 '{"a":1}'。这样你就可以把 JSON 放到代码字符串中。

什么时候需要 JSON 转义？

把 JSON 数据嵌入到 JavaScript/Python 代码中、打印到日志文件、或者作为 API 请求参数传递时，需要先转义。

转义和反转义有什么区别？

转义是把 JSON 对象变成字符串字面量（添加引号、转义特殊字符）；反转义是逆转这个过程，把字符串字面量恢复成 JSON 文本。

数据会上传到服务器吗？

不会。所有处理完全在浏览器本地完成，数据不会离开你的电脑。
