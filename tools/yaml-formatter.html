YAML 格式化/校验

在线格式化 YAML 配置并检查缩进、冒号和常见语法问题

隐私说明

这个工具在你的浏览器中运行。你输入的内容、文件、JSON、JWT、图片、PDF、密码、哈希或文本不会上传到 AI 工具盒子的服务器。

站点可能记录基础访问量和转化点击事件，但不会追踪用户输入内容或文件内容。

关于这个工具

免费的在线 YAML 格式化与校验工具，适合整理 Docker Compose、Kubernetes、GitHub Actions、CI/CD、OpenAPI 等配置片段。工具会检查 Tab 缩进、奇数缩进、缺少冒号、未闭合引号、重复键等常见问题，并输出更干净的 YAML 文本。

所有处理都在浏览器本地完成，你粘贴的配置文件、Token、环境变量示例不会上传到服务器。注意：这是轻量级 YAML 检查器，覆盖常见配置场景，不等同于完整 YAML 1.2 解析器。

主要功能

  • 格式化 YAML / YML 配置文本
  • 检查 Tab 缩进和奇数缩进
  • 提示缺少冒号、未闭合引号等常见错误
  • 检测同层级重复键
  • 支持压缩为单行便于粘贴
  • 浏览器本地处理，配置内容不上传

常见问题

支持完整 YAML 1.2 规范吗？

这个工具是轻量级格式化与常见错误检查器，适合 Docker Compose、Kubernetes、GitHub Actions 等常见配置。锚点、复杂多行标量等高级语法可能只做保守检查。

配置里的密钥会上传吗？

不会。格式化、校验和复制都在浏览器本地执行，输入内容不会上传到 AI 工具盒子的服务器。

为什么重点检查缩进？

YAML 对缩进非常敏感。线上排查中最常见的问题就是 Tab、奇数缩进、列表层级和缺少冒号。
