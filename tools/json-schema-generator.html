JSON Schema 生成器

从 JSON 数据样本自动生成 JSON Schema（Draft-07）

提示：Ctrl+Enter / Cmd+Enter 快速生成

关于这个工具

JSON Schema 生成器帮助你从 JSON 数据样本自动生成 JSON Schema（Draft-07 规范）。适合：

  • API 开发中从响应数据自动生成 Schema 文档
  • 为配置文件生成数据结构约束
  • 数据库记录结构定义
  • 前端类型定义的前置步骤

支持智能类型推断（integer/number/string 自动识别）、optional/required 属性推断、数组元素类型分析、嵌套对象递归处理，以及常见格式（email、uri、date-time、uuid）自动识别。

所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • 从 JSON 数据样本自动生成 Schema
  • 支持嵌套对象递归生成
  • 数组元素类型自动分析
  • 智能类型推断（integer/number/string）
  • 自动识别 email、uri、date-time、uuid 格式
  • optional/required 属性推断
  • additionalProperties 约束标记
  • Ctrl+Enter 快捷键快速生成
  • 纯本地处理，数据零上传

常见问题

生成的 Schema 是哪个版本？

默认生成 Draft-07（2019-09）兼容的 Schema，这是当前最广泛支持的版本。

能处理嵌套对象吗？

可以。工具会递归处理所有嵌套的对象和数组，最大递归深度 10 层。

为什么有的属性没出现在 required 里？

null 或 undefined 值的属性会被视为 optional，不会标记为 required。

和 JSON Schema 校验器有什么区别？

生成器从样本数据反向生成 Schema 约束；校验器用已定义的 Schema 验证数据。两者是互补的逆向流程。

数据会被上传吗？

不会。所有处理都在浏览器本地完成，数据不会离开你的设备。
