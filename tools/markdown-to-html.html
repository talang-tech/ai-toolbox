Markdown 转 HTML

将 Markdown 转换为干净 HTML，支持预览、复制和下载

预览

隐私说明

这个工具在你的浏览器中运行。你输入的内容、文件、JSON、JWT、图片、PDF、密码、哈希或文本不会上传到 AI 工具盒子的服务器。

站点可能记录基础访问量和转化点击事件，但不会追踪用户输入内容或文件内容。

关于这个工具

免费在线 Markdown 转 HTML 工具，适合把 README、博客草稿、文档片段快速转换为可复制的 HTML。支持标题、列表、引用、代码块、表格、链接、图片、粗体、斜体和删除线。

转换和预览都在浏览器本地完成，文档内容不会上传到服务器。默认开启安全模式，会转义原始 HTML，适合处理来自外部的 Markdown 文本。

主要功能

  • Markdown 一键转 HTML
  • 实时 HTML 预览
  • 复制 HTML 片段
  • 下载完整 HTML 文件
  • 支持表格、代码块、引用和链接
  • 安全模式转义原始 HTML
  • 浏览器本地处理，文档不上传

常见问题

支持 GitHub Flavored Markdown 吗？

支持常用 GFM 子集，包括表格、删除线、代码块和列表。任务列表等高级语法会逐步补齐。

Markdown 内容会上传吗？

不会。转换、预览、复制和下载都在浏览器本地完成。

安全模式有什么作用？

安全模式会转义原始 HTML，降低粘贴外部 Markdown 时把脚本或危险标签渲染出来的风险。
