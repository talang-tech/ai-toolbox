CSV 查看器/转表格

解析 CSV/TSV 为表格，可复制 HTML 表格或 JSON

隐私说明

这个工具在你的浏览器中运行。你输入的内容、文件、JSON、JWT、图片、PDF、密码、哈希或文本不会上传到 AI 工具盒子的服务器。

站点可能记录基础访问量和转化点击事件，但不会追踪用户输入内容或文件内容。

关于这个工具

免费在线 CSV 查看器和表格转换工具，可把 CSV、TSV 或自定义分隔符数据解析为可滚动表格，并复制为 HTML 表格或 JSON 数组。支持引号字段、字段内逗号、双引号转义和表头识别。

所有解析和转换都在浏览器本地完成，适合预览导出的报表、运营数据、后台列表和简单数据清洗片段，不会上传原始表格内容。

主要功能

  • CSV/TSV 在线表格预览
  • 支持逗号、分号、Tab、竖线和自定义分隔符
  • 识别第一行为表头
  • 复制为 HTML table
  • 复制或下载 JSON 数组
  • 支持引号字段和字段内逗号
  • 浏览器本地处理，表格数据不上传

常见问题

支持字段里包含逗号吗？

支持。用双引号包裹的字段可以包含逗号，例如 "Product, Growth"。

可以处理 TSV 吗？

可以，在分隔符下拉框中选择 Tab 即可解析 TSV。

数据会上传到服务器吗？

不会。CSV 解析、表格预览和 JSON 转换都在浏览器本地执行。
