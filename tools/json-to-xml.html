JSON 转 XML

将 JSON 数据一键转换为 XML 格式，支持自定义根元素名称和缩进

关于这个工具

免费的 JSON 转 XML 在线转换工具。支持任意嵌套的 JSON 对象和数组，自动生成格式规范的 XML 文档。你可以自定义根元素名称和缩进大小（2/4 空格），输出带 XML 声明的标准 XML 文本。

所有转换在浏览器本地完成，你的数据不会上传到服务器。适合 API 数据格式转换、配置文件互转、数据迁移等场景。

主要功能

  • 将 JSON 对象/数组转换为格式规范的 XML
  • 支持任意嵌套深度的 JSON 结构
  • 自定义根元素名称
  • 可配置缩进（2 或 4 空格）
  • 自动生成 XML 声明（version/encoding）
  • 自动过滤注释和空行
  • 浏览器本地处理，数据不上传

常见问题

支持多深的 JSON 嵌套？

没有深度限制。工具递归遍历所有层级，任意深度的嵌套 JSON 都可以转换为 XML。

敏感数据安全吗？

完全安全。所有转换在浏览器本地完成，数据不会离开你的电脑。

JSON 数组怎么转 XML？

数组中的每个元素都会以原始元素名称重复出现。例如 {"items": [1,2,3]} 会生成 <items>1</items><items>2</items><items>3</items>。

为什么我的 XML 标签名变了？

XML 元素名称不能以数字开头，不能包含空格和特殊字符。不支持的字符会被替换为下划线，数字开头的名称会被加前缀。
