CSS 转 JS 转换器

将 CSS 样式转换为 React 内联样式对象、CSS-in-JS 对象或 styled-components 语法

关于这个工具

免费的在线 CSS 转 JS 转换器，帮助前端开发者将标准 CSS 样式快速转换为 React/TypeScript 项目中使用的 CSS-in-JS 格式。支持三种输出模式。所有处理在浏览器本地完成。

主要功能

  • 三种输出模式：JS 对象 / 内联样式 / styled-components
  • 自动将 CSS 属性名转换为驼峰命名 (camelCase)
  • 智能值类型推断
  • 支持 200+ CSS 属性的驼峰映射
  • 支持多个 CSS 规则同时转换
  • 一键复制转换结果
  • Ctrl+Enter 快捷键快速转换
  • 浏览器本地处理，代码不上传

常见问题

CSS 转 JS 转换器支持哪些输出格式？

支持三种格式：JS 对象、React 内联样式、styled-components 语法。

数据会被上传到服务器吗？

不会。所有转换在浏览器本地完成。
