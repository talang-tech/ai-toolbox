HTML 格式化/美化

格式化美化 HTML 代码，支持缩进和空行压缩

关于这个工具

免费的在线 HTML 格式化/美化工具，将压缩或杂乱的 HTML 代码转换为清晰易读的格式化代码。支持自定义缩进（2空格、4空格、Tab），可选空行压缩功能。

适用场景：调试 HTML 模板、阅读压缩的 HTML 代码、代码审查、学习 HTML 结构。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 一键格式化美化 HTML 代码
  • 支持 2 空格、4 空格、Tab 三种缩进方式
  • 可选空行压缩，减少空白行
  • 智能识别内联元素和块级元素
  • 正确处理注释、自闭合标签、空元素
  • 实时统计输入/输出大小
  • 一键复制格式化结果
  • 浏览器本地处理，数据不上传

常见问题

这个工具和 HTML Minifier 有什么区别？

HTML Minifier 是压缩 HTML 减少体积，本工具是格式化美化 HTML 使其更易读。两者互补。

支持哪些 HTML 版本？

支持 HTML4、HTML5、XHTML。自动识别自闭合标签。

格式化后的 HTML 会改变功能吗？

不会。格式化只改变缩进和换行，不会影响 HTML 的功能和语义。

支持自定义缩进吗？

支持。你可以选择 2 空格、4 空格或 Tab 缩进。

数据安全吗？

所有处理在浏览器本地完成，数据不会上传到任何服务器。
