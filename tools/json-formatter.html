JSON 格式化

JSON 美化、压缩、校验，错误位置精准定位

关于这个工具

开发者最常用的工具之一。粘贴 JSON 即可一键格式化（美化）、压缩成单行，或校验是否合法。如有错误，会精准告诉你出错位置和原因。

支持嵌套对象和数组，所有处理在浏览器本地完成。

主要功能

  • JSON 一键美化格式化
  • JSON 压缩去空格
  • JSON 语法校验，错误位置高亮
  • JSON 树状视图折叠展开
  • 支持大文件解析
  • 自动修复常见语法错误

常见问题

JSON 和 JS 对象有什么区别？

JSON 是纯文本格式，键名必须双引号；JS 对象是语言结构，键名可以省略引号。

最大支持多大的 JSON？

只要浏览器内存允许，可以处理几十 MB 的 JSON 文件。

数据会上传到服务器吗？

不会。所有处理都在您的浏览器本地完成，数据不会上传。
