HTML 转 JSX

将 HTML 转换为 React JSX 语法，处理 className、style、属性映射等

关于这个工具

免费在线 HTML 转 JSX 转换工具。将普通 HTML 一键转换为 React JSX 语法，自动处理：

  • class → className
  • style 字符串 → JSX 对象语法
  • for → htmlFor
  • 自闭合标签（img/br/input 等）
  • 内联样式转为驼峰命名对象
  • 布尔属性处理

所有处理在浏览器本地完成，内含示例代码供参考。

主要功能

  • 一键 HTML 转 JSX 语法
  • 自动 class 转 className
  • style 字符串转为 JSX 对象
  • 自闭合标签自动处理
  • for → htmlFor 等属性映射
  • 布尔属性自动识别
  • 支持多根元素片段
  • 浏览器本地处理，数据不上传

常见问题

JSX 和 HTML 有什么区别？

JSX 是 React 的模板语法扩展，使用 className 替代 class、camelCase 属性名、内联样式需写成对象等。此工具自动处理这些差异。

SVG 也能转换吗？

可以，工具支持 SVG 标签和属性的转换，包括 viewBox 等特有属性。

数据上传吗？

不会，所有转换在浏览器本地完成。
