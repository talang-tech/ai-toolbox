IP 子网计算器

CIDR 地址计算网络/广播/掩码/可用主机范围

关于这个工具

输入 IP 地址和 CIDR 前缀长度，计算子网掩码、网络地址、广播地址、可用主机范围和主机总数。

主要功能

  • CIDR 地址解析
  • 网络地址计算
  • 广播地址计算
  • 可用主机范围
  • 子网掩码显示
  • 可用主机数量

常见问题

什么是 CIDR？

无类别域间路由，用 IP/前缀长度表示子网，如 192.168.1.0/24。

/24 有多少可用 IP？

256 个总地址，去掉网络地址和广播地址，可用 254 个。

支持 IPv6 吗？

目前支持 IPv4，IPv6 可以后续添加。
