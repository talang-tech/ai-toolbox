Markdown 表格转 JSON

将 Markdown 表格解析为 JSON 数组或对象

关于这个工具

免费的 Markdown 表格转 JSON 工具，快速将 Markdown 格式的表格数据解析为 JSON 数组或对象。支持自动识别表头（第一行作为键名），适合数据迁移、API 构建、数据分析和自动化脚本编写场景。

支持任意数量的行和列，列名自动转换为合法的 JSON 键名。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 自动识别 Markdown 表格格式
  • 支持对象数组（首行作为键名）和数组数组两种输出格式
  • 列名自动转换为合法 JSON 键名
  • 实时转换，粘贴即出结果
  • 一键复制 JSON 输出
  • 所有处理在浏览器本地完成，零数据上传

常见问题

Markdown 表格格式有要求吗？

标准 Markdown 表格即可：第一行表头，第二行分隔线（|---|），后续数据行。支持任意数量的列和行。

表头包含特殊字符怎么办？

工具会自动将表头中的特殊字符替换为下划线，确保生成合法的 JSON 键名。中文表头会被保留。

生成的 JSON 能用在什么地方？

适合 API 数据构建、前后端数据交换、数据分析脚本、自动化测试等场景。

支持多大数据？

作为浏览器本地工具，支持数千行级别的表格。超大表格可能存在性能问题。
