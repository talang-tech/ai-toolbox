输入颜色预览

关于这个工具

免费在线颜色名称查询工具。输入任意 Hex 或 RGB 颜色值，自动匹配最接近的 CSS 命名颜色（总共 148 种标准颜色名称）。支持关键词搜索颜色名称，也可浏览完整 CSS 命名色板，实时预览所有颜色。

所有计算在浏览器本地完成，颜色数据不上传服务器。

主要功能

  • 输入 Hex 或 RGB 自动匹配最接近的 CSS 颜色名称
  • 148 种标准 CSS 命名颜色完整色板浏览
  • 实时颜色预览，一键复制颜色名称
  • 按关键词快速过滤颜色名称
  • 浏览器本地处理，无数据上传

常见问题

支持哪些颜色格式？

支持 Hex（#ff6347、#f63 简写）和 RGB 格式。

有多少种标准 CSS 颜色名称？

CSS 标准定义了 148 个命名颜色。

颜色匹配的原理是什么？

采用欧几里得距离在 RGB 空间计算最接近的命名颜色。

颜色名称在浏览器中都支持吗？

148 种 CSS 命名颜色在所有现代浏览器中均可使用。
