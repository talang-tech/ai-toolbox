Markdown 表格格式化器

对齐、排序、美化 Markdown 表格，按列升序/降序排序

||

关于这个工具

免费在线 Markdown 表格格式化工具，支持排序、对齐和美化。特别适合 GitHub README 和文档中的大型表格。

  • 列排序：按任意列升序/降序
  • 对齐设置：左对齐、居中或右对齐
  • 规范输出：自动修复格式问题
  • 移除表格：转为纯文本

所有处理在浏览器本地完成。

主要功能

  • 按任意列升序/降序排序
  • 统一对齐：左/中/右
  • 自动修复分隔行和列宽
  • 转为纯文本（逗号或管道分隔）

常见问题

支持什么表格格式？

标准 GFM 格式，需有分隔行和管道符。

表头会被排序影响吗？

不会，表头始终保持在顶部。
