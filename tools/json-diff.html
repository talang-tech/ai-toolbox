JSON 对比

深层比较两个 JSON 的差异，精准定位新增/删除/修改项

隐私说明

这个工具在你的浏览器中运行。你输入的内容、文件、JSON、JWT、图片、PDF、密码、哈希或文本不会上传到 AI 工具盒子的服务器。

站点可能记录基础访问量和转化点击事件，但不会追踪用户输入内容或文件内容。

关于这个工具

JSON Diff（JSON 差异对比）工具可以深层比较两个 JSON 对象或 JSON 数组的差异。对比结果按路径逐项列出，清晰标注新增、删除、修改和类型变更。常用于 API 响应对比、配置文件版本比对、数据结构变更审计等场景。

所有处理在浏览器本地完成，数据不会被上传。

主要功能

  • 深层递归对比 JSON 对象和数组
  • 新增/删除/修改/类型变更分类高亮
  • 全路径精准定位差异点
  • 自动对比（输入即触发）
  • 复制差异摘要
  • 浏览器本地完成，零数据上传

常见问题

支持 JSON 数组对比吗？

支持。数组按索引对比，新增/删除的元素会标注索引位置。

能对比很大的 JSON 吗？

只要浏览器内存允许即可。过大的 JSON 建议分片段对比。

数据会传到服务器吗？

不会。所有对比都在浏览器本地完成，适合比较包含敏感信息的 JSON。
