HTML 实体编解码

< 与 < 互转，支持常用命名实体和数字实体

关于这个工具

将 HTML 特殊字符转换为实体编码，或将实体编码还原为原字符。支持常用命名实体、十六进制和十进制数字实体。

主要功能

  • HTML 特殊字符编码
  • HTML 实体解码
  • 支持命名实体（&）
  • 支持数字实体（&）
  • 支持 Unicode 字符
  • XML 兼容

常见问题

为什么 HTML 要转义字符？

< > & " ' 这些字符在 HTML 中有特殊含义，转义后才能正确显示。

命名实体和数字实体有什么区别？

命名实体如 < 可读性好；数字实体如 < 覆盖范围更广。

中文需要转义吗？

UTF-8 编码下中文一般不需要转义。
