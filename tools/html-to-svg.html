HTML 转 SVG

将 HTML 代码片段转换为 SVG 矢量图形，支持复制和下载

🔒 隐私提示：所有处理在浏览器本地完成，数据不会上传到服务器。

关于这个工具

免费的在线 HTML 转 SVG 工具。将 HTML 代码片段转换为可缩放矢量图形(SVG)。使用 SVG 的 foreignObject 技术将 HTML 嵌入 SVG，保留文本可选中、可搜索特性。

适合：将 UI 组件导出为矢量图用于文档、将 HTML 表格/图表转为 SVG 用于报告、设计稿交付、演示文稿中的代码片段展示。

所有处理在浏览器本地完成，无需上传数据。

主要功能

  • 将 HTML 代码片段转换为标准 SVG 格式
  • 保留文本可选中、可搜索特性
  • 支持自定义 SVG 宽度和高度
  • 一键复制 SVG 代码或下载 SVG 文件
  • 预览转换效果，所见即所得
  • 完全本地处理，数据不上传服务器

常见问题

HTML 转 SVG 的原理是什么？

使用 SVG 的 foreignObject 元素，可以直接在 SVG 中嵌入 HTML 内容。文本保持可选中、可搜索状态。注意：部分复杂 CSS 效果可能不支持。

哪些 HTML 和 CSS 特性支持？

基础 HTML 标签、CSS 样式、字体、颜色、边距等均支持。不支持外部资源加载、iframe、JavaScript 交互。

转换后的 SVG 可以缩放吗？

可以。SVG 是矢量格式，可以无限缩放而不失真，适合印刷和 Retina 显示屏。

数据安全吗？

完全安全。所有处理在浏览器本地完成，没有任何数据上传到服务器。

支持中文内容吗？

支持。SVG 使用 UTF-8 编码，中文等 Unicode 字符完整保留。

可以下载为文件吗？

可以。点击下载按钮即可保存为 .svg 文件，可在浏览器、设计软件中直接打开。
