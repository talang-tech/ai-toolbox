JSONPath 提取

用 $.path 语法快速从 JSON 中提取需要的数据

关于这个工具

JSONPath 是 JSON 数据的「XPath」，用路径表达式从复杂 JSON 中提取嵌套字段、数组元素。

支持：$ 根节点、.key 取属性、[0] 取下标、[*] 取全部、条件过滤等

主要功能

  • $ 根路径语法支持
  • 点表示法和括号表示法
  • 条件过滤表达式
  • 数组切片和索引
  • 通配符支持
  • 实时提取预览

常见问题

JSONPath 和 XPath 有什么关系？

JSONPath 是 JSON 版的 XPath，语法风格类似但更简单。

支持过滤表达式吗？

支持 ?() 条件过滤，如 $.items[?(@.price > 100)]。

可以提取嵌套很深的字段吗？

可以，JSONPath 支持任意层级的嵌套。
