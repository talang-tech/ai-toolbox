JSON 排序

按字母序排序 JSON 键值、数组元素，支持嵌套和自定义顺序

关于这个工具

免费的在线 JSON 排序工具，支持多种排序方式：按字母序重排 JSON 对象键值、按字母/数字排序数组元素、自定义排序顺序。处理嵌套 JSON 结构时自动递归排序。

所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 按字母序排序 JSON 对象键
  • 排序 JSON 数组元素（字母/数字）
  • 递归排序嵌套 JSON 结构
  • 区分/不区分大小写选项
  • 一键复制排序结果
  • 浏览器本地处理，数据安全

常见问题

排序会修改原始 JSON 吗？

不会。排序只影响输出结果，原始输入不变。

支持多大的 JSON 文件？

只要浏览器内存允许，可处理数 MB 的 JSON 文件。

数组元素如何排序？

默认按字符串字母序排序，勾选「数字排序」后按数值排序。

数据会上传到服务器吗？

不会。所有处理在浏览器本地完成，数据不会上传。

嵌套对象也能排序吗？

可以。递归排序模式会处理所有层级的嵌套对象和数组。
