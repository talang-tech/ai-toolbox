HTML 转 Markdown

将 HTML 转换为 Markdown 格式，支持预览、复制和下载

预览

提示：Ctrl+Enter / Cmd+Enter 快速转换

关于这个工具

免费在线 HTML 转 Markdown 工具。将 HTML 网页、富文本片段或代码片段快速转换为整洁的 Markdown 格式。适合：

  • 从网页复制内容转换为 Markdown 笔记
  • 将 HTML 邮件转换为 Markdown
  • 从富文本编辑器提取 Markdown 内容
  • 清理 HTML 格式保留纯文本标记

转换完全在浏览器本地完成，内容不会上传到服务器。

主要功能

  • HTML 一键转 Markdown
  • 支持标题 h1-h6、段落、列表
  • 支持表格转换
  • 支持链接、图片、代码块
  • 加粗、斜体、删除线转换
  • 实时 Markdown 预览
  • 复制或下载 .md 文件
  • 浏览器本地处理，内容不上传

常见问题

支持哪些 HTML 标签？

支持主流块级标签：h1-h6、p、ul/ol、blockquote、pre/code、table、hr、div；内联标签：a、img、strong/b、em/i、del/s、code。

HTML 内容会上传吗？

不会。所有转换和预览都在浏览器本地完成，数据不会离开你的设备。

转换后的 Markdown 可以在哪里使用？

可在 GitHub README、Markdown 笔记、博客草稿、Notion、Obsidian 等任何 Markdown 编辑器中使用。

支持 HTML 表格吗？

支持。HTML table 会被转换为 Markdown 表格格式。

脚本和样式会被保留吗？

不会。script 和 style 标签会被自动移除，保证输出干净。
