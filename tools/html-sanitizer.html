HTML 净化器

安全地清洗 HTML 代码，移除 XSS 攻击向量、恶意脚本和危险标签

🔒 隐私提示：所有处理在浏览器本地完成，HTML 代码不会上传到服务器。

关于这个工具

免费的在线 HTML 净化器。安全地清洗 HTML 代码，移除 XSS（跨站脚本）攻击向量、恶意脚本、危险标签和事件处理器。支持两种模式：安全模式（清空脚本内容但保留标签结构）和严格模式（移除所有未知标签和脚本标签）。

基于白名单机制，只允许安全的 HTML 标签和属性，自动移除所有 on* 事件处理器、javascript: 协议链接等 XSS 向量。所有处理在浏览器本地完成，HTML 代码不会上传到服务器。

主要功能

  • 移除 XSS 攻击向量（javascript:、data: 等危险协议）
  • 移除所有 on* 事件处理器（onclick、onload、onsubmit 等）
  • 安全模式：保留标签结构，清空脚本内容
  • 严格模式：移除所有未知标签和脚本标签
  • 基于白名单的标签和属性过滤
  • 完全本地处理，HTML 代码不上传服务器

常见问题

什么是 XSS 攻击？

XSS（跨站脚本攻击）是攻击者通过注入恶意脚本到网页中来窃取用户数据或劫持会话的攻击方式。HTML 净化器可以移除这些恶意代码。

安全模式和严格模式有什么区别？

安全模式会清空脚本和样式的内容但保留标签本身。严格模式会完全移除所有未知和危险的标签。

支持哪些 HTML 标签？

支持所有标准的安全 HTML 标签，包括标题、段落、列表、表格、表单、媒体元素等。

会移除 style 属性吗？

不会。合法的 style 属性会被保留，但所有 on* 事件处理器都会被移除。

数据安全吗？

完全安全。所有处理在浏览器本地完成，HTML 代码不会上传到服务器。

适合什么场景使用？

适合用户输入内容展示前的安全清洗、富文本编辑器输出过滤、HTML 邮件内容安全处理等场景。
