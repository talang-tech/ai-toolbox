XML 转 JSON

将 XML 数据快速转换为 JSON 格式，支持嵌套结构解析和自定义选项

关于这个工具

免费在线 XML 转 JSON 转换工具。将 XML 数据一键转换为 JSON 格式，自动处理嵌套元素、属性、文本节点和数组。支持自定义转换选项，适合 API 集成、数据迁移和配置文件处理。

  • 开发者：将 XML API 响应转换为 JSON 进行调试
  • 数据工程师：批量转换 XML 配置文件为 JSON 格式
  • 迁移场景：从 XML 架构迁移到 JSON 的数据中间件

所有转换在浏览器本地完成，数据不会上传。支持自动检测数组节点、属性前缀标记（@）、命名空间处理等高级功能。

主要功能

  • XML 一键转换为 JSON 格式
  • 支持深度嵌套的 XML 结构
  • 自动识别数组节点（相同标签）
  • 属性文本节点正确分离
  • 自定义缩进和紧凑输出
  • 属性前缀标记开关（@ 符号）
  • 复制、清空、错误提示
  • 浏览器本地处理，数据不上传

常见问题

XML 属性在 JSON 中怎么表示？

默认情况下，属性会用 @ 前缀标记（如 @id）。可以通过去掉选项中的勾选来关闭此前缀。

XML 和 JSON 的根本区别是什么？

XML 有属性和命名空间的概念，JSON 只有键值对、数组和嵌套对象。转换时属性和文本节点会被适当映射为 JSON 结构。

支持带命名空间的 XML 吗？

支持。命名空间前缀会被保留为元素的属性或键名的一部分。对于复杂的命名空间转换，建议先验证结果。

数据安全吗？

全部处理在浏览器本地完成，数据不会上传到任何服务器。
