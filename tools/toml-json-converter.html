TOML JSON 互转

TOML 与 JSON 格式双向转换工具

关于这个工具

免费的 TOML 与 JSON 双向转换工具，在两种流行的配置文件格式之间快速转换。TOML 以其简洁易读的语法在 Rust 社区（Cargo.toml）、Python 社区（pyproject.toml）中被广泛使用，而 JSON 则是 Web 开发和 API 领域的事实标准。

支持标准 TOML 语法：基本键值对、字符串、数字、布尔值、数组、表（[table]）和表数组（[[array]]）。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • TOML 与 JSON 双向转换
  • 支持标准 TOML 语法：表、表数组、字符串、数字、布尔值、数组
  • 一键互换输入输出方向
  • 一键复制转换结果
  • 自动识别 TOML 数组和嵌套表结构
  • 所有处理在浏览器本地完成，零数据上传

常见问题

TOML 和 JSON 有什么区别？

TOML 语法更简洁易读，专为配置文件设计。JSON 更通用，广泛用于 Web API 和数据交换。TOML 不支持 null 值，JSON 不支持多行字符串（不加转义）。

支持哪些 TOML 语法？

支持基本键值对、字符串（单引号和双引号）、数字、布尔值、数组、表（[table]）、表数组（[[array]]）以及内联表。暂不支持多行字符串、日期时间和浮点数特殊格式。

TOML 在哪些地方使用？

Rust 的 Cargo.toml、Python 的 pyproject.toml、Ruby 的 Bundler 配置等。随着 Rust 和 Python 生态的发展，TOML 越来越流行。

转换结果可以保持原样吗？

TOML 和 JSON 之间有些差异：TOML 不支持 null 值，JSON 不支持多行字符串。转换会尽力保持数据完整性，但部分格式细节可能丢失。
