JSON 压缩

压缩 JSON 去除空格换行，减小体积，支持复制和下载

关于这个工具

免费的在线 JSON 压缩工具。去除 JSON 字符串中的空格、换行和缩进，将美化格式的 JSON 压缩为紧凑格式，显著减小体积。适用于 API 请求体压缩、数据传输优化、存储空间节省等场景。

支持大 JSON 文件压缩、一键复制压缩结果、下载为 .json 文件。支持从格式化 JSON 到单行紧凑 JSON 的转换。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 一键压缩 JSON 去除空格换行
  • 可选的压缩前语法验证
  • 实时显示压缩前/后大小和压缩率
  • 一键复制压缩结果
  • 下载为 .json 文件
  • 支持大文件处理
  • 显示压缩体积节省百分比
  • 浏览器本地处理，数据不上传

常见问题

压缩后 JSON 还能用吗？

压缩仅去除空格和换行，JSON 结构和数据完全不变，可以直接使用。

压缩率能有多大？

对于格式化美观的 JSON，压缩率通常在 30%-70% 之间，具体取决于缩进和空行数量。

和 JSON 格式化有什么区别？

JSON 格式化是美化 JSON 使其易读，JSON 压缩是去除空格使体积最小。两者是相反的操作。

支持验证 JSON 语法吗？

支持。勾选压缩前验证语法，压缩前会先检查 JSON 是否合法，不合法会提示错误。

数据安全吗？

所有处理在浏览器本地完成，数据不会上传到任何服务器。
