常见问题

什么是 ASCII？

ASCII（American Standard Code for Information Interchange）是美国信息交换标准代码，用 7 位或 8 位二进制数字表示 128 或 256 个字符，包括英文字母、数字、标点符号和控制字符。

ASCII 和 Unicode 有什么区别？

ASCII 只定义了 128 或 256 个字符，主要用于英文。Unicode 支持全球几乎所有语言的字符，包含超过 14 万个字符。ASCII 是 Unicode 的一个子集。

什么是扩展 ASCII？

扩展 ASCII 使用 8 位编码（0-255），在标准 ASCII（0-127）基础上增加了 128 个额外字符，包括特殊符号、制表符和外来字母。

支持中文吗？

本工具专注于 ASCII 字符集。中文等 Unicode 字符请使用 Unicode 转换器工具。

HTML 实体编码是什么？

HTML 实体编码用 & 开头的特殊序列表示 HTML 中的特殊字符，如 < 表示小于号 <，& 表示 & 符号。

数据安全吗？

完全安全。所有字符编码转换在浏览器本地完成，数据不会上传到服务器。

\\uXXXX 转义是什么？

\\uXXXX 是 JavaScript 和 JSON 中使用的 Unicode 转义序列，\\u0041 表示 'A'，\\u00A9 表示版权符号 ©，等等。
