常见问题

什么是 SemVer？

SemVer（语义化版本）使用 MAJOR.MINOR.PATCH 格式：主版本号表示不兼容的 API 变更，次版本号表示向下兼容的功能新增，补丁号表示向下兼容的问题修复。

数据会上传服务器吗？

不会。所有处理都在浏览器本地完成，不上传任何数据。
