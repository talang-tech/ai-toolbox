JSON 转 Go Struct

在线将 JSON 转换为 Go 结构体定义

关于这个工具

将 JSON 数据自动转换为 Go (Golang) Struct 结构体定义，支持 omitempty 标签、驼峰命名转换。Go 开发者必备工具。

主要功能

  • 生成带 json 标签的 Go 结构体
  • 支持嵌套对象和数组
  • omitempty 和 inline 标签选项
  • 帕斯卡命名字段
  • 所有 JSON 类型的自动推断

常见问题

字段名是如何确定的？

JSON 键会自动转换为 PascalCase。我们会处理特殊字符、数字和常见的 Go 命名约定。

能处理空字段吗？

可以！null 值会变成带 omitempty 标签的指针类型，实现正确的 JSON 序列化而不包含空字段。
