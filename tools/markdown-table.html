Markdown 表格生成器

将 CSV、TSV 或文本快速转换为 Markdown 格式表格

关于这个工具

Markdown 表格生成器帮助你将 CSV、TSV 或其他分隔符数据快速转换为整洁的 Markdown 表格格式，适合嵌入 README、GitHub Issues、博客文章和文档。支持自定义对齐方式（左对齐、居中、右对齐），以及首行作为表头。

所有处理在你的浏览器中本地完成，数据不会离开你的设备。

主要功能

  • 支持 CSV、TSV、管道符、分号等多种分隔符
  • 自定义列对齐方式：左对齐、居中、右对齐
  • 首行作为表头，或单独的数据行
  • 自动处理带引号的 CSV 字段
  • 一键复制生成的 Markdown 表格
  • 所有处理在浏览器本地完成，零数据上传

常见问题

CSV 字段包含逗号怎么办？

工具自动解析带引号的 CSV 字段。如果字段包含逗号，请用双引号括起来，工具会自动正确处理。

表格能支持多大数据？

作为浏览器本地工具，支持数千行级别。超大表格（万行以上）可能出现性能问题。

生成的 Markdown 表格可以在哪里使用？

GitHub README、Git Issues/PR、博客文章、文档系统等几乎所有支持 Markdown 的平台上都可以使用。

支持其他分隔符吗？

支持逗号 (CSV)、制表符 (TSV)、管道符 (|) 和分号 (;)。
