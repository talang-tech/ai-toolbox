TOML 格式化

TOML 配置文件格式化、验证排错，自动整理缩进与表结构

关于这个工具

免费的在线 TOML 格式化与验证工具。TOML 是一种广泛用于配置文件（如 Rust Cargo、Python pyproject.toml）的格式。

  • 格式化：自动整理缩进、对齐等号、整理表格结构、清理多余空白行
  • 验证：检查空表头、无效键值对、制表符警告等常见问题

适合：编辑 Rust Cargo.toml、Python pyproject.toml、VSCode 等工具的配置文件前后进行格式化清理。

所有处理在浏览器本地完成，配置文件内容不会上传到任何服务器。

主要功能

  • TOML 一键格式化，自动整理缩进
  • 表格 [section] 和 [[array]] 结构清晰排列
  • 等号对齐，键值对整洁
  • 基础语法验证：检查空表头、无效值
  • 去除多余空行和行尾空格
  • 支持标准 TOML 语法（多行字符串、内联表等）
  • 浏览器本地处理，配置不上传
  • Ctrl+Enter 快捷键快速执行

常见问题

TOML 和其他配置格式有什么区别？

TOML 设计目标是直观易读，类比 INI 但更强大。支持嵌套表、数组、日期等类型。常见于 Rust（Cargo.toml）和 Python（pyproject.toml）。

格式化后会破坏注释吗？

不会。工具保留所有行内注释和行级注释，仅调整缩进和空白。

支持 TOML v1.0 的所有功能吗？

工具支持常见 TOML 结构：表、行内表、数组、字符串、数字、布尔值、日期。部分高级特性（如点分隔键）有基础支持。

数据会上传到服务器吗？

不会。所有格式化与验证完全在浏览器本地完成，配置内容不会离开你的设备。
