常见问题

clip-path 是什么？

CSS clip-path 属性允许你裁剪元素到指定形状，如多边形、圆形、椭圆等，常用于创建独特的视觉设计效果。

clip-path 浏览器兼容性如何？

现代浏览器普遍支持 clip-path，包括 Chrome、Firefox、Safari、Edge。部分旧版浏览器可能需要 -webkit- 前缀。

polygon 和 circle 有什么区别？

Polygon 使用百分比坐标定义任意多边形顶点；Circle 只需要圆心位置和半径，适合圆形裁剪。

数据会上传到服务器吗？

不会。所有处理在浏览器本地完成，无数据上传。

clip-path 可以用在哪些场景？

头像裁剪、图片特效、卡片设计、动画元素、遮罩效果、响应式布局、创意导航。
