JSON 展平/还原

嵌套 JSON 一键展平为点号键名，支持反向还原

关于这个工具

免费在线 JSON 展平与还原工具。将深层嵌套的 JSON 对象展平为单层点号键名结构，也可将展平结果还原回原始嵌套格式。

  • 展平模式：将嵌套 JSON 转换为点号分隔的键值对，如 {"user": {"name": {"first": "John"}}} → {"user.name.first": "John"}
  • 还原模式：将展平后的点号键名 JSON 恢复为原始嵌套结构
  • 数组支持：正确处理 JSON 数组索引，如 items.0.name

适合：处理配置文件的扁平化、日志分析、数据 ETL 管道预处理、与 jq/flatten 库配合使用、API 响应解析。

所有处理在浏览器本地完成，数据不会上传到任何服务器。

  • 多层嵌套 JSON 一键展平为点号键名

常见问题

JSON 展平是什么意思？

将嵌套的 JSON 对象转换为单层键值对，用点号表示层级关系。例如 {"a": {"b": "c"}} 展平后变为 {"a.b": "c"}。

数组会怎么处理？

数组元素会使用数字索引作为键名的一部分，例如 {"items": ["a", "b"]} 展平后变为 {"items.0": "a", "items.1": "b"}。

展平后的 JSON 还能还原吗？

可以。选择"还原"模式并粘贴展平后的 JSON，即可恢复为原始嵌套结构。

数据会上传服务器吗？

不会。所有操作完全在浏览器本地完成，数据不会离开你的设备。

支持大 JSON 文件吗？

支持。但建议 JSON 文件大小不要超过 5MB，以免影响浏览器响应速度。

和 jq 的 flatten 有什么区别？

结果类似，但本工具是图形化界面、不限平台，无需安装 jq，适合不熟悉命令行的用户。
