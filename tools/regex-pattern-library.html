内置 30+ 高频使用的正则表达式模式，覆盖邮箱验证、URL匹配、手机号、身份证、日期时间、IP地址、密码强度检测等常见场景。每个模式附有说明，支持一键复制和实时测试。

所有处理在浏览器本地完成，不上传任何文本。

  • 内置 30+ 常见正则模式，覆盖邮箱/URL/手机号/IP/密码等
  • 分类浏览：邮箱、网址、数字、身份、电话、日期、Web 开发、安全、文本
  • 一键复制正则模式到剪贴板
  • 内置正则测试面板，支持修改和实时测试
  • 纯前端处理，数据不上传服务器

常见问题

这些正则模式的准确度如何？

每个模式都经过常用场景测试验证。但正则匹配有一定局限性，建议在实际项目中结合业务数据做进一步测试。

可以在测试面板中修改正则吗？

可以。选择模式后，正则表达式会填充到下方的「自定义正则」输入框，你可以自由修改并实时看到匹配结果。

支持哪些正则标志？

支持 g（全局）、i（忽略大小写）、m（多行）、s（点号匹配换行）、u（Unicode）等标准 JS 正则标志。

我的文本会上传到服务器吗？

不会。所有文本和正则运算都在你的浏览器本地完成，不会上传任何数据到服务器。
