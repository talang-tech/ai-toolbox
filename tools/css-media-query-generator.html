常见问题

什么是 CSS 媒体查询？

CSS 媒体查询 (@media) 是 CSS3 引入的强大功能，允许根据设备特性（如视口宽度、屏幕方向、分辨率等）应用不同的样式，是实现响应式设计的核心技术。

移动优先和桌面优先有什么区别？

移动优先（Mobile First）使用 min-width 查询，先写小屏样式，再逐步为大屏增强。桌面优先使用 max-width 查询，先写大屏样式，再为小屏适配。推荐使用移动优先策略。

什么是断点（Breakpoint）？

断点是响应式设计中样式发生变化的临界宽度值。常见的断点有：手机 480px、平板 768px、笔记本 1024px、桌面 1280px、大屏 1440px 等。

支持哪些设备预设？

支持 6 种预设：手机 (480px)、小平板 (640px)、平板 (768px)、笔记本 (1024px)、桌面 (1280px)、大屏 (1440px)。

生成的代码可以直接使用吗？

可以。生成的是标准的 CSS @media 规则，可以直接复制到你的样式文件中使用。

数据安全吗？

完全安全。所有媒体查询生成在浏览器本地完成，代码不会上传到服务器。

什么是 orientation 查询？

orientation 媒体特性用于检测设备的屏幕方向：portrait（竖屏，宽度小于高度）和 landscape（横屏，宽度大于高度）。

可以组合多个条件吗？

可以。支持使用 and、or 和 not 逻辑操作符组合多个媒体特性，如宽度和方向同时满足条件。
