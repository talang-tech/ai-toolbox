JSON 转 Zod

从 JSON 数据自动生成 Zod 验证 Schema，支持嵌套对象、数组、可选字段和枚举推断

关于这个工具

免费的在线 JSON 转 Zod Schema 工具，自动从 JSON 数据生成 TypeScript 生态中最流行的验证库 Zod 的 Schema 定义。支持深度嵌套对象、数组、可选字段、联合类型、枚举推断等高级特性。所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • 自动推断 JSON 字段类型
  • 支持深度嵌套对象和数组
  • 可选字段推断
  • 枚举值自动推断
  • 支持 Zod 原生类型
  • 特殊格式推断
  • 生成可直接使用的 TypeScript 代码
  • 零数据上传
