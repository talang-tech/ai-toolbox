JSON ↔ CSV 转换

JSON 数组与 CSV 表格格式双向转换，支持含逗号/引号的复杂内容

关于这个工具

JSON 和 CSV 是数据处理中最常用的两种格式。本工具支持：JSON 数组对象转 CSV 表格、CSV 表格转 JSON 数组。

正确处理字段内的逗号、引号、换行符等复杂情况。

主要功能

  • JSON 数组转 CSV 表格
  • CSV 表格转 JSON 数组
  • 支持含逗号/引号的复杂内容
  • 自动检测表头
  • 支持嵌套对象扁平化
  • 一键复制结果

常见问题

支持嵌套的 JSON 吗？

支持，会自动扁平化嵌套对象。

CSV 中的逗号怎么处理？

包含逗号的字段会自动用双引号包裹。

最大支持多少行？

只要浏览器内存允许，可以处理几万行数据。
