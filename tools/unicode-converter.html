Unicode 转换器

Unicode 编码互转：\uXXXX、十六进制、十进制、HTML 实体

关于这个工具

免费的在线 Unicode 转换工具，支持多种编码格式互转。一键解码 \uXXXX 转义序列为可读文本，也支持将中文/特殊字符编码为多种格式。

所有处理在浏览器本地完成，数据不会上传。

主要功能

  • 支持 \uXXXX 转义序列解码/编码
  • 十六进制字节序列与文本互转
  • 十进制 Unicode 码点与文本互转
  • HTML 实体编码/解码
  • 自动检测输入格式
  • 显示字符数量和 Unicode 信息
  • 完全本地处理，数据不上传

常见问题

\uXXXX 格式是什么？

JavaScript 中的 Unicode 转义序列，例如 \u4e2d\u6587 等于「中文」。

支持 4 位以上的 Unicode（如 Emoji）吗？

支持。\u{1F389}、surrogate pair 和直接输入均可识别。

数据会上传到服务器吗？

不会。所有转换完全在浏览器本地完成。
