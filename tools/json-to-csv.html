JSON 转 CSV

将 JSON 数组或对象一键转换为 CSV 表格格式

Ctrl+Enter

关于这个工具

免费的在线 JSON 转 CSV 工具。将 JSON 数组或对象一键转换为逗号分隔的 CSV 表格格式。支持复杂嵌套对象的扁平化处理，常用于：API 响应数据导出到 Excel/WPS、数据库查询结果转表格、数据分析前的格式转换。

支持自定义分隔符（逗号、制表符、分号、竖线等），可选择是否包含表头行，支持嵌套对象扁平化处理为点号分隔的列名。

所有处理在浏览器本地完成，JSON 数据不会上传到任何服务器。

主要功能

  • 支持 JSON 数组和单个对象
  • 自动检测并提取所有字段作为列
  • 支持嵌套对象扁平化（点号路径列名）
  • 支持简单值数组（每个值一行）
  • 自定义分隔符：逗号、制表符、分号、竖线
  • 可选择是否包含表头行
  • Ctrl+Enter 快捷键执行
  • 浏览器本地处理，JSON 数据不上传

常见问题

支持嵌套的 JSON 对象吗？

支持。选择「嵌套扁平化」模式，嵌套的字段会用点号路径作为列名，如 user.address.city。

JSON 转 CSV 后中文会乱码吗？

不会。输出的 CSV 是 UTF-8 编码，用 Excel 打开时记得选择 UTF-8 编码。

我的 JSON 只有一个对象怎么办？

单个对象也会被转为单行 CSV，方便查看对象结构。

分隔符如何选择？

默认逗号适用于 Excel。如果字段值里可能出现逗号，建议用制表符。

数据会上传到服务器吗？

不会。所有处理在浏览器本地完成。
