关于这个工具

免费的在线 CSS 转 SCSS/SASS 转换器，帮助前端开发者将标准 CSS 样式快速转换为 SCSS 或 SASS 语法。支持自动识别嵌套关系、提取 CSS 变量为 SCSS 变量、智能格式化。

适合：重构旧 CSS 项目为 SCSS 风格、学习 SCSS 语法、快速迁移 CSS 代码库。所有处理在浏览器本地完成，无需安装任何软件。

主要功能

  • CSS 自动转换为 SCSS 嵌套语法
  • 支持 SCSS 和 SASS 两种输出格式
  • 自动提取 CSS 自定义属性为 SCSS 变量
  • 智能识别父子选择器关系
  • 支持 Ctrl+Enter 快捷键快速转换
  • 一键复制转换结果
  • 浏览器本地处理，代码不上传服务器

常见问题

SCSS 和 SASS 有什么区别？

SCSS 使用花括号和分号，与 CSS 语法更相似；SASS 使用缩进语法，更简洁。

CSS 变量会被如何处理？

工具会自动提取 CSS 自定义属性并转换为 SCSS 变量。

数据会被上传到服务器吗？

不会。所有转换在浏览器本地完成。

支持复杂 CSS 选择器吗？

支持常见的 CSS 选择器。
