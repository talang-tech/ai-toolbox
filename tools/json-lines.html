JSON Lines (NDJSON) 工具

验证、格式化、转换和统计 JSON Lines (NDJSON) 格式数据，支持行级处理

🔒 隐私提示：所有数据在浏览器本地处理，不会上传到服务器。

关于这个工具

免费的在线 JSON Lines (NDJSON) 工具，处理每行一个独立 JSON 对象的格式（JSON Lines / NDJSON / JSONL）。支持验证、格式化、统计、转换为 JSON 数组、过滤、提取字段等操作。适合 日志分析、数据处理管道、机器学习数据集、流式数据 等场景。

JSON Lines 格式的每行是一个独立的 JSON 对象，行与行之间不是数组关系，而是独立的记录。本工具支持将 JSON Lines 与 JSON 数组互相转换、验证每行 JSON 合法性、统计字段分布、按条件过滤行、提取指定字段列。所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • 验证 JSON Lines 格式：检查每行 JSON 合法性
  • JSON Lines ↔ JSON 数组互相转换
  • 统计行数、字段分布、数据类型分布
  • 按条件过滤行（字段存在 / 值匹配）
  • 提取指定字段列（类似 SQL SELECT）
  • 格式化输出：缩进、排序键、行号
  • 错误定位：精确定位到问题行号和错误信息
  • 完全本地处理，数据不上传

常见问题

什么是 JSON Lines 格式？

JSON Lines (NDJSON/JSONL) 是一种每行包含一个独立 JSON 对象的格式，行与行之间用换行符分隔。常用于日志文件、流式数据、大数据处理等场景。

JSON Lines 和 JSON 数组有什么区别？

JSON Lines 是每行一个独立 JSON 对象，整体是一个 分隔的文本文件。JSON 数组是将所有数据包裹在 [...] 中。本工具可以在这两种格式之间互相转换。

支持多大的文件？

没有硬性限制，但建议处理不超过 10MB 或 50000 行，以确保浏览器性能。所有处理在本地完成。

数据安全吗？

完全安全。所有数据在浏览器本地处理，不会上传到任何服务器。

过滤功能怎么用？

支持按字段存在性过滤（如 field:exists）和按值匹配过滤（如 field==value）。支持多条件组合。
