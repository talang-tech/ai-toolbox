JS 压缩/美化

JavaScript 代码一键压缩美化，去注释、去空白、格式化缩进

关于这个工具

免费的在线 JavaScript 压缩与美化工具。支持两种模式：

  • 压缩模式：移除单行/多行注释、去除多余空白与换行，大幅减小 JS 代码体积
  • 美化模式：添加正确缩进和换行，恢复杂乱 JS 代码的可读性

适合：上线前压缩 JS 减小文件大小、从混淆代码恢复可读格式、批量整理脚本代码。

所有处理在浏览器本地完成，代码不会上传到任何服务器。

主要功能

  • JavaScript 一键美化格式化，嵌套缩进清晰
  • JS 压缩：去注释、去空白，大幅减小体积
  • 支持单行/多行注释自动移除
  • 压缩模式适合生产环境部署

  • 原大小 vs 压缩后大小对比

常见问题

JS 压缩后能正常工作吗？

压缩仅移除注释和空白，不影响代码逻辑执行。但极简化的压缩可能在某些极端情况下有问题，建议压缩后快速测试。

压缩率一般能达到多少？

取决于注释和空白量。带大量注释和格式空白的代码可压缩 30%-50%。已被压缩的代码效果有限。

美化后的代码结构和原代码一致吗？

美化通过添加缩进和换行改善可读性，但不会恢复丢失的变量名或注释。

数据会上传到服务器吗？

不会。所有格式化与压缩完全在浏览器本地完成，代码不会离开你的设备。

支持 ES6+/TypeScript 吗？

工具主要处理标准 JavaScript 语法。部分现代语法（如 JSX、TypeScript）可能不被正确处理。
