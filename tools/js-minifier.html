JS 压缩/美化

压缩和美化 JavaScript 代码，支持去除注释、空格、换行，以及代码格式化排版

关于这个工具

免费的在线 JS 压缩与美化工具，支持将 JavaScript 代码一键压缩（去除注释、空格、换行，减小文件体积）或美化（格式化缩进、添加空格和换行，提升可读性）。

适用于前端构建前的代码压缩、代码审查时的格式化查看、复制别人的压缩代码后还原为可读格式等场景。所有处理在浏览器本地完成，代码不会上传到服务器。

主要功能

  • 一键压缩 JavaScript 代码
  • 一键美化/格式化 JavaScript 代码
  • 去除所有注释（单行/多行/JSDoc）
  • 去除多余空格和换行
  • 自动缩进和格式化
  • 实时统计：原大小/结果大小/减少比例
  • 复制结果一键粘贴
  • 零数据上传，浏览器本地处理

常见问题

JS 压缩后还能还原吗？

压缩会丢失注释和格式信息，无法完全还原。推荐使用美化功能从压缩代码恢复可读格式。

压缩后的代码能直接用于生产环境吗？

可以。本工具去除注释和空格不会改变代码语义，适合用于生产环境部署。

支持 ES6+ 语法吗？

支持。本工具不解析 AST，而是基于文本处理，对 ES6/ES7+ 语法兼容。

代码会被上传吗？

不会。所有处理在浏览器本地完成，代码不会上传到任何服务器。
