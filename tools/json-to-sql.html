JSON 转 SQL

将 JSON 数组转换为 SQL INSERT 语句

关于这个工具

免费的 JSON 转 SQL 在线工具，将 JSON 数组或对象快速转换为 SQL INSERT 语句。支持批量插入、CREATE TABLE 自动生成、UPSERT 冲突处理、自定义表名和字段名映射。

适用场景：数据库迁移、数据导入、API 数据落库、测试数据生成、数据备份。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 一键将 JSON 数组转换为 SQL INSERT 语句
  • 支持批量插入 (VALUES) 和单条插入两种模式
  • 自动生成 CREATE TABLE 语句
  • 支持 UPSERT (ON CONFLICT DO UPDATE)
  • 自定义表名、引号风格和 NULL 处理方式
  • 自动推断字段类型 (INTEGER/REAL/BOOLEAN/TEXT/DATE)
  • 可选 DROP TABLE 前置语句
  • 一键复制生成的 SQL 代码

常见问题

生成的 SQL 语句可以直接用吗？

可以。生成的 SQL 兼容 PostgreSQL、MySQL、SQLite 等主流数据库。

支持嵌套 JSON 对象吗？

嵌套对象会被展开为扁平字段。

批量插入和单条插入有什么区别？

批量插入将所有数据放在一个 INSERT 语句中，性能更好。

UPSERT 是什么？

UPSERT 即 ON CONFLICT DO UPDATE，当主键冲突时自动更新其他字段。

数据安全吗？

所有处理在浏览器本地完成，数据不会上传到任何服务器。
