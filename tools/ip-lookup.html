IP 地址查询

查询当前 IP 地址、地理位置、ISP 信息，快速了解网络连接详情

🔒 隐私说明：查询在你的浏览器中直接请求公开的 ip-api.com 接口，我们不会存储你的 IP 地址或查询记录。

关于这个工具

IP 地址查询工具可以即时显示你当前的公网 IP 地址，以及基于该 IP 的地理位置信息，包括国家、省/州、城市、邮政编码、经纬度和时区。同时展示网络运营商（ISP）、所属组织和自治系统编号（ASN），帮助你快速了解自己的网络连接来源，或排查网络、代理、VPN 相关问题。

你也可以在输入框中填入任意 IP 地址进行查询，工具会调用免费的公开接口 ip-api.com 返回结果。所有请求都在你的浏览器中直接发起，我们不会存储你的 IP 地址或查询记录。查询结果支持一键复制，并可在地图上查看大致地理位置，方便调试、分析日志或了解服务器归属地。

主要功能

  • 一键查询当前公网 IP 地址
  • 支持查询任意指定 IP 地址
  • 显示国家、省/州、城市、邮编
  • 显示经纬度与时区信息
  • 显示 ISP 运营商、组织与 ASN
  • 可在地图上查看大致位置
  • 查询结果一键复制
  • 浏览器直连，不存储你的 IP

常见问题

这个工具会存储我的 IP 地址吗？

不会。查询在你的浏览器中直接请求公开的 ip-api.com 接口，我们不记录或存储你的 IP 地址和任何查询记录。

为什么显示的城市或位置不准确？

IP 地理定位是基于运营商分配的数据库估算的，通常能精确到城市级别，但可能存在偏差，尤其在使用移动网络、VPN 或代理时。它不代表你的精确物理地址。

可以查询别人的 IP 地址吗？

可以在输入框中填入任意公网 IP 地址（如 8.8.8.8）查询其归属地和运营商信息，但无法查询内网 IP（如 192.168.x.x）。

查询失败或没有结果怎么办？

免费接口对 HTTPS 页面可能存在请求频率限制，稍等片刻再试即可。也可能是网络问题或浏览器插件拦截了请求。

什么是 ASN 和 ISP？

ISP 是为你提供网络接入的运营商，ASN（自治系统编号）是互联网上标识一个独立网络的编号，常用于网络路由和溯源分析。
