图片 Base64 编码

将图片转换为 Base64 Data URL

关于这个工具

在线将图片转换为 Base64 Data URL，可直接嵌入 CSS、HTML 中，无需额外 HTTP 请求。支持 JPG、PNG、GIF、SVG、WebP 格式。

主要功能

  • 转换 JPG、PNG、GIF、SVG、WebP 为 Base64
  • 拖拽上传
  • 预览编码后的图片
  • 复制为 Data URL、CSS background 或 HTML img 标签
  • 显示文件大小和压缩信息

常见问题

Base64 图片有什么好处？

Base64 图片消除了 HTTP 请求，非常适合小图标和缩略图。它们直接嵌入代码中，简化了部署流程。

文件大小开销是多少？

Base64 编码会使文件大小增加约 33%。仅适用于小图片（<10KB）。大图片应保留为单独文件。
