INI 配置文件转换器

INI 与 JSON、YAML、TOML 格式互转，支持嵌套节和注释处理

关于这个工具

免费在线 INI 配置文件转换工具，支持 INI 与 JSON/YAML/TOML 之间的双向互转。自动处理嵌套节、注释去除、类型推断和缩进控制。

  • INI → JSON：转换为标准 JSON
  • INI → YAML：适合 CI/CD 配置
  • INI → TOML：兼容 Python/Go 项目
  • 反向转换：JSON/YAML/TOML → INI

所有处理在浏览器本地完成。

主要功能

  • 支持 INI ↔ JSON/YAML/TOML 双向互转
  • 自动处理嵌套节：section.sub.key
  • 智能类型推断：数字/布尔值
  • 保留或去除 INI 注释

常见问题

嵌套节怎样处理？

点号语法如 [database.replica] 解析为嵌套结构。

数据安全吗？

所有处理在浏览器本地完成，不上传。
