CSS 转 SCSS/SASS

将扁平 CSS 转换为嵌套结构的 SCSS/SASS 代码

关于这个工具

免费的在线 CSS 转 SCSS/SASS 工具，将扁平 CSS 代码转换为嵌套结构的 SCSS 或 SASS 代码。自动识别层叠选择器并创建父子嵌套，支持 SCSS 和 SASS 两种语法格式输出。

适用场景：迁移到 SCSS/SASS 项目、代码重构、CSS 代码组织优化。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 一键将扁平 CSS 转换为嵌套 SCSS/SASS
  • 自动识别层叠选择器创建父子嵌套
  • 支持 SCSS (花括号) 和 SASS (缩进) 两种语法
  • 保留所有 CSS 声明和值
  • 实时统计规则数和字符数
  • 一键复制生成的代码
  • 浏览器本地处理，数据不上传

常见问题

SCSS 和 SASS 有什么区别？

SCSS 使用花括号 {} 和分号 ;，与 CSS 语法兼容。SASS 使用缩进语法，更简洁。

嵌套规则准确吗？

工具通过选择器前缀匹配尝试嵌套，适用于常见的父子层级结构。

转换后的代码可以直接使用吗？

生成的 SCSS/SASS 语法正确，可直接在项目中使用。

支持 @media 等 at-rule 吗？

支持。@media 等 at-rule 会被保留在顶层。

数据安全吗？

所有处理在浏览器本地完成，数据不会上传到任何服务器。
