JSON 转 Python 类

将 JSON 转换为 Python dataclass/class 定义代码

关于这个工具

免费的 JSON 转 Python 类生成器，将 JSON 对象或数组自动转换为 Python 类定义代码。支持 @dataclass 装饰器、类型注解（typing 模块）、蛇形命名、可选字段推断。

常见应用场景：API 开发、数据解析、代码生成、快速原型。所有处理在浏览器本地完成，数据不会上传到任何服务器。

主要功能

  • 自动将 JSON 转换为 Python 类定义
  • 支持 @dataclass 装饰器
  • 支持 Python typing 类型注解
  • 支持蛇形命名转换
  • 可选字段推断
  • 自动处理嵌套对象生成子类
  • 自动处理数组元素生成 List 类型
  • 一键复制生成的 Python 代码

常见问题

生成的 Python 类可以直接用吗？

可以。生成的代码包含完整的类定义和类型注解，直接复制到你的 Python 项目中使用。

@dataclass 和普通类有什么区别？

@dataclass 自动生成 __init__、__repr__、__eq__ 等方法，适合数据容器。

什么是可选字段？

当 JSON 中某个字段值为 null 时，启用可选字段会将其类型标记为 Optional[Type]，并赋予默认值 None。

支持嵌套 JSON 吗？

支持。嵌套的 JSON 对象会自动生成对应的子类。

数据安全吗？

所有处理在浏览器本地完成，数据不会上传到任何服务器。
