JSON 转 TOML

将 JSON 数据快速转换为 TOML 格式，支持嵌套对象和数组

关于这个工具

免费的在线 JSON 转 TOML 工具，将 JSON 对象快速转换为 TOML 格式。TOML 是一种广泛应用于配置文件（如 Cargo.toml、pyproject.toml）的格式，以可读性强著称。

支持嵌套对象、数组、字符串、数字、布尔值、null 等所有 JSON 数据类型。自动识别数组是纯值列表（转为 TOML 内联数组）还是对象数组（转为 TOML 表数组）。所有处理在浏览器本地完成，数据不会上传到服务器。

主要功能

  • JSON 对象快速转换为 TOML 格式
  • 支持嵌套对象自动转 TOML 节(section)
  • 智能识别数组类型（值列表 vs 表数组）
  • 支持字符串、数字、布尔值、null 等类型
  • 处理特殊字符自动转义
  • 一键复制或下载结果
  • 零数据上传，浏览器本地处理
  • 支持 TOML v1.0 规范

常见问题

JSON 转 TOML 支持哪些 JSON 类型？

支持字符串、数字、布尔值、null、嵌套对象、数组、混合类型数组等所有 JSON 数据类型。

嵌套对象怎么转换为 TOML？

嵌套对象会自动转为 TOML 的节（section）表示，如 a.b.c 会转为 [a.b] 下的 c。

数组怎么处理？

纯值数组（如 [1, 2, 3]）转为 TOML 内联数组；对象数组（如 [{a:1}, {a:2}]）转为 TOML 表数组 [[array]]。

数据会上传到服务器吗？

不会。所有处理在浏览器本地完成，无需上传。

TOML 和 YAML 有什么区别？

TOML 侧重可读性，适合配置文件；YAML 更灵活但语法复杂。两者各有适用场景。

支持 TOML v1.0 规范吗？

是的。输出遵循 TOML v1.0 规范，包括内联表、表数组、多行字符串等特性。
