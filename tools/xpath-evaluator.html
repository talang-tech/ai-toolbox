XPath 表达式测试器

在线测试和调试 XPath 表达式，支持 XML/HTML 文档，实时高亮匹配节点

关于这个工具

免费的在线 XPath 表达式测试器，让您快速测试、调试和验证 XPath 表达式。输入 XML/HTML 文档和 XPath 表达式，实时高亮显示匹配的节点及其文本内容。支持所有 XPath 1.0 核心语法，包括路径表达式、谓语、轴、通配符、运算符和内置函数。

本工具适合 前端开发者、数据处理工程师、测试工程师、爬虫开发者 等需要频繁处理 XML/HTML 文档的人群。所有处理在浏览器本地完成，文档内容不会上传到服务器，隐私安全有保障。

  • 支持所有 XPath 1.0 核心语法：路径、谓语、轴、函数
  • 实时高亮匹配节点，显示节点文本和属性
  • 支持 XML 和 HTML 文档输入

常见问题

XPath 和 CSS 选择器有什么区别？

XPath 可以沿 DOM 树向上/向下/横向遍历，功能更强大；CSS 选择器只能向下选择子元素。XPath 支持文本匹配、位置计算等高级功能。

支持 XPath 2.0 或 3.0 吗？

本工具使用浏览器内置的 document.evaluate()，支持 XPath 1.0 完整语法。XPath 2.0/3.0 需要外部库支持，暂未包含。

支持 HTML 命名空间吗？

支持。输入 HTML 文档时，工具会自动处理 HTML 命名空间。您也可以使用 local-name() 函数忽略命名空间匹配。

数据安全吗？

完全安全。所有 XPath 求值在浏览器本地完成，文档内容不会上传到任何服务器。

支持哪些 XPath 轴？

支持所有 XPath 1.0 轴：child, parent, ancestor, descendant, following, preceding, following-sibling, preceding-sibling, attribute, self, descendant-or-self, ancestor-or-self 等。

最大支持多大的文档？

建议 XML/HTML 文档不超过 500KB，以免影响浏览器性能。超出时会截断提示。

可以调试 XPath 函数吗？

支持所有 XPath 1.0 内置函数：string(), count(), concat(), substring(), contains(), starts-with(), normalize-space(), translate(), not(), boolean(), number(), sum(), floor(), ceiling(), round() 等。

匹配结果可以导出吗？

匹配结果以文本形式展示，支持一键复制到剪贴板，方便后续使用。
