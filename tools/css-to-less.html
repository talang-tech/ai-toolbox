CSS 转 LESS

将扁平 CSS 转换为嵌套结构的 LESS 代码

关于这个工具

免费的在线 CSS 转 LESS 工具，将扁平 CSS 代码转换为嵌套结构的 LESS 代码。自动识别层叠选择器并创建父子嵌套，保留所有 CSS 声明。

主要功能

  • 一键将扁平 CSS 转换为嵌套 LESS
  • 自动识别层叠选择器创建父子嵌套
  • 保留所有 CSS 声明和注释
  • 支持 @media 等 at-rule 保留
  • 实时统计规则数和字符数
  • 一键复制生成的 LESS 代码
  • 浏览器本地处理，数据不上传

常见问题

CSS 和 LESS 有什么区别？

LESS 是 CSS 预处理器，支持嵌套、变量、混合、函数等特性。

嵌套规则准确吗？

工具通过选择器前缀匹配实现嵌套，适用于常见的层级结构。

转换后的 LESS 可以直接使用吗？

生成的 LESS 代码语法正确，可直接在支持 LESS 的项目中使用。

支持 @media 查询吗？

支持。@media 规则会被保留在顶层。

数据安全吗？

所有处理在浏览器本地完成，数据不会上传到任何服务器。
