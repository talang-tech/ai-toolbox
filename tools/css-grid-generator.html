常见问题

CSS Grid 和 Flexbox 有什么区别？

Grid 是二维布局（行和列同时控制），Flexbox 是一维布局（行或列）。Grid 适合整体页面布局，Flexbox 适合组件内部排列。

什么是 1fr 单位？

1fr 是 CSS Grid 的弹性单位，代表剩余空间的一份。1fr 1fr 1fr 表示三列均分剩余宽度。

gap 和 grid-gap 有什么区别？

gap 是标准属性，grid-gap 已废弃。建议使用 gap 同时设置行间距和列间距。

justify-content 和 justify-items 有什么区别？

justify-content 控制整个网格在容器中的水平对齐，justify-items 控制网格内项目的水平对齐。
