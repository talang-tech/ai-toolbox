HTML 转 Pug

将 HTML 标签转换为 Pug/Jade 模板语法，支持类和 ID 简写

🔒 隐私提示：所有处理在浏览器本地完成，数据不会上传到服务器。

关于这个工具

免费的在线 HTML 转 Pug 转换器，帮助 Node.js 开发者将 HTML 标签快速转换为 Pug（原 Jade）模板语法。支持元素标签、属性、类名、ID、文本内容、嵌套结构的完整转换。所有处理在浏览器本地完成。

主要功能

  • HTML 自动转换为 Pug 缩进语法
  • 支持类名和 ID 简写
  • 支持所有 HTML 属性和布尔属性
  • 支持自闭合标签
  • 支持嵌套元素结构
  • 一键复制 Ctrl+Enter 快捷键
  • 浏览器本地处理，数据不上传

常见问题

Pug 和 Jade 是什么关系？

Pug 原名 Jade，是 Node.js 平台最流行的模板引擎之一。

转换后的代码可以直接使用吗？

可以。符合 Pug 2.x 语法规范。

数据会被上传吗？

不会。所有转换在浏览器本地完成。

支持 HTML5 元素吗？

支持所有标准 HTML 元素。
