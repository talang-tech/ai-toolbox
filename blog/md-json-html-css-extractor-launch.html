新增 Markdown 表格转 JSON 和 HTML 提取 CSS 工具

本周我们新增了两个实用的开发者工具：

🔄 Markdown 表格转 JSON

很多开发者日常在 GitHub Issues、README 或文档中使用 Markdown 表格，但需要将表格数据导入代码或数据库时，手动转换非常繁琐。

这个新工具支持：

  • 将 Markdown 表格解析为 JSON 对象数组，首行自动作为键名
  • 也支持纯数组格式，所有行作为数据返回
  • 列名中的特殊字符自动转换为合法 JSON 键名（中文保留）
  • 实时转换，粘贴即可看到结果
  • 一键复制 JSON 输出

适用场景：

  • 将 GitHub Issue 或 README 中的表格数据导入数据库
  • 构建 API 测试数据
  • 数据分析脚本的数据准备
  • 自动化测试 fixture 生成

🎨 HTML 提取 CSS 选择器

在接手遗留项目、CSS 重构或 HTML 分析时，经常需要快速了解 HTML 中使用了哪些 CSS 类名和 ID。这个工具自动从 HTML 中提取所有选择器并生成 CSS 骨架。

主要功能：

  • 提取所有 CSS 类名（.classname 格式）
  • 提取所有 ID 选择器（#id 格式）
  • 提取所有 HTML 标签
  • 三种模式：类名、ID、标签或全部提取
  • 自动生成 CSS 骨架代码，方便快速填充样式
  • 实时提取，输入即结果

适用场景：

  • 前端开发调试，快速了解 HTML 结构对应的样式
  • CSS 重构，从 HTML 中提取所有引用选择器
  • 学习他人代码，分析现有 HTML 的样式结构
  • 创建新页面的 CSS 骨架，避免遗漏选择器

其他更新

  • CSS Box Shadow Generator 工具已上线，支持可视化生成 box-shadow
  • CSS Unit Converter 支持 px、em、rem、%、vw、vh 等常见单位互转
  • CSS Media Query Generator 提供可视化断点配置
  • 优化了隐私说明提示，所有工具强制显示"浏览器本地处理，不上传数据"

关于数据隐私

所有新工具均遵循隐私优先原则：所有处理在浏览器本地完成，HTML 代码和表格数据不会上传到服务器。你可以放心使用，即使处理敏感的业务数据也不会有泄露风险。
