新增 Mock 数据生成器和 TOML JSON 互转工具

2026 年 7 月 31 日

AI 工具盒子今天新增两款实用工具：Mock 数据生成器和TOML JSON 互转工具，进一步丰富开发者工具箱。

🧪 Mock 数据生成器

测试数据是开发过程中不可或缺的一环，但手动构造数据既耗时又容易遗漏边界情况。Mock 数据生成器帮助开发者快速生成逼真的测试数据，支持 15 种字段类型：

  • 基础信息：姓名、邮箱、电话、地址
  • 职业信息：公司、职位、薪资
  • 标识信息：ID、社保号、信用卡号（仅测试用）
  • 网络信息：网址、IP 地址
  • 其他：出生日期、颜色、描述文本

支持三种输出格式：JSON（适合 API 开发）、CSV（适合导入电子表格）、Markdown 表格（适合文档展示）。可以自由组合字段，生成 1 到 1000 条记录。

所有数据在浏览器本地生成，不会上传到服务器，保证数据安全。

🔄 TOML JSON 互转工具

TOML 作为简洁易读的配置文件格式，在 Rust（Cargo.toml）、Python（pyproject.toml）生态中越来越流行。TOML JSON 互转工具支持双向转换：

  • TOML → JSON：将配置文件转为 JSON 供 API 或脚本使用
  • JSON → TOML：将 JSON 数据转为 TOML 配置文件格式
  • 支持标准 TOML 语法：表、表数组、内联表、字符串、数字、布尔值
  • 一键互换方向，方便来回调试
