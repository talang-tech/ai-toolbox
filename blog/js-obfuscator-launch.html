🔒 JavaScript 混淆器上线，三种等级保护前端代码

AI 工具盒子今天新增 JavaScript 混淆器，帮助开发者保护前端 JS 代码，防止轻易被逆向分析。支持三种混淆等级，内置代码美化器，所有处理在浏览器本地完成。

三种混淆等级

轻度（Light）

  • 变量自动重命名为短名称（如 _0xa, _0xb...）
  • 注释和多余空白删除
  • 适合日常代码保护，不影响可读性

中度（Medium）

  • 包含轻度所有功能
  • 字符串自动拆分拼接（"hello" → "he" + "llo"）
  • 增加逆向难度

重度（Heavy）

  • 包含中度的所有功能
  • 数字转十六进制编码（42 → 0x2a）
  • 最高级别的保护

内置代码美化器

混淆后的代码可以直接用内置美化器一键还原格式，方便调试。变量名无法还原，但格式恢复后更易阅读。

使用场景

  • 保护前端业务逻辑：混淆核心算法，防止被轻易复制
  • 保护 API 密钥：增加逆向成本
  • 代码安全审计：测试你自己的代码抗混淆能力
  • 学习混淆原理：通过实际观察理解混淆机制

隐私优先

所有处理在浏览器本地完成，代码不会上传到任何服务器。这也是 AI 工具盒子一贯的设计原则。
