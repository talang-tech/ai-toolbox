# CSS 媒体查询生成器：在线可视化生成响应式断点

## 什么是 CSS 媒体查询？

CSS 媒体查询（@media）是响应式 Web 设计的核心技术。它允许你根据设备的特性（如视口宽度、屏幕方向、分辨率等）应用不同的 CSS 样式，让同一个网站在手机、平板、笔记本和桌面等各种设备上都能呈现出最佳效果。

## 为什么需要媒体查询生成器？

虽然手写媒体查询并不复杂，但使用可视化生成器能带来这些好处：

**快速原型开发**：不用写代码就能测试不同断点效果。

**学习响应式设计**：直观理解 min-width（移动优先）和 max-width（桌面优先）的区别。

**预设断点参考**：常见设备断点作为起点，省去查阅文档的时间。

**减少语法错误**：避免手写 @media 规则时的拼写或格式错误。

**提升开发效率**：一键生成标准代码，直接粘贴使用。

## 代码示例

### 移动优先（推荐）
```css
@media (min-width: 768px) {
  /* 平板及以上设备 */
  .container {
    max-width: 720px;
  }
}
```

### 桌面优先
```css
@media (max-width: 768px) {
  /* 手机和平板设备 */
  .sidebar {
    display: none;
  }
}
```

### 带方向检测
```css
@media (min-width: 768px) and (orientation: landscape) {
  /* 横屏平板 */
  .gallery {
    grid-template-columns: repeat(3, 1fr);
  }
}
```
