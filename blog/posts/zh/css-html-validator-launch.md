# 🎨 CSS 验证器和 HTML 验证器上线

AI 工具盒子新增两款强大的代码质量检查工具，帮助开发者快速发现 CSS 和 HTML 代码中的错误、最佳实践问题和可访问性隐患。

## CSS 验证器

新的 [CSS 验证器](/tools/css-validator) 可以检查 CSS 代码中的多种常见问题，无需将代码发送到服务器：

- **语法错误检测**：未闭合的大括号、括号、方括号
- **属性检查**：识别未知 CSS 属性名，避免拼写错误
- **重复选择器**：发现重复的 CSS 选择器定义
- **缺失单位警告**：检测长度属性缺少单位（如 `width: 100` 而不是 `width: 100px`）
- **颜色值验证**：检查无效的十六进制颜色值
- **重复属性**：同一规则内重复声明相同属性
- **空规则**：选择器后没有任何声明
- **@import 位置**：确保 import 语句位于样式表顶部

所有检查在浏览器本地完成，代码不会上传到任何服务器，保护你的隐私。

## HTML 验证器

新的 [HTML 验证器](/tools/html-validator) 提供全面的 HTML 代码质量检查：

- **标签嵌套**：验证标签是否正确嵌套，检测未闭合标签
- **重复 ID**：发现页面中重复的 ID 属性
- **弃用元素**：检测 `<center>`、`<font>`、`<blink>` 等已弃用标签
- **弃用属性**：检测 `align`、`bgcolor` 等建议使用 CSS 替代的属性
- **可访问性检查**：提醒缺失的 `alt` 属性、`lang` 属性、`<label>` 关联
- **文档结构**：检查缺失的 DOCTYPE、字符集声明、viewport、标题
- **内联事件处理器**：提醒使用 `onclick` 等内联事件处理器，建议改用 addEventListener
- **空属性**：检测空的 `href` 和 `src` 属性

## 为什么选择本地验证？

与传统的 W3C 验证器不同，我们的工具完全在浏览器中运行，不会将你的代码发送到外部服务器。这意味着：

1. **隐私保护**：敏感的项目代码不会离开你的设备
2. **速度更快**：无需等待网络请求，即时出结果
3. **离线可用**：页面加载后即可离线使用
