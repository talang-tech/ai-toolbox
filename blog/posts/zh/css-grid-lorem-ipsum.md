今天上线了两个新工具：**CSS Grid 生成器** 和 **Lorem Ipsum 生成器**。一个是可视化布局利器，一个是经典占位文本工具，都是前端开发者的日常刚需。

## CSS Grid 生成器

CSS Grid 是二维布局的标准方案，但手写 grid-template 属性组合容易出错。CSS Grid 生成器提供可视化界面，让你：

- 调节 **列数** 和 **行数**（1-8 列/行）
- 控制 **列间距** 和 **行间距**
- 选择 **模板类型**：auto（1fr 弹性均分）或 **固定尺寸**（自定义列宽和行高）
- 配置 **justify-items、align-items、justify-content、align-content**
- 实时预览网格效果，一键复制生成的 CSS 代码

所有 CSS 生成在浏览器本地完成，无需上传数据。

### 典型使用场景

- 快速搭建页面布局原型
- 生成响应式网格模板
- 学习 CSS Grid 属性组合
- 复用现有 CSS 框架的网格配置

## Lorem Ipsum 生成器

经典的拉丁语占位文本生成器，支持四种输出模式：

- **单词**：生成指定数量的独立单词
- **句子**：生成随机句子，自动标点
- **段落**：生成完整段落，支持纯文本和 HTML 格式
- **列表**：生成无序列表（纯文本或 HTML `<ul>`）

内置 200+ 拉丁语词汇库和 15 种经典段落开场语，确保生成的文本看起来自然专业。

### 用法建议

- **排版设计**：用段落模式填充文章布局
- **UI 原型**：用列表模式展示导航或条目
- **代码演示**：用 HTML 格式直接嵌入模板
- **内容填充**：用单词模式快速生成测试数据
