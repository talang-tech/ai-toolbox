AI Toolbox 今天新增两个高频工具：**HTML 标签去除器** 和 **JSON 转 CSV 转换器**。这两个场景都是开发者日常数据整理中的高频需求，而且天然适合浏览器本地处理——完全不需要把数据上传到服务器。

## 🧹 HTML 标签去除器

复制网页内容时经常带进一堆 markup，导致粘贴到文档、邮件或编辑器时全是标签和样式残片。手动清理不仅慢，还容易漏。

[HTML 标签去除工具](/tools/html-stripper) 让你粘贴 HTML 代码，一键提取纯文本。

### 三种处理模式

1. **去除标签（保留内容）**：只删掉 `<div>`、`<span>`、`<p>` 等标签，保留文字内容。适合从富文本编辑器或网页复制内容后清理格式。
2. **去除标签+内容**：同时移除 `<script>`、`<style>`、`<svg>`、`<noscript>`、`<template>` 等标签及其内部内容。适合提取网页正文时顺便去掉埋点和样式定义。
3. **仅解码 HTML 实体**：不删除标签，只将 `&amp;`、`&lt;`、`&nbsp;` 等实体转换为正常字符。适合需要保留 HTML 结构但又要正常显示特殊符号的场景。

### 实用选项

- **保留换行结构**：开启后，`<p>`、`<br>`、`<div>`、`<h1-h6>` 等块级标签被替换为换行符，保留段落结构。关闭后所有内容连成一段。
- **合并多余空格**：自动把连续空格压成一个，让输出更干净。

### 实时统计

粘贴 HTML 后，工具实时显示处理前后的字符数对比和压缩比例，方便评估清理效果。

### 适用场景

- 从网页复制内容粘贴到 Word、邮件、微信公众号编辑器前去掉格式
- 从邮件模板的 HTML 源文件中提取纯文本文案
- 从前端项目代码中提取多语言文案（去掉 JSX/模板标签）
- 从爬虫临时抓取的 HTML 片段中提取正文做粗略阅读

## 📊 JSON 转 CSV 转换器

很多场景都需要把 JSON 数据导出为表格格式——API 响应结果想贴到 Excel 里看看，数据库查询的 JSON 输出要发给同事做数据分析，或者只是想看一眼嵌套对象长什么样。

[JSON 转 CSV 工具](/tools/json-to-csv) 把 JSON 数组或单个对象转成逗号分隔的 CSV。

### 核心能力

- **支持 JSON 数组和单个对象**：数组每对象一行，单个对象转为单行 CSV
- **自动提取所有字段作为列**：合并所有对象中的 key，动态生成表头
- **两种格式模式**：
  - **平铺模式**：每个对象一行，所有 key 作为列
  - **嵌套扁平化**：嵌套对象用点号路径作为列名，例如 `user.address.city`、`profile.avatar.url`
- **支持简单值数组**：`["a", "b", "c"]` 每个值一行

### 分隔符选择

| 分隔符 | 适用场景 |
|--------|----------|
| 逗号 `,` | Excel/WPS 默认格式，最通用 |
| 制表符 `\t` | 字段值可能含逗号时的安全选择 |
| 分号 `;` | Excel 中某些区域设置中 CSV 默认分隔符 |
| 竖线 `\|` | 日志文件或 CLI 工具中常用 |

### 典型场景

- API 响应 JSON 导出为 Excel 表格，非技术团队也能直接看
- 数据库查询结果（JSON 格式）转 CSV 后导入分析工具
- 嵌套配置文件的字段结构可视化——扁平化后一眼看清所有可用字段
- 测试数据从 JSON 转为表格格式给 QA 团队使用
- 把复杂 JSON 转成简单表格，方便发给非技术同事填写补充

两个工具的处理逻辑都在浏览器 JavaScript 中完成，粘贴的 HTML 或 JSON 数据不会离开你的设备。不需要注册、不需要下载、不需要付费。
