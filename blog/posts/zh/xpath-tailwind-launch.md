# 新增 XPath 测试器和 CSS 转 Tailwind 工具

本周我们新增了两个高频开发者工具：

## 🔍 XPath 表达式测试器

支持在线测试和调试 XPath 1.0 表达式，实时高亮匹配节点。支持 XML 和 HTML 文档输入，完整支持路径表达式、谓语、轴、通配符和内置函数。

**适用场景：**
- 前端开发者调试 DOM 选择逻辑
- 数据处理工程师测试 XML 转换
- 爬虫开发者验证 XPath 提取规则
- 测试工程师编写自动化测试脚本

所有处理在浏览器本地完成，文档内容不会上传到服务器。

## 🎨 CSS 转 Tailwind CSS

将传统 CSS 属性转换为 Tailwind CSS 等效类名，支持颜色、间距、Flexbox、Grid、Typography、Border、Shadow 等常用属性映射。颜色值自动匹配最接近的 Tailwind 色板。

**适用场景：**
- 从传统 CSS 迁移到 Tailwind 的项目
- Tailwind 初学者快速查找对应类名
- 代码重构时批量转换 CSS 规则

## 其他更新

- 完善了 JSON Lines 工具的错误处理和示例数据
- 优化了 CSS 属性参考首页的加载性能
- 修复了部分页面在移动端的显示问题
