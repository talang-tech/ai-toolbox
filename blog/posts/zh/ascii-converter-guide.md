# ASCII 转换器：在线字符编码互转工具

## 什么是 ASCII 编码？

ASCII（American Standard Code for Information Interchange，美国信息交换标准代码）是计算机领域最基础的字符编码标准。它使用 7 位或 8 位二进制数来表示 128 或 256 个字符，包括：

- **英文字母**：A-Z（65-90），a-z（97-122）
- **数字**：0-9（48-57）
- **标点符号**：!@#$% 等
- **控制字符**：换行（10）、回车（13）、制表符（9）等
- **扩展 ASCII**：0-255 范围内的特殊符号和外来字母

尽管 Unicode 已经成为现代 Web 的主流编码标准，但 ASCII 作为其子集，在开发工作中仍然频繁使用。

## 为什么需要 ASCII 转换工具？

在日常开发中，你可能会遇到这些场景：

**调试字符编码问题**：当网页显示乱码时，查看字符的 ASCII 码值可以帮助定位问题。

**编写 HTML 实体**：需要在 HTML 中显示特殊字符（如 &lt; &gt; &amp;）时，需要知道它们的编码值。

**处理协议数据**：网络协议、文件格式等技术文档常常使用十六进制或二进制表示字符。

**学习计算机基础**：理解字符如何以二进制形式存储，是学习计算机科学的基础。

**JSON/JavaScript 转义**：\\uXXXX 转义序列在 JSON 和 JavaScript 中表示 Unicode 字符。
