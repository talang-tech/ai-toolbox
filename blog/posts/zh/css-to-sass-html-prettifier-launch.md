## 两个新工具，让前端代码更整洁

今天上线了两个很实用的前端开发工具，都针对开发者日常工作中常见但处理起来又有点烦人的场景。

### 1. CSS 转 SCSS/SASS

如果你正在把项目从纯 CSS 迁移到 SCSS 或 SASS 预处理器，以前可能需要手动一层层加嵌套。现在直接把 CSS 粘贴进来，工具会自动识别层叠选择器，把 `.container .title span` 这样的嵌套结构转换成 SCSS 或 SASS 格式。

**核心功能：**

- 支持 SCSS（花括号语法）和 SASS（缩进语法）两种输出
- 自动识别父子选择器关系并创建嵌套
- 保留所有 CSS 声明和值，不丢失任何属性
- 实时统计规则数和输出字符数

**适用场景：** 项目从 CSS 迁移到 SCSS/SASS、代码重构、CSS 代码组织优化。

### 2. HTML 格式化/美化器

很多时候我们拿到的是压缩过的 HTML 代码（比如从模板引擎输出、从 CDN 下载的页面、或者从 API 返回的 HTML 片段），阅读起来非常痛苦。这个工具可以把它们一键格式化成清晰易读的缩进结构。

**核心功能：**

- 支持 2 空格、4 空格、Tab 三种缩进方式
- 可选空白行压缩
- 智能识别内联元素（`<span>`、`<a>` 等）和块级元素，不会在行内元素上乱换行
- 正确处理 HTML 注释、自闭合标签、空元素
- 统计输入输出字节数变化

**适用场景：** 调试 HTML 模板、阅读压缩 HTML、代码审查、学习 HTML 结构。

### 为什么这两个工具值得试

- **零上传** — 所有处理在浏览器本地完成，不需要担心代码泄露
- **即时响应** — 纯前端 JS 处理，没有网络延迟
- **免费使用** — 没有任何使用限制

### 小提示

CSS 转 SCSS 和之前已有的 CSS 转 LESS 配合使用，可以覆盖主流 CSS 预处理器之间的互转需求。HTML 格式化则和已有的 HTML 压缩器互补 — 一个是压缩，一个是美化，看你需要什么。
