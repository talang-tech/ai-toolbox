## Two New Tools for Cleaner Frontend Code

Two practical frontend development tools launched today, addressing common daily annoyances for developers.

### 1. CSS to SCSS/SASS Converter

If you're migrating a project from plain CSS to SCSS or SASS, you used to manually nest selectors one by one. Now just paste your CSS and the tool automatically detects cascading selectors — converting `.container .title span` into properly nested SCSS or SASS syntax.

**Key features:**

- Supports both SCSS (bracketed) and SASS (indented) syntax output
- Auto-detects parent-child selector relationships for nesting
- Preserves all CSS declarations and values
- Real-time rule count and character stats

**Use cases:** CSS to SCSS/SASS migration, code refactoring, CSS organization optimization.

### 2. HTML Prettifier/Beautifier

Often we get minified or messy HTML — from template engines, CDN pages, or API responses — and it's painful to read. This tool transforms it into clean, properly indented code instantly.

**Key features:**

- Choose between 2-space, 4-space, or Tab indentation
- Optional whitespace collapse
- Smart inline vs block element handling (no spurious line breaks inside `<span>` or `<a>`)
- Proper handling of HTML comments, self-closing tags, and empty elements
- Input/output size comparison

**Use cases:** Debugging HTML templates, reading minified HTML, code review, learning HTML structure.

### Why Try These Tools

- **Zero upload** — All processing happens locally in your browser
- **Instant response** — Pure frontend JS, no network latency
- **Free** — No usage limits of any kind
