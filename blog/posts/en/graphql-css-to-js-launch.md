# ⚡ GraphQL Formatter and CSS to JS Converter Launched

AI Toolbox adds two high-value developer tools today: **GraphQL Formatter** and **CSS to JS Converter**.

## GraphQL Formatter

The new [GraphQL Formatter](/en/tools/graphql-formatter) formats GraphQL queries, mutations, and subscriptions with basic syntax validation.

- Format query/mutation/subscription with clean indentation
- Handle strings, block strings, and comments correctly
- Basic syntax validation: brace matching, operation naming suggestions
- Empty selection set and directive prefix detection

All processing is 100% local in your browser. No data upload.

## CSS to JS Converter

The new [CSS to JS Converter](/en/tools/css-to-js) converts standard CSS styles to CSS-in-JS format for React/TypeScript projects. Three output modes:

**JS Object mode** — for React style objects, makeStyles, Emotion css function

**Inline Style mode** — for React JSX style attribute

**styled-components mode** — for styled-components and Emotion styled API

Smart value handling: numbers stay as numbers, dimension values become strings, function calls and CSS variables are preserved as strings. Built-in mapping for 200+ CSS properties.

## Why Local Processing?

Like all AI Toolbox tools, these run entirely in your browser:

1. **Privacy** — your code never leaves your device
2. **Speed** — instant results, no server wait
3. **Offline** — works even without internet after page load
