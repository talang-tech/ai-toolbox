# 🔄 CSS to SCSS/SASS and HTML to Pug Converters Launched

AI Toolbox adds two new code conversion tools today: **CSS to SCSS/SASS Converter** and **HTML to Pug Converter** to help frontend developers with style and template format conversions.

## CSS to SCSS/SASS Converter

The new [CSS to SCSS/SASS Converter](/en/tools/css-to-scss) converts standard CSS to SCSS or SASS nested syntax. Perfect for refactoring legacy projects or learning CSS preprocessing.

**Key Features:**

- **Auto-nesting**: Smart parent-child selector detection, auto-generates nested structure
- **Dual format output**: SCSS (braces) and SASS (indentation) syntax
- **Variable extraction**: Auto-extracts CSS custom properties to SCSS variables
- **One-click copy**: Ctrl+Enter shortcut for quick conversion

## HTML to Pug Converter

The new [HTML to Pug Converter](/en/tools/html-to-pug) converts HTML tags to Pug (formerly Jade) template syntax with class/ID shorthand, attribute support, and self-closing tags.

**Key Features:**

- **Full syntax conversion**: Elements, attributes, classes, IDs, text content
- **Smart shorthand**: Auto-converts class and id to .class and #id notation
- **Self-closing tags**: Correctly handles img, br, input, etc.
- **Nested structure**: Preserves original HTML hierarchy

## Why Local Processing?

Like all AI Toolbox tools, these run entirely in your browser:

1. **Privacy** — your code never leaves your device
2. **Speed** — instant results, no server wait
3. **No installation** — no Node.js or preprocessor tools needed

## Use Cases

- SCSS migration: Refactor legacy CSS to SCSS
- Template conversion: Migrate HTML to Express.js Pug views
- Learning: Understand CSS nesting and Pug indentation syntax
- Batch processing: Convert large numbers of style and template files
