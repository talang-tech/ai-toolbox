JSON 转义 & HTML 转纯文本：两个实用新工具上线

2026-07-11 · 4 分钟阅读

今天上线了两个开发者日常高频使用的工具：JSON 转义/反转义工具 和 HTML 转纯文本工具。

JSON 转义/反转义工具

把 JSON 嵌入代码字符串是编程中的常见操作。无论是 JavaScript 中拼接字符串、Python 日志中打印 JSON 对象，还是将 JSON 作为 API 参数传递，都需要先转义 JSON 中的特殊字符。

这个工具提供两个核心功能：

  • 转义：将 JSON 文本转换成字符串字面量格式，自动添加引号，转义换行符、引号、反斜杠等字符
  • 反转义：将转义后的字符串还原为可读的 JSON 文本，并自动验证 JSON 有效性

使用场景

  • 调试日志：把 JSON 打印到日志文件，用 JSON.stringify() 转义后写入
  • 代码嵌入：将 JSON 配置嵌入到 JavaScript/Python 代码字符串中
  • API 测试：从 API 返回的 JSON 中提取字符串，需要先反转义
  • 代码生成：生成包含 JSON 字面量的代码片段

示例

输入 JSON：


{"name": "张三", "age": 30, "bio": "你好\n世界"}

转义后：


"{\"name\": \"张三\", \"age\": 30, \"bio\": \"你好\\n世界\"}"

HTML 转纯文本工具

从网页复制内容经常带着大量 HTML 标签和样式，手动清理很麻烦。HTML 转纯文本工具可以一键提取干净文本。

功能亮点：

  • 自动去除所有 HTML 标签、脚本、样式
  • 保留链接：可选择显示为"文本(URL)"格式
  • 标题标记：可选择用 # 格式保留标题层级
  • 智能换行：块级元素自动换行，保持可读性
  • 统计信息：显示字符缩减率和处理耗时

使用场景

  • 整理网页内容：从文章中提取文字，去除干扰元素
  • 清理富文本粘贴：从 Word 或网页复制内容时，去除格式
  • 邮件内容提取：从 HTML 邮件中提取纯文本
  • 内容分析：统计网页正文字数、关键词密度

关于隐私

两个工具的所有处理都在浏览器本地完成，文本不会上传到任何服务器。你可以放心使用，即使处理敏感数据也不会泄露。
