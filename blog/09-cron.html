Cron 表达式完全指南：从入门到精通

Cron 表达式是定时任务的通用语言，从 Linux 的 crontab 到 Kubernetes 的 CronJob，从 GitHub Actions 到 AWS CloudWatch Events，几乎所有定时调度系统都使用 Cron 语法。

Cron 的字段结构

最常见的是5 字段格式：


* * * * *
│ │ │ │ │
│ │ │ │ └─── 星期 (0-6，0=周日)
│ │ │ └───── 月份 (1-12)
│ │ └─────── 日期 (1-31)
│ └───────── 小时 (0-23)
└─────────── 分钟 (0-59)

部分系统（Quartz、AWS）使用6 字段（加秒）或7 字段（加年）。本文聚焦最通用的 5 字段格式。

特殊符号含义

符号 含义 示例
* 任意值 * = 每分钟
, 枚举多个值 0,30 = 每小时第 0 和 30 分钟
- 范围 0 9-18 * = 9 点到 18 点的每小时第 0 分钟
/ 步长 /5 * = 每 5 分钟

常见场景实例

分钟级任务


* * * * *          # 每分钟
*/5 * * * *        # 每 5 分钟
0,30 * * * *       # 每半小时（0 和 30 分）
15,45 * * * *      # 每小时第 15 和 45 分

小时级任务


0 * * * *          # 每小时整点
0 */6 * * *        # 每 6 小时（0, 6, 12, 18 点）
0 9-18 * * *       # 工作日 9 点到 18 点，每小时整点
30 2 * * *         # 每天凌晨 2:30

每日任务


0 2 * * *          # 每天凌晨 2 点
0 2 * * 1-5        # 每周一到周五凌晨 2 点（工作日）
0 2 * * 0,6        # 每周六、周日凌晨 2 点（周末）
0 2,14 * * *       # 每天 2 点和 14 点

每周任务


0 3 * * 1          # 每周一凌晨 3 点
0 3 * * 5          # 每周五凌晨 3 点
0 9 * * 1,3,5      # 周一、周三、周五早上 9 点

每月任务


0 4 1 * *          # 每月 1 号凌晨 4 点
0 4 1,15 * *       # 每月 1 号和 15 号凌晨 4 点
30 4 L * *         # 每月最后一天凌晨 4:30（需系统支持 L 语法）

复杂组合


0 */2 1-10 * *     # 每月 1-10 号，每 2 小时整点
*/30 9-17 * * 1-5  # 工作日 9:00-17:00，每 30 分钟
0 2 * * 1#2        # 每月第二个周一凌晨 2 点（需系统支持 # 语法）

Cron 经典陷阱

陷阱 1：日期和星期是 OR 关系


0 2 15 * 5    # ❗ 不是"15号且周五"，而是"15号 OR 周五"！

这是 Cron 最容易踩坑的地方。当你同时指定日期和星期，条件是或（满足任一即可），而不是且。

如果需要"15号且是周五才执行"，需要在脚本中额外判断。

陷阱 2：时区问题

Cron 使用系统本地时区。你的服务器可能不是北京时间！


date  # 查看系统时区

在容器环境尤其要注意时区配置。

陷阱 3：步长不是从 0 开始


*/5 * * * *    # 0,5,10,15,...55 分 ✅
1-59/5 * * * * # 1,6,11,...56 分 ❗

陷阱 4：日期间隔的月份天数问题


0 2 */15 * *   # 每 15 天，但 2 月只有 28 天
                 # 30/31 号可能在下个月不存在

陷阱 5：输出和日志

Cron 任务的 stdout/stderr 默认会发邮件，但很多系统没有配置邮件服务。

✅ 最佳实践：重定向输出到日志


0 2 * * * /path/to/script.sh >> /var/log/cron/script.log 2>&1

环境变量问题

Cron 执行时的 PATH 非常有限，常见问题：

❌ 出错：command not found

✅ 解决：脚本开头设置完整 PATH，或者使用绝对路径


#!/bin/bash
export PATH="/usr/local/bin:/usr/bin:/bin"

不同实现的差异

实现 字段数 特殊语法支持
Linux crontab 5 基础语法
Vixie Cron 5 @reboot, @yearly, etc.
Quartz 6-7 L, W, #
Kubernetes CronJob 5 基础语法
GitHub Actions 5 标准 POSIX
AWS CloudWatch 6 L, W, #

常用简写


@reboot    # 启动时执行一次
@yearly    # 每年一次 (0 0 1 1 *)
@monthly   # 每月一次 (0 0 1 * *)
@weekly    # 每周一次 (0 0 * * 0)
@daily     # 每天一次 (0 0 * * *)
@hourly    # 每小时一次 (0 * * * *)
