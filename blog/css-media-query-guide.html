CSS 媒体查询生成器：在线可视化生成响应式断点

什么是 CSS 媒体查询？

CSS 媒体查询（@media）是响应式 Web 设计的核心技术。它允许你根据设备的特性（如视口宽度、屏幕方向、分辨率等）应用不同的 CSS 样式，让同一个网站在手机、平板、笔记本和桌面等各种设备上都能呈现出最佳效果。

为什么需要媒体查询生成器？

虽然手写媒体查询并不复杂，但使用可视化生成器能带来这些好处：

快速原型开发：不用写代码就能测试不同断点效果。

学习响应式设计：直观理解 min-width（移动优先）和 max-width（桌面优先）的区别。

预设断点参考：常见设备断点作为起点，省去查阅文档的时间。

减少语法错误：避免手写 @media 规则时的拼写或格式错误。

提升开发效率：一键生成标准代码，直接粘贴使用。

工具功能

我们的 CSS 媒体查询生成器 提供以下核心功能：

1. 6 种设备断点预设

  • 📱 手机：480px
  • 📱 小平板：640px
  • 📱 平板：768px
  • 💻 笔记本：1024px
  • 🖥️ 桌面：1280px
  • 🖥️ 大屏：1440px

2. 两种模式

  • min-width（移动优先）：先写小屏样式，逐步为大屏增强
  • max-width（桌面优先）：先写大屏样式，再为小屏适配

3. 方向检测

支持 orientation: portrait（竖屏）和 orientation: landscape（横屏）。

4. 自定义断点

自由输入任意像素值，灵活控制断点位置。

5. 一键复制

生成的 @media 规则代码可直接粘贴到样式文件中。

代码示例

移动优先（推荐）


@media (min-width: 768px) {
  /* 平板及以上设备 */
  .container {
    max-width: 720px;
  }
}

桌面优先


@media (max-width: 768px) {
  /* 手机和平板设备 */
  .sidebar {
    display: none;
  }
}

带方向检测


@media (min-width: 768px) and (orientation: landscape) {
  /* 横屏平板 */
  .gallery {
    grid-template-columns: repeat(3, 1fr);
  }
}

常用断点策略

一个常见的响应式断点系统：

断点 宽度 目标设备
xs < 480px 小屏手机
sm ≥ 480px 大屏手机
md ≥ 768px 平板
lg ≥ 1024px 笔记本/小桌面
xl ≥ 1280px 桌面显示器
xxl ≥ 1440px 大屏显示器
