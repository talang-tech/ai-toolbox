为什么需要进制转换工具？

在开发工作中，进制转换是最常见的需求之一。调试网络协议时看到的十六进制报文、分析二进制文件时的字节数组、配置颜色值时的十六进制 RGB、查看日志时的 ASCII 编码——这些场景都需要开发者灵活地在不同进制之间切换。

大部分操作系统自带的计算器虽然支持进制转换，但功能有限，不支持批量转换、文本编码转进制、字节数组格式等高级功能。一个专门的在线工具可以大幅提升效率。

常见进制转换场景

1. 网络协议调试

HTTP 请求的二进制数据包、TCP 报文、WebSocket 帧——这些底层协议调试最常见的就是十六进制和二进制之间的转换。例如：

  • 十六进制 48656C6C6F → ASCII 文本 Hello
  • 二进制 01001000 01101001 → 十进制 72 105 → ASCII Hi

2. 文件编码分析

查看文件头（magic number）来判断文件类型：

  • PDF 文件头：25 50 44 46 (十六进制) → %PDF (ASCII)
  • PNG 文件头：89 50 4E 47 → .PNG
  • ZIP 文件头：50 4B 03 04 → PK..

3. 颜色值转换

Web 开发中常需要在十六进制和十进制 RGB 之间转换：

  • #FF5733 → 十六进制 FF 57 33 → 十进制 255 87 51
  • 二进制 11111111 01010111 00110011 → RGB(255, 87, 51)

4. 字节数组操作

在嵌入式开发、C/C++ 编程中，字节数组是常见的数据格式：

  • 字节数组 0x48 0x65 0x6C 0x6C 0x6F → 字符串 Hello
  • 字符串 世界 → 字节数组 (UTF-8) 0xE4 0xB8 0x96 0xE7 0x95 0x8C

进制转换技巧

  1. 十六进制快速转十进制：0xFF = 15×16 + 15 = 255，0xA0 = 10×16 + 0 = 160
  2. 二进制快速转十六进制：每 4 位二进制对应 1 位十六进制，1101 1010 = DA
  3. 十进制转十六进制：除以 16 取余数，从后往前排列
  4. ASCII 码记住关键值：A=65(0x41)、a=97(0x61)、0=48(0x30)、空格=32(0x20)
