程序员必备：二进制、八进制、十进制、十六进制完全指南

作为程序员，每天都在和各种进制打交道，但真正理解背后原理的人并不多。

为什么计算机用二进制？

计算机由数字电路组成，电路只有"通"和"断"两种状态，对应 0 和 1。

这就是二进制成为计算机基础语言的根本原因：最简单的物理实现。

进制基础

什么是进制？

进制就是进位制。N 进制就是"逢 N 进一"。

进制 基数 符号集 前缀表示法 典型场景
二进制 2 0, 1 0b 机器码、位运算、标志位
八进制 8 0-7 0 / 0o Linux 文件权限
十进制 10 0-9 (无) 人类日常计算
十六进制 16 0-9, A-F 0x 内存地址、颜色值、哈希值

为什么程序员偏爱十六进制？

原因 1：二进制到十六进制的转换非常方便

4 位二进制 = 1 位十六进制，完美对齐：


二进制    十六进制
0000  →  0
0001  →  1
...
1110  →  E
1111  →  F

因此，一个 32 位的二进制数，可以用 8 位十六进制简洁表示。

原因 2：直观性

  • 0b11111010011010110010110001000000 = 4294967040 ❌ 无法一眼看懂
  • 0xFACEB000 ✅ 程序员一眼就懂

这就是为什么内存地址、颜色值、哈希值全部使用十六进制。

各进制间转换方法

十进制 → 二进制：除 2 取余法

以 42 为例：


42 ÷ 2 = 21  余 0
21 ÷ 2 = 10  余 1
10 ÷ 2 = 5   余 0
 5 ÷ 2 = 2   余 1
 2 ÷ 2 = 1   余 0
 1 ÷ 2 = 0   余 1

从下往上 读余数：101010

✅ 验证：32 + 8 + 2 = 42

二进制 → 十进制：位权展开法

101010₂ = 1×2⁵ + 0×2⁴ + 1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 32 + 8 + 2 = 42₁₀

二进制 ↔ 十六进制：4 位分组法

二进制 → 十六进制：从右往左每 4 位一组，分别转换


101010 = 0010 1010
         ↓    ↓
         2    A

结果 = 0x2A

十六进制 → 二进制：每一位展开成 4 位


0xFACE = 1111 1010 1100 1110

快速转换技巧

背诵 2 的幂


2⁰ = 1      2⁵ = 32     2¹⁰ = 1024
2¹ = 2      2⁶ = 64     2¹⁶ = 65536
2² = 4      2⁷ = 128    2²⁰ = 1048576
2³ = 8      2⁸ = 256    2³² = 4294967296
2⁴ = 16     2⁹ = 512

记住了这些，看到二进制数可以瞬间算出来。

程序员的进制日常

场景 1：颜色值

CSS 中的十六进制颜色：


#FF0000  = 红色 (R=255, G=0, B=0)
#00FF00  = 绿色
#0000FF  = 蓝色
#FFFFFF  = 白色
#808080  = 灰色

每两位对应一个颜色通道（00=0，FF=255）。

场景 2：Linux 文件权限


rwx r-x r--  =  7 5 4 （八进制）

每三位二进制 = 一位八进制：

  • r (读) = 4 = 100
  • w (写) = 2 = 010
  • x (执行) = 1 = 001

所以 chmod 755 是程序员每天都在敲的命令。

场景 3：位运算


flags = 0b1010  # 第 1、3 位是 1
flags |= 0b0100  # 设置第 2 位
flags &= ~0b1000 # 清除第 3 位

在底层开发、性能优化中，位运算每天都会用到。

场景 4：内存地址


0x7ffee6b8c8a0  # 典型的 64 位内存地址

十六进制让 64 位地址只用 16 个字符就能表示。

常见误区

误区 1：十六进制是"编程专用"，没必要学

❌ 错。十六进制是程序员的母语，不会十六进制就不会看懂底层代码。

误区 2：进制转换用工具就行，不用自己会算

✅ 工具可以用，但理解原理让你能瞬间估算。看到 0x1000 应该立刻反应出是 4096，而不是等工具转换。

误区 3：八进制已经淘汰了

❌ 还没有。文件权限 chmod 755 每天都在用。
