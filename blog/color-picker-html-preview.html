AI Toolbox 又添两位新成员！今天上线的 颜色选择器 和 HTML 实时预览 两个工具，都是开发者日常高频使用的利器。

🎨 颜色选择器 (Color Picker)

在线取色工具，支持 HEX / RGB / HSL / HSV 四种色彩模式：

  • 点击颜色选择器选取任意颜色
  • 内置 8 种常用色块快速切换
  • 四种格式一键复制
  • 颜色预览区域自动适配对比度
无需安装任何软件，打开浏览器即可使用。

🔍 HTML 实时预览 (HTML Live Preview)

边写边看，所见即所得：

  • 输入 HTML/CSS/JS 代码 → 实时渲染
  • 支持快捷键 Ctrl+Enter 手动刷新
  • iframe sandbox 安全隔离，代码不会上传
  • 支持一键清空和复制

适合前端原型设计、代码片段测试、学习 HTML 调试。

两款工具的共同特点

  • ✅ 100% 本地处理：所有计算在浏览器完成，数据不上传服务器
  • ✅ 免费：无需注册、无需登录
  • ✅ 隐私优先：适合企业内网、敏感场景使用
  • ✅ 响应式：手机、平板、桌面都能用
