条形码生成器、颜色对比度检查器和 CSS 动画生成器上线

2026-07-13 · 5 分钟阅读

🏷️ 条形码生成器和颜色对比度检查器上线

AI 工具盒子新增两款实用工具，帮助电商从业者和前端开发者更高效地完成日常任务。

条形码生成器

新的 条形码生成器 支持五种主流条形码格式：

  • Code128 — 支持字母数字和特殊字符，适合内部编码和物流
  • EAN-13 — 国际通用的 13 位商品条码标准
  • UPC-A — 北美地区常用的 12 位商品条码
  • Code39 — 简单的字母数字编码，适合非零售场景
  • EAN-8 — 8 位缩短版商品条码

所有生成都在浏览器本地使用 Canvas 完成，数据不会上传到服务器。支持一键下载为 PNG 和 SVG 格式。

颜色对比度检查器

新的 颜色对比度检查器 帮助确保你的网站设计符合 WCAG 2.2 无障碍标准：

  • 支持 HEX、RGB、HSL 颜色格式输入
  • 实时计算对比度比例
  • 自动判断 WCAG AA 和 AAA 标准
  • 视觉效果预览，直观感受文字可读性

CSS 动画生成器

新上线的 CSS 动画生成器 让你可视化生成 @keyframes 动画效果：

  • 16 种预设动画：淡入淡出、滑入滑出、弹跳、抖动、旋转、脉冲、心跳、翻转、缩放等
  • 可自定义时长、缓动函数、延迟、播放次数、方向和填充模式
  • 实时预览动画效果
  • 一键复制生成的 CSS 代码

所有处理在浏览器本地完成，无需任何外部依赖。
